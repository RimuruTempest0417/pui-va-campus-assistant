# 培華校園助手 · Pui Va Campus Assistant

> 為澳門培華中學師生打造的校園服務小程序
> 校內考試與學年專題評核作品（**不參加比賽**）

[![CI](https://github.com/RimuruTempest0417/pui-va-campus-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/RimuruTempest0417/pui-va-campus-assistant/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-2ea44f.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-0.125.0-6D3FC4.svg)](docs/releases)

> **目標**：這是一個**考試與測驗導向**的作品 —— 以校內評核標準（功能完整度／技術難度／設計與體驗／文件與演示）交付，
> 不做對外報名、不追求上架審核。因此「學校能不能給正式主體」不再是關鍵路徑，重點是「打開就能完整跑通」。

校園裡每天發生四件高頻小事：**東西丟了找不到人、活動報名靠群裡接龍、今天午餐吃什麼、重要通知埋在群訊息裡**。
本項目把這四類校內資訊流做成可互動、有狀態、能閉環的產品——不是把學校官網搬進小程序，而是讓每一條校園資訊都有狀態、有用戶、有數據回饋。

> 本倉庫根目錄**就是**微信小程序的專案根目錄，可直接用微信開發者工具導入。
> 後端 API 獨立倉庫：[pui-va-campus-server](https://github.com/RimuruTempest0417/pui-va-campus-server)

## 技術棧

| 層 | 選型 | 理由 |
|---|---|---|
| 前端 | 微信小程序原生 + **Skyline** 渲染引擎 + glass-easel 組件框架 | 只發一端，跨端框架是額外成本；Skyline 是微信 2023 後的主力渲染引擎 |
| UI | 自建 9 個組件 + design tokens | Vant Weapp／TDesign 在 Skyline 下相容性差；自建才能統一品牌色與按壓手感 |
| 後端 | Fastify 5 + TypeScript（ESM）+ Prisma 6 | 與前端同語言；Prisma schema 即文件；Fastify 啟動快、外掛生態足夠 |
| 資料庫 | PostgreSQL 16（開發本機／上線騰訊雲，同 schema 平移） | 支援關聯查詢與 `pg_trgm`（W-9 智能匹配要用） |
| 圖片 | 騰訊雲 COS + CDN，**簽名直傳**（圖片不經過 API） | 省頻寬、避開 1 MB body 限制 |
| 認證 | `wx.login` → `code2Session` → 自簽 JWT | 不用微信雲開發，身分仍由微信保證 |

## 資料來源：預設連真後端（不是示範版）

**預設 `DEMO_MODE: 'off'`，一律打真 API。** 後端沒開就會看到錯誤與重試，不會偷偷換成假資料——
「刷新一下就變示範版」這種事不會再發生。

| 設定 | 行為 |
|---|---|
| `'off'`（**預設**） | 只用真 API；連不上就是連不上（首頁會顯示失敗與重試） |
| `'auto'` | 先打真 API，網路類錯誤才落回本地 mock（適合隨時給人看的場合） |
| `'on'` | 一律本地 mock（完全離線） |

**要離線演示又不想改程式**：首頁拉到底部點「資料來源」→ 打開「**離線示範模式**」開關。
這個開關存在本地 storage（`pv_force_demo`），關掉立刻回到真 API，不需要重新編譯。

未登入也能瀏覽（訪客）：首頁、失物、活動、菜單、公告都會正常載入，只有發布／認領／報名／評分會提示「請先登入」。

頁面只 require `services/data.js` 一個入口，所以切模式不用改任何頁面。

## 目前進度

- [x] **班主任一眼看到本班這個月的出席率（v0.125.0）**：家長問「我孩子這個月出席幾天」，老師以前只能去網頁後台翻全校月報，手機上根本翻不到。現在功課頁那張「班級總覽」最下面多一列「本月出席率」：右邊是百分比，左邊寫「缺席 7 人日 · 5 天有紀錄」；點一下就在原地展開每一天的缺席人日與當天出席率，還有「缺席最多的三天」，再點一次收起。數字跟校務處月底交的那份是同一份計算 —— 遲到算出席、請假不算缺席，不會出現老師講一套、校方講另一套；這個月還沒有任何出缺席紀錄時右邊是「—」而不是 0%，免得看起來像全班曠課。只有老師與校方看得到這一列，學生看不到

- [x] **自己送出的假單和報修，現在搜得到（v0.124.0）**：請了假想確認老師批了沒，或報修之後想再看一次總務回了什麼，以前只能回「我的假單」「我的報修」兩頁各翻一次。現在首頁放大鏡打你自己寫過的字（例如「發燒」或「冷氣」），結果會多出「我的假單」與「我的報修」兩組：假單那一列寫著病假／事假／公假與日期，右邊是待審批／已批准／已駁回；報修那一列寫著「304 室 冷氣」，右邊是待接單／處理中／已完成，第二行還寫出是哪一間、多久以前報的。點任何一列都直接跳到那份清單，不用再一筆一筆找。搜尋只找得到你自己送出的那幾筆 —— 別人也請了同一天、別班報修寫了同樣的字，都不會出現在你的結果裡；家長與未登入的人看不到這兩組（家長看孩子請假走「我的子女」）

- [x] **出席率月報可以匯出成 Excel（v0.123.0）**：校務處月底要把「這個月每班出席幾人日、遲到幾個、請假幾個」交給班主任，以前只能在網頁後台一頁一頁抄。現在「成績與出勤」的出席率月報旁邊多一顆「匯出 CSV」：左邊可以選明細要按班級（一列一個班）還是按日（一列一天），按下就下載一份 Excel 直接開、中文不會亂碼。匯出的數字跟畫面上那一份是同一個來源算出來的，不會出現「畫面寫缺席 3 人、檔案寫 4 人」；遲到算出席、請假不算缺席，沒紀錄的那天出席率留空而不是 0%（免得看起來像全校曠課）。每列都寫著月份，跟其他月份的檔案放在一起也分得出哪一份是哪個月。手機版沒有這顆按鈕是刻意的 —— 微信小程序不能下載檔案

- [x] **老師在電腦上直接印一張成績單（v0.122.0）**：以前要印成績單只能在小程序裡存成圖片，或者把整個後台分頁印出來 —— 紙上會連按鈕和補登表格一起印，而且看不出這張是誰的。現在網頁後台「成績與出勤」選好學生之後多一顆「列印成績單」：先選學年，按下去就排成一張 A4 —— 抬頭是學號、姓名、班別與列印時間，下面按學段分區列科目、測驗、日期、分數，每段右邊寫平均，最後一行是這個學年的出缺席與出席率。列印時只印這一張，畫面上的按鈕與其他表格不會跟著印出去；缺考顯示「—」不當作 0 分，平均也只算有分數的科目
- [x] **校曆多一條時間軸：接下來有什麼，一頁看完（v0.121.0）**：校曆以前只有月視圖，想知道接下來幾週有什麼，得在格子上一格一格點，或另外開公告和測驗兩頁對照。現在校曆最上面多一組「月視圖／時間軸」切換：時間軸由今天起排 60 天，只列有安排的那幾天，一天一組 —— 日期旁邊寫著「週六 · 今天」，下面一張卡把這天的事按輕重排好：緊急公告、測驗、活動、學校發布的校曆、假期、一般公告。左邊一條細色帶看出這天最重的是什麼（紅＝緊急、橙＝測驗、紫＝活動）；活動會寫出時間與地點。同一件事不會重複出現兩次：老師把考試建成活動時，活動和測驗是同一列；公告裡寫「11 月 27 日考試」時，那一場會落在考試那天、不是公告發布那天。想用月曆看那一天，點一下日期就切回月視圖並選中它
- [x] **自己的成績、出缺席、借閱、假單，現在可以自己帶走（v0.120.0）**：以前要把自己幾年的紀錄留一份，只能請校務處從後台匯出。現在到「設定」最下面的「我的資料」：成績、出缺席、借閱、請假四列，按哪一列就把它複製成 CSV 文字，貼到 Excel、Numbers 或記事本就能存檔（小程序不能下載檔案，所以是複製）。檔案裡只有你自己的紀錄 —— 學生帶別人的學號會被擋下來，家長只拿得到自己綁定的那一位子女（一個家校通家長帳號對應一位學生，另一個孩子要登入他自己的帳號再匯出）。成績那張缺考的那一格是空的、不是 0 分，免得算平均時被拉低；請假那張寫出假別、天數、狀態與誰審批，原因裡的換行會被壓成一個空白，Excel 打開不會整張歪掉。當下真的沒有資料時會明講「還沒有資料」，不會給你一份空檔

- [x] **校方看得到「哪道菜最不受歡迎」（v0.119.0）**：學生每天都在菜單頁打分數，以前這些分數只進不出 —— 學生看得到平均 4.5，校務處卻沒有任何地方能回答「哪道菜沒人想吃」。現在兩套後台都看得到：小程序「管理後台 → 菜單」在排菜單表單下面多一段「近 30 天評分統計」，第一行是全校平均、幾道菜、幾則評分與 1–2 分佔多少，下面每道菜一列寫著平均分、評分人數與被評 1–2 分的則數，最後列出最常被評低分的菜與比例；網頁後台「排菜單」同一段還能先選 30／90／180 天或近一年再看。兩條規矩：少於 3 人評分的菜只標「樣本不足」、不進排名（三個人就能把一道菜判死，那不叫統計）；已停售的菜不進統計，免得拿舊菜去問廚房。兩邊的數字都由後端同一支算，一定一樣
- [x] **家長可以從「我的子女」直接替孩子請假（v0.118.0）**：以前家長要請假得先找到首頁的「請假申請」，那條路看起來是給學生自己用的，家長常以為自己沒有權限。現在「我的子女」最上面那張卡多一列「代請假」：點下去直接進假單表單，上方已經寫著孩子的名字（一個家長帳號對應一個孩子，不用選），選假別與起訖日期、寫一句原因就送出。送出後同一頁往下滑就是「孩子的假單」：每張寫假別、日期、天數，右邊是狀態（待審批／已批准／已駁回），下面一行標著「家長代送」或「學生本人」，被駁回的直接把原因寫在列上，還沒批之前可以自己取消；只列最近五張，右邊「全部」會開完整清單。老師那一邊也看得到同一句話，不必再猜這張是誰送的
- [x] **斷網時還看得到上次的公告與課表（v0.117.0）**：學校 Wi-Fi 不通、後端在維護時，以前是四個最常看的頁面一起變「載入失敗」。現在公告、班級課表、功課、成績與出缺席（含家長的子女成績頁）會顯示**上次成功載入的那一份**，最上面一條橫幅寫著「離線資料 · 上次更新 14:32」，時間就是那份資料真的抓下來的時間。三條規矩：只有真的抓到才存、只有連不上才拿出來用、超過 24 小時就當沒有（照常顯示載入失敗）—— 不會偷偷換成示範資料，權限不足或找不到東西也照原樣失敗。快取跟著身分走（換人登入或換查詢條件都讀不到別人的），發布、報名、打勾、評分這些動作一定要真的連上才算送出
- [x] **成績單可以印了（v0.116.0）**：老師交數字時最常被問「成績單可以印嗎」，這一版把它做成真的紙上版面。在「成績與出缺席」→ 成績分頁右上多一顆「列印成績單」：一張 A4 版面寫著學生姓名、班別與學年，下面按學段（第一段／第二段／第三段）分區，每一科列出測驗名稱、日期與分數，缺考顯示「—」而不是 0；每個學段右邊自動算平均（只算有分數的那幾筆）。最後一段是這個學年的出缺席：上課日、出席、遲到、請假、缺席與出席率 —— 遲到算出席、請假不算缺席，跟學校算的數字對得上。讀到兩個學年以上時左邊會出現學年 chip，切一下就換學年；按「列印預覽」把按鈕收起來就能截圖，按「存成圖片」存到相簿（白底黑字，深色模式下也一樣）。家長從「我的子女」→ 成績分頁有同一顆，印的是自己孩子的；老師／資訊管理員在小程序後台選中學生後也印得出來。同一版，小程序後台的「成績」分頁多一段「出席率月報」：選月份就看全校與每一班的出席率、缺席／遲到／請假，外加這個月缺席最多的五天，不必再開電腦
- [x] **通知中心分好類了（v0.115.0）**：以前找「上星期批准的那張假單」得從頭翻。現在通知中心上方一排 chip：全部／功課／借閱／審批／報修／其他，每一顆右邊直接寫那一類還有幾則沒讀；點一顆就只看那一類，也可以「清空本組未讀」只清這一組，其他分類與別人的通知都不受影響。首頁鈴鐺的未讀數仍然是全部，不會因為你切了某個分頁而變少
- [x] **假單可以匯出成檔案、班級出席率一頁看完（v0.114.0）**：以前老師月底要交「這個月誰請了幾天假」，只能在後台一頁一頁抄。現在「假單」分頁多一個日期區間與一顆「匯出 CSV」，匯出來的檔案用 Excel 直接開中文不會亂碼，一列一張假單（學號、姓名、班別、假別、起訖、天數、狀態、誰審批、原因都在），下拉自動帶檔名，完成訊息直接告訴你幾筆。「成績與出缺席」分頁多一段「出席率月報」：選月份就看到全校這個月的出席率、缺席／遲到／請假各有幾人日，外加每個班一張表 —— 遲到算出席、請假不算缺席，跟學校算的數字對得上；那個月還沒有任何紀錄時顯示「—」而不是 0%。報修統計也多一行「平均接單 X 小時」，看得出是沒人接單還是修不完
- [x] **教師端「班級總覽」：朝會前 30 秒看完本班（v0.113.0）**：老師以前要知道「本班這週誰沒交功課、有沒有待審假單、報修處理到哪」，得在後台三個分頁之間來回，手機上每次還要重新篩班級。現在「功課」頁最上面多一張卡：本班人數，加上功課未交人次、逾期功課、待審假單、報修待處理四個數字，再往下是依科目分組的未交人次與最近三張待審假單（誰、什麼假、哪幾天）。這些數字與點進功課、假單、報修各分頁看到的同一份資料算出來，不會兩邊不一樣。班級是由學校在後台替你設定的，老師只看得到自己那一班；學生帳號看不到這張卡（裡面有同學姓名）。還沒設定班級時這張卡不出現，功課頁其他部分照常可用
- [x] **首頁多一張「今日待辦」：今天還有什麼沒做完，一眼看完（v0.112.0）**：以前想知道「今天還有什麼沒交、下一節在哪間課室、有幾則通知沒讀」，得沿著首頁九條入口一條一條讀。現在首頁最上面有一張卡把三件事收在一起：未交功課幾項（有逾期會多一行「1 項已逾期」並轉橘色，全部交齊寫「都交了」）、下一節是哪一科在哪間課室幾點（放假日直接寫原因，例「重陽節假期（校曆公告）」；放學後寫「今天沒有下一節了」）、還有幾則通知沒讀（超過 99 寫 99+）。按哪一行就直接跳到那一頁。三個數字跟功課頁、課表頁、通知中心是同一份資料，不會兩邊不一樣；某一支剛好沒連上時只有那一行寫「暫時取不到」，其他行照常，往下拉刷新就回來。還沒登入時整張卡不會出現；家長看到的只有兩行 —— 孩子的未交功課數與你自己的未讀通知
- [x] **搜尋也找得到書和場地（v0.111.0）**：以前搜尋只到公告、活動、失物、轉贈、菜單、功課與提案，記得「那本《活著》」還是得先點進圖書館再打一次字。現在同一支放大鏡就能找館藏：打書名、作者、或書背上的索書號（例 857.7）都找得到，每一列右邊標「可借」或「已借完」，下面寫「可借 2 / 3 冊」——借完的書照樣列出來，只是標已借完，免得你以為館裡沒有。場地與器材也一起進來了：搜「鋼琴」或「三樓」會列出在那個位置的場地，第二行直接寫它在哪一層，點進去就是借用頁。已下架或已刪除的書與場地不會出現；搜尋框下面多兩顆 chip（館藏／場地），訪客也搜得到
- [x] **搜尋補上功課與提案（v0.110.0）**：以前只搜得到公告、活動、失物、轉贈與菜單，現在打「三角函數」也會找出自己班那一份功課與它的截止時間（別班的功課不會出現），打「圖書館」也會列出同學提過的相關提案與連署進度。提案連「暫不採納」都留著，看得到校方回過什麼；功課那組點下去就是功課清單，提案那組直接進詳情。搜尋框下面多兩顆 chip（功課／提案），想只看一種時點一下就好
- [x] **連署名單看得到底（v0.109.0）**：提案詳情頁的「連署的人」原本只顯示前 12 位，熱門提案永遠看不到完整名單。現在超過 12 位時會多一列「看全部 18 人連署」，點進去是完整名單：每個人的頭像字、暱稱、身分（學生／老師／家長／校內職員）、班別，以及什麼時候連署的，由上往下就是連署順序（提案人排第一）。名單一次載 20 位，滑到底或按「載入更多」看下一批；訪客也看得到，連署名單本來就是公開的。後端名單走分頁（`GET /proposals/:id/supports`，預設 20 位一頁、上限 50），詳情頁的載入時間不會隨連署人數變慢
