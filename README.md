# 培華校園助手 · Pui Va Campus Assistant

> 為澳門培華中學師生打造的校園服務小程序
> 校內考試與學年專題評核作品（**不參加比賽**）

[![CI](https://github.com/RimuruTempest0417/pui-va-campus-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/RimuruTempest0417/pui-va-campus-assistant/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-2ea44f.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-0.77.0-6D3FC4.svg)](docs/releases)

> **目標**：這是一個**考試與測驗導向**的作品 —— 以校內評核標準（功能完整度／技術難度／設計與體驗／文件與演示）交付，
> 不做對外報名、不追求上架審核。因此「學校能不能給正式主體」不再是關鍵路徑，重點是「打開就能完整跑通」。

校園裡每天發生四件高頻小事：**東西丟了找不到人、活動報名靠群裡接龍、今天午餐吃什麼、重要通知埋在群訊息裡**。
本項目把這四類校內資訊流做成可互動、有狀態、能閉環的產品——不是把學校官網搬進小程序，而是讓每一條校園資訊都有狀態、有用戶、有數據回饋。

> 本倉庫根目錄**就是**微信小程序的專案根目錄，可直接用微信開發者工具導入。
> 後端 API 獨立倉庫：[pui-va-campus-server](https://github.com/RimuruTempest0417/pui-va-campus-server)

## 技術棧

| 層 | 選型 | 理由 |
|---|---|---|
| 前端 | 微信小程序原生 + **Skyline** 渲染引擎 + glass-easel 組件框架 | 只發一端，跨端框架是額外成本；Skyline 是微信 2023 後的主力渲染引擎 |
| UI | 自建 9 個組件 + design tokens | Vant Weapp／TDesign 在 Skyline 下相容性差；自建才能統一品牌色與按壓手感 |
| 後端 | Fastify 5 + TypeScript（ESM）+ Prisma 6 | 與前端同語言；Prisma schema 即文件；Fastify 啟動快、外掛生態足夠 |
| 資料庫 | PostgreSQL 16（開發本機／上線騰訊雲，同 schema 平移） | 支援關聯查詢與 `pg_trgm`（W-9 智能匹配要用） |
| 圖片 | 騰訊雲 COS + CDN，**簽名直傳**（圖片不經過 API） | 省頻寬、避開 1 MB body 限制 |
| 認證 | `wx.login` → `code2Session` → 自簽 JWT | 不用微信雲開發，身分仍由微信保證 |

## 資料來源：預設連真後端（不是示範版）

**預設 `DEMO_MODE: 'off'`，一律打真 API。** 後端沒開就會看到錯誤與重試，不會偷偷換成假資料——
「刷新一下就變示範版」這種事不會再發生。

| 設定 | 行為 |
|---|---|
| `'off'`（**預設**） | 只用真 API；連不上就是連不上（首頁會顯示失敗與重試） |
| `'auto'` | 先打真 API，網路類錯誤才落回本地 mock（適合隨時給人看的場合） |
| `'on'` | 一律本地 mock（完全離線） |

**要離線演示又不想改程式**：首頁拉到底部點「資料來源」→ 打開「**離線示範模式**」開關。
這個開關存在本地 storage（`pv_force_demo`），關掉立刻回到真 API，不需要重新編譯。

未登入也能瀏覽（訪客）：首頁、失物、活動、菜單、公告都會正常載入，只有發布／認領／報名／評分會提示「請先登入」。

頁面只 require `services/data.js` 一個入口，所以切模式不用改任何頁面。

## 打包交付（給老師）

```bash
node scripts/package.mjs     # → dist/pui-va-campus-assistant-vX.Y.Z.zip
```

會自動排除 `.git`／`node_modules`／`docs`／`.github`／個人設定，並把 `docs/交付給老師.md` 複製成包內的 `使用說明.md`；
打包後會驗證四個模組的頁面都在包內。zip 約 120 KB。

## 本地開發

```bash
# 一鍵驗收：六支守門串起來跑完並彙總（console 那步要 DevTools 開著，沒開會標「略過」）
node scripts/verify-all.mjs        # 4 通過／0 失敗；--no-console 跳過走查、--strict 讓略過也算失敗

# 也可以單獨跑（CI 也會跑）
node scripts/check-project.mjs     # 26 頁面 / 0 警告
node scripts/check-openapi.mjs     # 119 條路徑／138 個操作、0 重複鍵（--parity 印出與後端路由表的差）
node scripts/check-data-layer.mjs  # ALL PASS 101/101（固定跑示範資料層，含 data↔api↔mock 方法對齊）
node scripts/check-states.mjs      # 26 頁三態全部符合（--table 印出對照表）
node scripts/check-console.mjs     # 26 頁 console 走查：0 error／0 warn（要開發者工具開著專案）
```

1. 微信開發者工具 → 導入專案 → 選擇本倉庫根目錄
2. 直接編譯預覽（appid：`wx9f104c034c07e15f`）；**不跑後端也能操作**（示範模式）
3. 後端：`npm run dev`（`127.0.0.1:3100`），`config/config.js` 預設就指向它；開發者工具要勾「不校驗合法域名」
4. `project.private.config.json` 為個人本機設定，已加入 `.gitignore`

## 目前進度

- [x] **我那次認領到底通過了沒有（v0.77.0）**：以前提出認領之後，結果只會變成一則通知 —— 沒按過「允許接收通知」的人，在自己手機上永遠查不到後續。現在失物招領 → 右上「我的」→ 上方切到「我申請的」，一列一列寫著你送出的每一筆：待審核、已通過、未通過，還有送出的時間與通過／拒絕的時間，點一下就回到那件物品。別人的申請你看不到，你的也不會出現在別人手機上
- [x] **找不到就搜一下（v0.76.0）**：以前要找一則舊公告，只能在「公告」裡一頁一頁翻，活動和失物還得各自去翻一遍。現在首頁右上角多一個放大鏡：打「圖書館」三個字，公告、活動、失物一次全部列出來，標題有中的排最前、下面附一句命中處的摘要，點一下就跳到那一筆。搜到的範圍跟你平常看得到的完全一樣 —— 還沒到時間的公告、已經刪掉的東西都搜不到，失物的電話也不會因為搜尋而漏出去。最近搜過的關鍵字會留在自己手機上，下次直接點
- [x] **公告可以先寫好，明早八點才出現（v0.75.0）**：星期五放學前想通知「下週一升旗改在禮堂」，以前只能現在發（整個週末沒人看）或星期一早上記得手動按。現在後台發公告時可以指定發佈時間：到那個時間之前，學生和家長完全看不到（連網址都打不開），但老師的後台看得到、標成「排程中 · 10/27（一）08:00」；臨時想提前，按一下「立即發佈」就馬上出現。緊急公告不能預約（緊急要現在發才有通知），最多排到 90 天內
- [x] **東西丟了，別人撿到會通知你（v0.74.0）**：以前只有你主動點開某一筆失物，才看得到「可能是你的東西」。現在你貼出失物之後，只要有人撿到相似的東西（同分類、地點相近、時間接近），通知中心馬上會冒出一則「有人撿到像你的…」，點開就是那筆紀錄，可以直接提出認領。反過來，你撿到東西貼上去，正在找它的人也會被通知 —— 而且不會重複吵同一個人，也不會通知自己
- [x] **回饋催得動了（v0.73.0）**：上一版開始看得到回覆率，但往往只有一成多 —— 因為老師沒有地方可以催。後台的活動回饋區塊現在多一顆「提醒填回饋」，按一次就提醒那些「有來、但還沒填」的人（沒來的不會被要求評分，已經填過的不會再被打擾，同一場活動 12 小時內也不會重複催），按完就地顯示「已提醒 12 人（跳過 3 人最近催過）」。全部的人都填完、或這場活動沒有人簽到時，這顆按鈕是灰的。網頁後台同一套
- [x] **活動辦得好不好，後台看得到（v0.72.0）**：活動結束後學生填的星等與意見，以前只有學生自己看得到，老師想檢討只能一則一則翻。現在後台的活動統計卡多一段「回饋 3 份 · 平均 4.0 星 · 回覆率 60%」，下面接著星等分佈與最近幾則留言（帶暱稱與時間）。沒人填時顯示「還沒有人回饋」而不是 0 星；回覆率只算有出席的人，沒來的不會被算成「不願回饋」。網頁後台同一套
- [x] **公告有沒有人看，現在看得到（v0.71.0）**：老師發完公告最怕「發了等於沒發」。後台「公告」分頁現在每一則都顯示「已讀 3 / 25」，按一下就能展開名單 —— 誰看了、誰還沒看，一目了然；再按「催讀」只會通知還沒看過的人，已看過的不會再被打擾，同一則公告 12 小時內也不會重複催。網頁後台同一套
- [x] **成績批次補登（v0.70.0）**：老師手上那張紙可以直接貼進來 —— 後台「成績」分頁多一顆「批次匯入」，一行一筆「科目,類型,日期,分數」，一年級到六年級的整批成績一次填完。按「先檢查」會逐列告訴你哪一行日期看不懂、哪一筆是家校通同步的不能改，確認沒問題再按「確認匯入」；同一份內容裡重複的列、已經補過的那筆（會改成新的分數），都講清楚，不會靜靜地多出一倍。網頁後台同一套
- [x] **手機就能補登成績與出缺席（v0.69.0）**：老師和校務處不用再開電腦 —— 後台多一個「成績」分頁，輸入學號或直接點學生，就能補一筆成績或一天的出缺席，補完學生在自己手機立刻看到，該筆會標明「手動補登」。學年與學段沿用該生最近一筆，補下一科不用重打；同步來的資料在那頁只顯示不能改（那是學校系統的真相）。找學生不必先知道學號，一進分頁就先列出最近 20 位
- [x] **家校通斷了也不怕（v0.68.0）**：家長用自己的家校通帳號連結後，成績與出缺席直接在小程序看（當前＋上一個學年、三個學段）。學校站台維護或逾時導致同步失敗時，老師／校務處可以在網頁後台「成績與出勤」手動補登 —— 不會出現「今天系統壞了所以甚麼都不能做」
- [x] **小標題與數字排版統一（v0.59.0）**：全站的分組小標題統一成 13pt 次級灰＋一點字距（原本後台、菜單、登入頁各自寫了一份，字級在 15pt／13pt 之間飄），統計數字與名額、評分統一掛上等寬數字宣告；順手修掉「登入頁說已登入、後台卻說請先登入」的矛盾（JWT 過期時會清掉本機登入態並明確說「登入已過期，請重新登入」），以及每頁一條的導航列型別警告
- [x] **後台清單不再一張一張卡（v0.58.0）**：後台十四個分頁裡的十一份清單（認領、失物、垃圾桶、公告、活動、使用者、家長、檢舉、錯誤、推送、菜單）從「每一列各自一張卡」改成「整份一張卡、列與列之間一條細線」—— 原本一屏十幾塊白卡疊在一起，現在像 iOS 設定頁，一列一項、長清單掃起來快很多，也不會覺得每一筆都是獨立的東西。表單區仍然是獨立一張卡（那塊要打字，混進清單反而看不出範圍）
- [x] **示範資料不再被重複定義蓋掉（v0.54.0）**：示範模式的資料層裡有五個方法各寫了兩份（菜單週次、菜名、評分、熱門排行、切換身分），程式只會認後面那一份 —— 兩份現在內容一樣所以看不出問題，但只要有人只改上面那份，行為就會悄悄退回舊版，畫面、console、所有檢查都不會吭聲。這次逐段比對後只留一份，並把「同一支服務檔裡的方法名稱不得重複」寫成守門（重複就直接紅燈），以後不可能再默默發生
- [x] **活動附件（v0.53.0）**：活動詳情多了「附件」區塊，老師可以把比賽章程、場地圖掛上去（一份活動最多 10 份），同學點一下直接開檔，開不起來的（網頁連結）就複製連結自己貼到瀏覽器。老師在詳情頁就能加、能刪，不必找管理員。順手修掉一個真 bug：站內通知、活動回饋、組隊、回報問題這四類在真機上其實一直拋錯（檔內用了一個不存在的變數名），因為頁面都把錯誤吞掉了所以沒人發現
- [x] **回報問題（v0.52.0）**：遇到「按下去沒反應」「畫面怪」但沒有跳錯誤的情況，現在可以在設定頁寫一句話直接送到管理員 —— 系統會自動附上哪一頁、什麼手機、什麼版本，不用再靠口頭轉述。後台「錯誤」分頁多了「使用者回報」篩選與機型資訊；同一句話連按幾次只會併成一筆，不會把後台灌滿
- [x] **編輯衝突保護（v0.51.0）**：兩位老師幾乎同時改同一個活動或同一則公告時，後存的人不會再靜默蓋掉前一位 —— 先存的人成功，後存的人會看到「這筆剛被別人改過，已重新載入」，清單自動更新成最新版本，由他自己看過再決定要不要重做。順手把「每一個改動呼叫都要帶版本」寫成守門（漏一處就紅燈），因為漏帶的那條路徑會悄悄退回舊行為，畫面與 console 都不會提醒你
- [x] **登入失敗鎖定（v0.50.0）**：後台帳號密碼連續打錯 5 次，這個帳號會被鎖 15 分鐘 —— 鎖定期間就算密碼打對也進不來，訊息不透露帳號存不存在（換 IP 慢慢猜也擋得住）。管理員在「使用者」分頁看得到「已鎖定」與最後登入時間，按一顆「解除鎖定」就能讓本人立刻進去；站內使用說明也補了這一條。順手修好兩個「畫面顯示到別的字」的撞 key 錯誤（統計卡片的「本週概況」蓋掉簽到名單、「登入／培華校園助手」蓋掉兩步驗證欄位），並在守門腳本加上「同一個物件重複 key 直接紅燈」
