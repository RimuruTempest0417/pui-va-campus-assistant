# 培華校園助手 — 交付給老師的使用說明

這個資料夾就是微信小程序的專案本身，**不需要伺服器、不需要網路也能完整操作**（開一個開關就行）。

---

## 活動現場簽到（v0.24.0 新增）

1. 教職員登入 → 下方「管理後台」→「活動」分頁 → 對活動按「簽到」
2. 按「開始簽到」會出現 QR 與 6 位數字碼（投影到大屏或寫在白板）
3. 學生在自己手機：首頁 →「活動」→ 打開該活動，或「我的報名」→「現場簽到」→ 掃碼（也可手打 6 位碼）
4. 老師端即時看到「已簽到 n / 正取 m（出席率）」；沒帶手機的學生可由老師按「代簽」
5. 活動結束按「結束簽到」，舊碼立刻失效（下次要簽到請重新「開始簽到」）

## 二手書／校服轉贈（v0.88.0 新增）

1. 首頁 →「二手轉贈」→ 右下「送出東西」：選種類（書籍／校服／其他）、寫標題、選新舊，年級或尺碼與面交地點填一句就好
2. 想要別人送的東西：點進那一件 → 底部「我想要」→ 可以留一句話 → 送出；同一個人對同一件只能申請一次，等回覆時可以按「取消申請」
3. 物主收到通知後，在物品頁的「申請人」清單決定：按「給這位」把東西送出（其他人的申請會一起被婉拒），或按「婉拒」
4. 暫時不想送：按底部「下架」，別人在清單看不到；之後按「重新上架」就回來
5. 校內職員在後台「轉贈」分頁看得到全部貼文與四張統計，可以把不合適的貼文下架（之後可再上架）

> 聯絡方式只有「物主」與「被選中的那位」看得到，其他同學與訪客都看不到。

## 請假申請（v0.91.0 新增）

1. 學生：首頁 →「請假申請」→ 右上角「請假」→ 選假別（病假／事假／公假）、選開始與結束日期、寫一句原因 → 送出
2. 家長：用自己的家校通帳號登入後，同一條入口；表單上方會直接寫出孩子的名字（一個家長帳號只對應一位，不用選）
3. 送出後狀態是「待審批」，在「我的假單」看得到；還沒批之前可以自己按「取消」
4. 同一段日期不會有第二張算數的假單（系統會擋）；被駁回後改好原因，同一段可以重送
5. 老師／校務處：首頁 → 管理後台 →「假單」分頁（或網頁後台 →「假單」）→ 待審批按「批准」或「駁回」；**駁回一定要寫原因**，會同時通知家長與學生

> 請假日期只算到「天」，不填時間；一次最多 60 天，更長的請找校務處。

## 班級課表（v0.94.0 新增）

1. 學生：首頁往下滑一條「**今日課表**」，副標就是接下來要上的那一節（例「數學 · 302（10:30）」）—— 不必點進去就知道去哪間課室
2. 點進去：上面一段是「今天」（正在上的那一節左邊有紫線並標「現在」），右上角切「**整週**」五天一次看完；週末會顯示「今天不用上課」
3. 學生看的是**自己班**的課表（登入後自動用帳號上的班級）；沒登入就自己輸入班級名稱
4. 老師／校務處：後台 →「**課表**」分頁（小程序第 20 個分頁、網頁後台同一個名字）→ 貼一份 CSV，一行一格：

   ```
   班級,星期,節次,科目,老師,課室
   高二仁,1,1,數學,陳老師,302
   高二仁,1,2,英文,,302
   ```

   星期可以寫 `1–5` 或 `一–五`，節次 `1–8`，表頭有也認
5. **先按「先檢查」**：只列出每一列的結果 —— 可寫入／已存在（那一格已經有課，不會被蓋掉）／同檔重複／第幾行格式錯。確認沒問題再按「確認匯入」
6. 節次時間（第 1–8 節幾點到幾點）全校共用一份，預設 08:10 開始、每節 40 分鐘、第四節後午休；要改時間目前得由工程端改預設值

> 同一班同一節只能有一科（資料庫唯一鍵）：要調課就直接再匯入那一格，會覆蓋原本的科目與課室。

## 管理後台：誰看得到什麼（v0.26.1）

- **老師**：公告、活動（含現場簽到、自己活動的報名名單）
- **校內職員（校務處／圖書館／輔導室）**：公告、認領、成績、菜單、圖書館、場地、轉贈、名單 —— 可排菜單、可匯出全部活動的報名名單、可管館藏與場地、可下架不合適的轉贈貼文，不能開活動、不能發緊急公告
- **資訊管理員（資訊組）／最高權限**：18 個分頁全開（含「錯誤」「推送」兩頁觀測資料與「垃圾桶」）
- **學生／家長**：首頁不會出現「管理後台」入口；就算直接開頁面也會被踢回登入頁，後端同樣 403

登入方式一律是「帳號＋密碼」（由資訊組在後台建立），學生帳號沒有密碼、登不進後台。

## 五步打開

### 1. 解壓縮
把 `pui-va-campus-assistant-vX.Y.Z.zip` 解壓到任何位置（例如 `文件/培華校園助手/`）。

### 2. 導入專案
微信開發者工具 → **導入專案** → 目錄選擇剛解壓的資料夾 → AppID 填 `wx9f104c034c07e15f`（或按「測試號」）→ 確定。

### 3. 關掉域名校驗（重要）
導入後點右上角 **詳情 → 本地設定**，勾選：
- ☑ 不校驗合法域名、web-view（業務域名）、TLS 版本以及 HTTPS 證書

> 原因：後端還沒備案，請求會走 `127.0.0.1`，開發工具默認會阻擋。

### 4. 打開「離線示範模式」
編譯後首頁加載完成 → 拉到最底部點 **「資料來源」** → 打開「**離線示範模式**」開關 → 返回首頁，下拉刷新一次。

> 這樣四個模組都會用內建的示範資料，**完全不依賴後端**。
> 之後要接真後端，把同一個開關關掉即可（設定存在手機／工具本地，不用改程式碼）。

### 5. 四個模組怎麼玩（各 30 秒）
| 模組 | 操作路徑 | 看什麼 |
|---|---|---|
| 失物招領 | 首頁 → 失物招領 | 列表 6 筆 → 點一筆看詳情 → 「我要認領」→ 「已認領」狀態變化 → 發布一則 → 我的發布 |
| 活動與社團 | 首頁 → 活動與社團 | 切「已結束／全部」→ 點「科學社 · 水質檢測工作坊」（20/20 已滿）→ **排入候補，顯示候補第 1 位** → 我的報名看順位 |
| 午餐與小賣部 | 首頁 → 午餐與小賣部 | 切上／下週 → 點一道菜 → 給 1–5 星 → 回列表看平均分變化 → 底部「本週熱門」 |
| 公告與提示 | 首頁 → 公告與提示 | 置頂的緊急公告在第一位 → 點開自動變已讀 → 「全部標為已讀」→ 首頁未讀數變化 |

想一次看完資料層是否正常：首頁底部「資料來源」→ **重新檢查**，會跑 9 項檢查並顯示 `ALL PASS 9/9`。

## 常見問題

**Q：白屏／一直轉圈？**
先看開發者工具「調試器 → Console」有沒有紅色錯誤。若是 `request:fail` 或「不在以下 request 合法域名列表中」，表示第 3 步沒勾，或第 4 步的離線示範沒打開。

**Q：提示「請先登入」？**
示範模式有內建測試帳號，不會要求登入；出現這個提示通常代表你在真 API 模式但後端沒開。

**Q：想接真後端？**
到 [pui-va-campus-server](https://github.com/RimuruTempest0417/pui-va-campus-server) 執行 `npm install && npx prisma migrate dev && npx tsx prisma/seed.ts && npm run dev`，再改本專案 `config/config.js` 的 `API_BASE_URL`（預設 `http://127.0.0.1:3100/api/v1`），關掉離線示範開關。

**Q：圖片上傳呢？**
上傳簽名接口已完成，但對象存儲（騰訊雲 COS）還沒配置，所以發布頁目前以「地點＋文字描述」為主，圖片欄位先隱藏。已列入待辦（W-13 之後）。

**Q：可以改 appid 嗎？**
可以，`project.config.json` 的 `appid` 改成你自己的即可；示範模式不需要真實 appid。

## 老師可能會問的幾件事

**Q1：介面可以顯示簡體嗎？**
可以。右上角頭像 → 設定 → 介面語言，選「簡體」或「跟隨系統」。只影響介面文字，不動公告／失物內容。

**Q2：可以深色模式嗎？**
可以。設定 → 外觀：跟隨系統／淺色／深色。手機切深色時整個介面會跟著變。

**Q3：管理員帳號安全嗎？**
設定 → 安全 → 兩步驗證，用 Google／Microsoft Authenticator 掃密鑰即可開啟；開啟後登入要密碼＋6 位動態碼，另附 8 組一次性備用碼（用過即失效）。

**Q4：功課在哪裡看？老師怎麼派？**
首頁往下滑一條「功課」，副標就是「3 項未交」。點進去是你們班的功課，預設只列未完成的：交了就點那一列左邊的圓圈打勾（標題會劃線），點錯再點一次就取消；過了截止時間還沒打勾的會轉紅字並標「已逾期」。
老師（含資訊管理員、最高權限）在這一頁最下面會多一顆「出功課」：填科目、要做什麼、截止日期，送出就派給你自己那一班。同一班同一科同一天同一個內容不能重複送；派錯了按那一列右邊的「收回」，學生清單立刻消失，但紀錄留著可查。
功課是跟著**班級**走的，所以帳號要有班級資料（後台「使用者 → 編輯」可設定）；還沒設定時那一頁會直接告訴你去找校務處。

**Q5：系統會主動通知學生什麼？**
通知中心（首頁右上角鈴鐺）現在收這幾類：

| 什麼事 | 學生／家長會看到 |
|---|---|
| 功課快到截止（24 小時內） | 「功課快到截止：數學」＋要做什麼、幾點截止 |
| 功課已逾期 | 「功課已逾期：數學」＋逾期幾天（最多提醒三天） |
| 圖書館書快到期／已逾期 | 「即將到期：書名」／「逾期提醒：書名」 |
| 預約的書到館 | 「你預約的書已為你保留」，48 小時內要借 |
| 請假批准／駁回 | 「假單已批准」／「假單未通過」＋原因（家長與學生都收） |
| 場地器材批准／駁回 | 「借用申請已批准」／「借用申請未通過」 |
| 活動開始前 24 小時與 1 小時 | 「活動提醒：活動名」＋時間地點 |
| 認領結果、失物相似配對、有人想要你的二手物 | 對應的站內通知 |

功課與圖書館這兩類是每天固定時間自動跑一次（後端排程），不需要有人按；已經打勾的功課、已經歸還的書不會再通知。要臨時補跑一次，維運指令是 `POST /api/v1/cron/homework-reminders` 或 `POST /api/v1/cron/daily`（要帶 `CRON_SECRET`）。
