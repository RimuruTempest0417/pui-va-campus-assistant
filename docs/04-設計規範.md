# 設計規範 v2（Apple HIG 風格）

> 對應程式碼：`styles/tokens.wxss`（唯一來源）、`components/pv-*`、展示頁 `pages/style-guide`
> 品牌色來源：**培華主題色為紫色**（使用者確認）；校徽本身為紅字圓環＋藍水波＋綠葉，官網亦出現 `#9966FF` 紫
> 修訂：v2（2026-10-22）— 從「綠色系卡牌風」改為 Apple HIG 的分組列表風

## 一、色彩

| 角色 | 變數 | 值 | 用途 |
|---|---|---|---|
| Tint 培華紫 | `--pv-tint` | `#6D3FC4` | 學校主題色：主要動作、連結、選中態（白字對比 6.65:1，通過 AA） |
| Brand 培華紅 | `--pv-brand` | `#C8102E` | 校徽識別、緊急標記（不用於一般互動） |
| Danger | `--pv-danger` | `#D70015` | 破壞性操作（iOS systemRed） |
| Warning | `--pv-warning` | `#B25000` | 待處理、剩餘名額告急 |
| Success | `--pv-success` | `#248A3D` | 已完成、已認領 |
| 分組底 | `--pv-bg` | `#F2F2F7` | 頁面底色（systemGroupedBackground） |
| 卡片 | `--pv-surface` | `#FFFFFF` | 內容卡片 |
| 主文字 | `--pv-label` | `#000` | 標題、正文 |
| 次文字 | `--pv-label-2` | `rgba(60,60,67,.6)` | 說明、值 |
| 三級文字 | `--pv-label-3` | `rgba(60,60,67,.3)` | 註解、時間 |
| 分隔線 | `--pv-sep` | `rgba(60,60,67,.29)` | 髮絲線 1rpx |
| 填充 | `--pv-fill` | `rgba(120,120,128,.12)` | 分段控制底、按下態 |

**為何紫＋紅分工**：培華主題色是紫，所以紫當互動色（按鈕、連結、選中）；
紅色在 iOS 語意裡是「破壞性／警示」，保留給校徽識別、緊急公告與刪除操作，避免兩種紅互相干擾。
官網用的青藍 `#0C96B1` 與黃 `#DAC804` 只作校徽紋樣點綴，不進入 UI 互動層。

## 二、字階（pt → rpx，1pt ≈ 2rpx）

| 樣式 | 尺寸 | 字重 | 字距 | 行高 | 用途 |
|---|---|---|---|---|---|
| Large Title | 68rpx (34pt) | 700 | -1.2rpx | 1.1 | 頁面大標題 |
| Title 2 | 44rpx (22pt) | 600 | -0.6rpx | 1.2 | 卡片群標題 |
| Headline | 34rpx (17pt) | 600 | -0.2rpx | 1.35 | 列表主文字、按鈕 |
| Body | 34rpx (17pt) | 400 | -0.2rpx | 1.4 | 正文 |
| Subhead | 30rpx (15pt) | 400 | -0.2rpx | 1.4 | 次要說明 |
| Footnote | 26rpx (13pt) | 400 | 0 | 1.4 | 註解、分組標題 |
| Caption | 24rpx (12pt) | 400 | +0.2rpx | 1.4 | 時間、標籤 |

**關鍵**：字距**隨字級變化**（大標題收緊、小字放寬），這是 Apple 排版的核心細節，固定字距會在某個尺寸上明顯錯。

## 三、間距與圓角

- 間距以 **8rpx** 為基準：8 / 16 / 24 / 32 / 40 / 56
- 圓角：小元件 12rpx、按鈕與分段控制 20rpx、卡片與彈層 28rpx、膠囊 999rpx
- **最小觸控目標 88rpx（44pt）**：按鈕 md 就是 88rpx；小按鈕 68rpx 只用在次要動作
- 卡片**不用陰影**，靠白底 + 8rpx 髮絲線 + 分組留白分層（iOS grouped 的做法）

## 四、動效（對照 17 條原則）

| Apple 原則 | 本專案做法 |
|---|---|
| 即時回饋 | **不用 `hover-class`**（Skyline 下不可靠）→ 改用 `bindtouchstart` 自己設 `pressed` 狀態，手指落下那一幀就縮；按下 `60ms`、放開 `180ms`（縮放 0.96 + 透明度 0.88）；主要按鈕另加 `wx.vibrateShort({type:'light'})` 輕震 |
| 可中斷 / 彈簧 | Skyline 無彈簧 API，用 `cubic-bezier(.32,.72,0,1)`（iOS sheet 曲線）近似；Sheet 由下往上 320ms |
| 空間一致性 | Sheet 從底部進、往底部出；彈層遮罩只壓暗不位移，避免「跳」 |
| 排版 | 字距隨字級變化、行高隨字級反向（大標題緊、正文鬆） |
| 減弱動態 | 目標是 `prefers-reduced-motion`，但 **WXSS 不支援萬用選擇器 `*`**，且該 media query 在 wxss 編譯器的行為未確認 → 目前暫不實作（列入 P2） |
| 觸控目標 | 44pt 下限寫進按鈕尺寸，不可用更小的可點區域 |
| 語意色 | 紫給互動、紅只給破壞性與緊急、綠給完成 |

## 五、與 HIG 的已知偏離（Skyline 限制，寫進報告是加分）

1. **沒有真毛玻璃**：`backdrop-filter: blur()` 在 Skyline 尚不可靠，導航列改用 `rgba(249,249,249,.86)` 半透明近似（有透明感、無模糊）
2. **沒有彈簧 API**：用 CSS 曲線近似，無法做「手勢速度交棒」（原則 5）與「動量投影」（原則 6）；需要時改用 `worklet` 或 `wx.createAnimation`
3. **無 Dynamic Type**：小程序字級固定為 rpx，僅能用頁面設定提供「大字模式」（P2 再做）
4. **WXSS 不支援萬用選擇器 `*`**：寫 `* { ... }` 會讓**整個 wxss 檔**編譯失敗（錯誤只在「真機調試／上傳」時才暴露，模擬器刷新看不到）。
   減少動態因此改用逐組件的具體 class 停在待辦，不用 `*`。

## 六、驗證方式

- `pages/style-guide` 是視覺基準頁，含 `#token-probe`（尺寸只由 `var()` 決定）——用元素尺寸量測可證明 CSS 變數在 Skyline 真的生效
- `node scripts/check-project.mjs` 守門：頁面四件套、組件引用、docs 不進代碼包
