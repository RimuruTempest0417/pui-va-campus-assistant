# 前端 v1.0.2

**日期**：2026-11-18｜**後端 v1.0.2｜教育版 1.0.2**

## 這一版

主要是後端與網頁後台（老師在電腦上排課），小程序端只增加相容：

- 網頁後台「課表」分頁：班級下拉＋新增／刪除班級、依學校印刷版時間表排出的格線（早讀、8 節、小息、廣播操、午膳）、點格子直接輸入科目／老師／課室、**調堂模式點兩格互換**（後端交易完成，畫面自動重畫）。
- `/timetable` 與 `/timetable/today` 回應多了 `layout`（整張紙）與只含正式節次的 `periods`；小明台的課表頁照舊顯示第 1–8 節，「下一節」的計算不受作息列影響。

## 網頁後台的深色模式

網頁後台（`/admin`）會跟隨電腦的深／淺色設定自動切換，不需要按任何按鈕：深色時背景 `#0e0f13`、卡片 `#161821`、輸入框與捲軸一起變深，主色改亮一階（`#a98bf5`）以維持對比。列印不受影響。

## 未做

- 小程序後台的「課表」分頁新增**手機端調堂**：選班（可新增／刪除班級）→ 選星期 → 按「調堂」點兩格互換；單格也可改科目或清除。手機版是一天一欄的直向清單，整週五欄與模板替換仍請用電腦後台。
- **手機後台只保留常用分頁**（概況、認領、失物、活動、公告、成績、使用者、假單、課表、功課、報修）；其餘「坐下來處理」的分頁只在電腦後台出現。
- 使用說明新增四條問答（登入即同步、同步失敗會怎樣、手機怎麼調堂、手機少了哪些分頁）。

## 未做

- 課表格線未提供拖拉，也沒有「老師個人課表」視圖。
- 手機不提供整批 CSV 以外的模板替換（CSV 匯入保留作後備）。
