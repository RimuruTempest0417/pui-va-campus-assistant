# v0.71.0 — 公告已讀統計與催讀（W-54）

後端對應版本 **v0.32.0**。

## 做什麼

老師發完公告最常問的一句話是「到底有沒有人看」。在這之前，後台只能看到公告清單，
已讀狀態只有學生自己在列表上看到紅點 —— 老師手上一個數字都沒有。

這一版讓「誰看了、誰還沒看」變成可查的資料，而且可以直接催：

- **每則公告顯示已讀人數**：後台「公告」分頁的清單每列多一行「已讀 3 / 25」，
  不用點進去看就知道哪一則沒人理
- **名單可展開**：按「未讀名單」在該列下方展開已看／未看的人名（各最多 30 位），
  已看的人按「最近讀」排前面
- **一鍵催讀**：按「催讀」只發給**還沒看過**的人（站內通知匣），
  12 小時內同一則公告催過的不會重複發；畫面會說「已催讀 N 人（跳過最近催過的 M 人）」
- **網頁後台同一套**：`/admin` 的公告分頁多了「已讀」欄、名單與催讀按鈕

## 影響頁面／檔案

| 位置 | 改動 |
|---|---|
| `pages/admin/index`（公告分頁） | 每列「已讀 N / M」＋「未讀名單」＋「催讀」；展開區塊顯示已看／未看名單 |
| `services/admin.js` | 新增 `noticeReadStats(id)`、`remindNotice(id)` |
| `public/admin.html`（後端 repo） | 公告表多「已讀」欄、名單與催讀按鈕 |

## 三條規則（寫進後端，前端不重算）

1. **只催未讀者**：對已讀的人再發一次就是騷擾。
2. **12 小時內不重複催**：連點兩下不會發兩輪，被跳過的人數會顯示出來。
3. **分母＝未被停用的帳號**（含教職員）：停用帳號不計入，否則已讀率永遠到不了 100%。
