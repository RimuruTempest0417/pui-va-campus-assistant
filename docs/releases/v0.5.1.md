# v0.5.1 — 頂部安全區與全站可回彈滾動（2026-10-22）

使用者回報兩個 UI 問題：① 動態島與右上角膠囊蓋住頁面頂部，點不到 ② 部分頁面無法滾動、沒有回彈。

## 修法

### 1. 頂部安全區（不再寫死數字）

- `app.js` 的 `onLaunch` 量一次 `wx.getMenuButtonBoundingClientRect()` 與 `wx.getWindowInfo()`：
  `navHeight = (capsule.top − statusBarHeight) × 2 + capsule.height`，`total = statusBarHeight + navHeight`
- 自訂導航頁（首頁、設計系統）用 `padding-top: {{navTotal}}px`，不再用 `env(safe-area-inset-top)` 猜
- 實測（iPhone 模擬器 430×932）：`statusBarHeight 54 / navHeight 40 / total 94`，
  首頁第一個內容區塊量到 **top = 94px**，膠囊底部在 90px → 不再重疊

### 2. 全站可滾動 + 回彈

- 七個頁面全部改成 `<scroll-view scroll-y bounces enhanced show-scrollbar="{{false}}">`（Skyline 下頁面級滾動不穩，`bounces` 才是可靠的回彈來源）
- **固定元素移到 scroll-view 之外**：發布 FAB、詳情／發布頁的底部操作列、底部彈層 —— 否則會被裁切或跟著內容滾走
- 下拉刷新改用 scroll-view 的 `refresher-enabled` + `bindrefresherrefresh`（頁面級 `onPullDownRefresh` 在 scroll-view 內不會觸發）

## 踩到的坑（已寫進專案技能）

DevTools 熱重載**不會重跑 `app.onLaunch`**，因此 `globalData.nav` 一直是舊的 `null`，看起來像「程式沒生效」。
解法：`close_project_window` → `open_project_window`，量到的值才是真的。
