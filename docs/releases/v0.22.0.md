## 設計取捨

- 用**關聯表**而不是 User 上一個「家長 id」欄位：一位家長可以有多位子女、一位學生也可以有父、母兩個帳號，單欄位存不下
- 綁定只認**帳號（openid）**，所以家長要先用自己的微信登入一次才有帳號；角色必須先設成 PARENT，避免把老師帳號誤綁成家長（回 422 並說明原因）
- 本版只做「綁定關係＋讀取」，**代子女報名／取消（P3）排下一項**，避免一次改動太大
- 家長能力仍是「只讀」（等於 GUEST），隔離靠路由層反查，不靠能力矩陣 —— 這樣日後加代報名時只需給 PARENT 加能力，不會影響其他角色
- 網頁後台本來就沒有「活動／檢舉／審計」三個分頁（既有落差），本版不順手擴張，留在隊列第 9 項一起處理
