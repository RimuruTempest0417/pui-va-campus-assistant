# v0.125.0 — 班主任一眼看到本班出席率（2026-11-08）

## 做了什麼（W-106）

出席率月報（v0.114.0／v0.123.0）只有 `school:manage` 看得到，那是校務處的口徑：全校一張表、月底交數字。
但**每天要回答家長「我這個月出席幾天」的是班主任**，他要的只是自己班那一行。
這一版把它放到老師本來就會開的那一頁：**不開新頁、沒有新表、沒有第二份計算**。

- 後端新端點 `GET /teacher/class/attendance`（能力 `leave:review`：老師與校內職員都有；學生與家長 403）。
- **直接複用 `src/lib/attendance-monthly.ts`** 的聚合，只取本班那一列 —— 與
  `GET /admin/school/attendance/monthly` 是同一份程式，不會出現「班主任說 3 人缺席、校務處說 4 人」。
- 功課頁「班級總覽」卡最下面多一列「本月出席率」：左邊「缺席 N 人日 · N 天有紀錄」，右邊是出席率；
  點一下在原地展開每日明細與「缺席最多的三天」，再點一次收起。

## 四條規則（跟 `/teacher/class` 同一套，沒有第二種講法）

1. **班級由 `User.className` 決定**，不信前端傳來的班級。老師帶 `?className=` 別班回 403；
   管理員以上可以指定（與班級總覽同一條例外）。
2. **沒班級回 422** 並寫「請找校務處在後台設定班級」—— 不是 500，也不是空白的 0%。
3. **遲到算出席、請假不算缺席**：病假不該壓低班級出席率，否則跟學校算的數字對不上。
4. **沒有紀錄回 `null`，畫面顯示「—」**：0% 看起來像全班曠課，那是兩件完全不同的事。
