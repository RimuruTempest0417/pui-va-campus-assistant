# v0.26.1 — 校內職員（STAFF）後台入口（2026-10-25）

## 做什麼

- **首頁入口**：管理後台卡片原本只對 TEACHER／ADMIN／SUPER_ADMIN 顯示，現在 STAFF 也看得到；卡片副標改成依角色（`ADMIN_SUB`），STAFF 顯示「排菜單 · 報名名單」，不會看到自己打不開的「審核認領」。
- **後台分頁**：`pages/admin/index` 的 `ROLE_TABS` 加 `STAFF: [menu, export]`（只有菜單與名單）；`onLoad` 的角色放行從「硬寫三個角色」改成「這個角色有分頁才進」，沒有分頁直接回登入頁（原本的 `|| [notice]` 會讓學生也勉強進到公告分頁）。
- **角色標籤**：兩個前端都補上 STAFF「校內職員」（Lv2，與老師同級）。

## 順手修掉的靜默 bug

使用者分頁的「設為 X」按鈕靠 `item.level > r.level` 判斷，但 `roles` 是頁面裡的本地常數、每個元素沒有 `level` → `level > undefined` 永遠 false，**這些按鈕從來沒有顯示過**（console 完全沒有錯，只有肉眼比對才看得出來）。改成直接用 `GET /admin/users` 回來的 `roles`（後端已帶 `key／level／label`），本地清單只當離線備援，並補上 level。
