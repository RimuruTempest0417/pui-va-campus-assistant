# v0.26.0 — 介面繁簡切換（i18n 基礎）（2026-10-24）

## 為什麼

校內同時有本地生與內地生。原本介面文字寫死在 WXML 裡，簡體使用者看到的是繁體。
這版建立 i18n 底座，先把**最常看到的三個畫面**（首頁／公告列表／校曆）接上，其餘頁面後續逐頁遷移。

## 做了什麼

| 檔案 | 內容 |
|---|---|
| `utils/i18n.js` | 30 條文案的繁簡字典（首頁模組／單位／問候／校曆／共用／自檢頁）、`t(key)`、`setLocale()`、`locale()`、`isHans()`、`greetingByHour()`；未知 key 原樣回傳（方便漸進遷移） |
| `config/config.js` | `LOCALE: 'zh-Hant'`（預設）＋ storage key `pv_locale` |
| `pages/index` | 四個模組名稱與單位、問候語、示範標籤、緊急標籤、訪客／同學、載入失敗文案改吃 `t()`；`onShow` 會重取（切換語言回來立刻生效） |
| `pages/notices/list` | 「列表／校曆」分段、「全部標為已讀」 |
| `pages/calendar` | 標題、今天、空狀態、項目類型標籤（活動／緊急／校曆／公告） |
| `pages/dev/api-check` | 新增「介面語言：繁體／简体」切換（只改文案，不動資料） |
| `scripts/check-data-layer.mjs` | 新增 4 項 i18n 檢查 → **60/60** |

## 驗證

```
node scripts/check-project.mjs   → 19 頁 0 警告
node scripts/check-data-layer.mjs → ALL PASS 60/60（+4：繁簡齊全／切換生效／未知 key 原樣／非法值回退）
模擬器實測（切到簡體後回首頁）     → 失物招领/5 条 | 活动与社团/1 个 | 午餐与小卖部/1 款 | 公告与提示/2 条
再切回繁體                        → 失物招領/5 筆 | 活動與社團/1 個 …
```

## 覆蓋範圍（誠實說明）

已接：**首頁、公告列表、校曆、開發自檢頁**。
未接：失物／活動／菜單的內頁、後台十個分頁、網頁後台。這些頁面的文案仍寫死在 WXML，
下一版起逐頁遷移（每頁遷完都要 `t()` 覆蓋率檢查，避免半繁半簡）。

## 設計取捨

- **只翻介面，不翻內容**：公告標題、活動名稱、使用者暱稱一律照原文，避免把學校專有名詞翻壞。
- **字典放程式碼而非 JSON**：小程序 `require` JSON 在部分基礎庫版本行為不一致；字典放在 JS 裡可直接被 `check-data-layer.mjs` 載入驗證（不依賴 IDE）。
- **不引入第三方 i18n 庫**：30 條文案、兩種語言，自己寫 60 行比拉一個庫更容易維護。
