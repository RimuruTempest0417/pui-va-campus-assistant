# v0.2.0 — 設計系統（2026-10-22）

## 新增

- **design tokens**（`styles/tokens.wxss`）：品牌色（培華綠／校徽金）、語意色、中性色階、6 級字級、8 的倍數間距、圓角與陰影。
  所有頁面與組件只引用變數，不寫死色碼；換色只改這一個檔案。
- **8 個原子組件**（`components/pv-*`）：
  `pv-button`（4 型 × 2 尺寸 × block/loading/disabled）、`pv-card`（標題／額外／footer slot）、
  `pv-tag`（5 型 + plain）、`pv-avatar`（圖片或姓名首字）、`pv-empty`、`pv-skeleton`（行數＋頭像）、
  `pv-tabs`（含角標）、`pv-sheet`（底部彈層，含安全區）
- **設計系統展示頁**（`pages/style-guide/index`）：色彩、字級、所有組件與狀態；開發期檢視用，不進正式導覽
- `app.wxss` 引入 tokens；`scripts/check-project.mjs` 支援 `index.json` 命名慣例
