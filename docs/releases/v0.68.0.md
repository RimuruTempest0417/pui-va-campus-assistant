# v0.68.0 — W-53 第一階段：老師／職員替學生補登成績與出缺席

## 這一版做了什麼

家校通同步是靠學校站台，會因維護、逾時或密碼失效而斷。斷掉時老師與校務處原本只能等 ——
這一版把「補登」做成正式功能，補完學生在小程序立刻看得到。

**後端（v0.30.4）**

- 新能力 `school:manage`（老師、校內職員都有；管理員以上繼承）。能力矩陣仍只有 `src/lib/permissions.ts` 一份來源，`GET /admin/permissions` 自動跟著更新。
- 七支端點：
  - `GET /admin/school/students?q=` 用學號／姓名／班別找學生（只搜學生身分）
  - `GET /admin/school/grades?studentId=` 某位學生的成績，每筆帶 `manual` 旗標
  - `POST /admin/school/grades` 補登（upsert 到原本的唯一鍵）
  - `DELETE /admin/school/grades/:id` 只刪 `source=MANUAL`
  - `GET /admin/school/attendance?studentId=` 出缺席＋summary
  - `POST /admin/school/attendance` 補登（同一學生同一天是「改」）
  - `DELETE /admin/school/attendance/:id` 只刪 `source=MANUAL`
- 每次寫入都留審計（`school.grade.manual`／`school.attendance.manual`／`.delete`）。

**網頁後台**（`GET /admin` → 新分頁「成績與出勤」）

- 三段式：①找學生 → ②補登成績 → ③補登出缺席。學年／學段沿用同一組，補下一科不用重打。
- 列上的來源欄分「手動／同步」；同步的沒有刪除鈕（不是藏起來，後端也會擋）。
- 老師（TEACHER）與校內職員（STAFF）都看得到這個分頁。

**小程序（學生／家長端）**

- `pages/school` 的成績與出缺席，`source=MANUAL` 的列顯示「手動補登」標記，不再和家校通同步的資料混在一起看不出來源。

## 設計取捨（含一個刻意不做的事）

1. **同步來的資料不能被手動覆蓋，也不能刪。** 那是學校系統的真相；手動只補「系統裡沒有」的那幾筆。要修就等下一次同步，或由學校端改。覆蓋回 `409`、刪除回 `422`，不是靜默失敗。
2. **寫入一律 upsert 到原本的唯一鍵**（成績：學生＋學年＋學段＋科目＋類型＋日期；出缺席：學生＋日期）。同一個人補第二次是「改」而不是多一筆 —— 否則學生端會看到兩筆同名成績，家長第一個就會問。
3. **不做「改同步資料」的介面**：寧可讓老師多按一次「立即同步」，也不要做出「畫面上改了、下次同步又被蓋掉」的假功能。
4. 端點按既有慣例放在 `admin/school/*`，不改動原本的家長端 `/school/*`；學生端一行程式都沒改就吃到新資料（它本來就是讀同一張表）。
