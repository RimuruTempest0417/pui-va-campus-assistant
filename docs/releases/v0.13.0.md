# v0.13.0 — 訂閱消息與內容安全的前端配套（W-11，2026-10-23）

## 新增

| 檔案 | 內容 |
|---|---|
| `config/config.js` | `SUBSCRIBE_TEMPLATES`（claim／event／notice）。**留空就不彈窗**，功能照常運作 |
| `utils/subscribe.js` | `wx.requestSubscribeMessage` → 只把使用者按「允許」的模板送後端 |
| `services/{api,mock,data}.js` | `subscribe`／`mySubscriptions`（示範模式只記錄，不發送） |
| `pages/items/detail` | 送出認領申請前詢問 `claim` 模板 |
| `pages/events/detail` | 報名前詢問 `event` 模板 |

模板 ID 要在 mp 後台「訂閱消息」建立後填入 `config.SUBSCRIBE_TEMPLATES`，同時在後端 `.env` 填
`WX_TPL_CLAIM`／`WX_TPL_EVENT`／`WX_TPL_NOTICE`。

## 內容安全

違規內容由後端回 `422 CONTENT_RISKY`，前端沿用既有的錯誤文案（「內容未通過安全檢查，請修改後再送出」），不用另外改頁面。
