# v0.83.0 — 家校通帳號決定身分 ＋ 家長免綁定就看得到子女（2026-11-05）

> 後端 **v0.42.0**（`pui-va-campus-server`）

## 為什麼

v0.82.0 讓「有家校通帳密的人」都能登入，但登入之後還是半成品：

1. **身分要等管理員改**：所有人第一次登入都是學生，家長得請資訊管理員在後台改成 `PARENT`。
   可是家校通的帳號本來就分得出來（`s3201301037` 學生、`3201301037`／`pv3201301037` 家長）。
2. **家長看得到「子女」卻看不到成績**：家長端所有資料都掛在 `parent_links`，而那是管理員一筆一筆綁的；
   就算綁好了，成績與出缺席頁讀的是「自己的 JWT」，家長打開只會是空白。

這一版把這兩件事接完：**登入時就用帳號前綴決定身分、家長自動對應子女、家長讀子女的成績與出缺席**。

## 改了什麼

| 位置 | 內容 |
|---|---|
| 後端 `src/lib/school-account.ts`（新） | 純函式：`s…` → 學生、純數字 → 家長、`pv…` → 家長；**兩種以外的格式不硬猜**，建學生並回 `accountType: 'other'`（等指示）。另含 `extractStudentNos()`：家校通登入後首頁列出的學號（`studentNo=` 連結／`SELECT` 選項／`STUDENT_NO` 常數都認） |
| 後端 `POST /auth/school` | 第一次建立才用前綴決定角色（**已存在的帳號角色一律不動**，後台指派的不會被登入蓋掉）；家長第一次建立的暱稱是「家長」。回應新增 `accountType` 與 `children`（本次對應到的子女） |
| 家長免綁定 | 家長登入時把「他看得到的學號」建成 `parent_links`：先取家校通首頁列出的、再補上帳號本身的數字。子女還沒登入過就先建一列佔位帳號（`sc:s<學號>`，`lastLoginAt` 留空），他本人之後用 `s<學號>` 登入時接手同一列，**不會變兩個帳號**。對應失敗（資料庫出錯）**不會讓登入失敗**，只記一筆 warn |
| 後端 `GET /parents/me/children/:studentId/grades`、`/attendance` | 家長讀子女的成績與出缺席，形狀與 `/school/grades`、`/school/attendance` 一致；閘門仍是 `assertParent` ＋ `resolveChild`（未綁定 403、訊息與「沒這個人」相同） |
| 後端 `POST /parents/me/children/:studentId/sync` | 用**家長自己**已加密的 `SchoolLink` 登入家校通，抓回來的資料寫在**子女**那一列。既有同步邏輯抽成 `syncInto()` 一支，兩條路徑不再各寫一份 |
| 前端 `pages/school`（成績與出缺席） | 家長身分時這頁變成「選子女 → 看成績／出缺席」：一位直接顯示名字、多位給 chips 切換（切換會重抓，不是只換標題）；「連結家校通」保留，因為那是同步子女資料的憑證（`credLinked` 與「有沒有子女」是兩個旗標） |
| 前端 `pages/admin/login` | 家校通登入成功且對應到子女時，登入後多一句「已對應子女：N 位」；表單下方補一行帳號格式說明（學生 `s` 開頭、家長 `pv`／純數字） |
| 前端 `pages/help` | 家長分頁改寫 5 則（免綁定、帳號格式、怎麼看子女成績）＋訪客「只有家校通帳號能登入嗎」補上新的身分規則 |
| `docs/openapi.yaml` | 新增 3 條路徑、`/auth/school` 回應補 `accountType`／`children` |

## 怎麼驗

- 後端：`npx tsc --noEmit` 0 錯；`npm test` **43 檔 384 項全過**（v0.41.0 是 370 項）

- 前端守門：`check-project` **26 頁 0 警告**｜`check-i18n` **35 項（對照表 1074 組）**｜`check-data-layer` **111/111**｜`check-states` **26 頁三態全過**｜`check-openapi` **124 路徑／143 操作，parity 雙向 0**｜`check-pages-boot` **26 頁**｜`check-aliases` **59 檔**
- 家長視角頁面邏輯模擬（新增 `scripts/check-parent-view.cjs`）：**12 項全過** —— 家長身分會讀 `parentChildGrades/Attendance` 而不是自己的 `/school/*`、預設選第一位子女、切換子女會重抓、成績與 summary 有渲染、沒有誤入失敗狀態
- 過程中抓到的真 bug：`sc:<純數字>` 對「純數字家長」就是他自己的 openid，候選清單一定先找到自己 → 被「不能綁自己」的判斷跳過，**一位子女都對不上**。修法是把本人 openid 從候選剔除，且「找到的不是學生」時改建佔位帳號而不是直接跳過。
- 線上：後端 push `main` 後 Vercel 自動部署，以 `401`（路由已部署、只是沒帶 token）而不是 `404` 確認新版

## 沒做的／要講清楚

- **家校通有沒有「子女清單」端點，我沒有用真實家長帳號實測過**：目前做法是不猜端點，改從「登入後首頁」找學號（下拉選單／連結／常數），抓不到就退回「帳號數字部分」。如果你有家長帳號可以讓我試一次，就能確認哪一種寫法最穩。
- 佔位學生帳號（`sc:s<學號>`）會出現在後台使用者清單裡，`lastLoginAt` 是空的 —— 那不是異常，代表「這位學生還沒自己登入過」。
- 家長自己的 `/school/sync` 仍會寫在家長那一列（既有行為沒動），要在家長端同步子女請用「同步子女成績」；兩者刻意分開，避免家長的列出現一份不屬於他的成績。
- 手感（chip 按下去的回饋）與實際版面仍需你用手指看一次；自動化只能驗到資料與狀態。
