# v0.5.2 — 共用導航列、安全區與返回即刷新（2026-10-22）

## 根因

`app.json` 的 `window.navigationStyle` 是 **`custom`（全域）**，所以除首頁外**每個頁面都沒有真的導航列**：
沒有返回鍵、沒有頂部安全區 → 內容撞上動態島與右上角膠囊，底部按鈕也貼著螢幕邊緣。上一版只補了首頁的 padding，沒有解決這件事。

## 修法

### 1. 共用導航列 `pv-navbar`
- 高度由 `wx.getMenuButtonBoundingClientRect()` 實測（狀態列 + 導航列），不寫死
- 左側返回鍵（44pt 可點區）、標題、**右側預留 190rpx 給膠囊**，標題不會被蓋
- 套用到：列表／詳情／發布／我的發布／設計系統／自檢頁

### 2. 頁面骨架
- `.page-root` 改為 flex 直向 + `height: 100vh`，`pv-navbar` 佔頂部、`scroll-view` 吃剩餘高度（`flex: 1; min-height: 0`）
- 底部操作列的內容留白由 200rpx 加到 260rpx，按鈕不再貼邊

### 3. 返回即刷新
- 列表頁與「我的發布」改成 `onShow` 重抓（首次不重複請求）
- 在詳情頁認領後返回，列表狀態立即更新
