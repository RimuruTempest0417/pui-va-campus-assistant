# v0.41.0 — 站內通知、活動取消／延期、帳號救援、稽核匯出（2026-10-24）

## W-34 站內通知（前端＋後端）

訂閱消息有兩個天生限制：要使用者按過同意、而且只能發一次。所以另外做了**站內訊息匣**：

| 位置 | 內容 |
|---|---|
| 後端 | `notifications` 表；`GET /notifications`（含未讀數）、`GET /notifications/unread-count`、`PATCH /notifications/read` |
| 前端 | `pages/notifications`：分類標籤（活動／認領／公告／系統）、未讀紅點、點擊即已讀並跳到對應頁、全部標為已讀 |
| 首頁 | 右上角鈴鐺＋未讀數量徽章（99+ 上限） |
| 設定頁 | 「通知」入口 |

## W-29 活動取消／延期

- 後端 `PATCH /admin/events/:id` 收 `postpone: true`：改時間時記下 `postponedFrom`，原時間保留
- 取消或延期 → **自動通知所有正取與候補**（站內通知，帶活動連結）
- 前端活動詳情：取消顯示紅色提示條；延期顯示「原定 X，請留意新時間」

## W-26 帳號救援

管理員可對**低於自己等級**的帳號：

- `POST /admin/users/:id/temp-password` → 產生 10 碼臨時密碼（回傳一次）並清掉 2FA
- `POST /admin/users/:id/reset-2fa` → 只清 2FA（保留密碼）

兩者都寫審計紀錄。

## W-27 稽核匯出

`GET /admin/audit.csv`（最高權限）：UTF-8 BOM＋中文表頭，Excel 直接開不亂碼。
