# v0.122.0 — 老師在電腦上直接印一張成績單（2026-11-07）

## 做了什麼（W-103）

小程序裡已經可以把成績單存成圖片（v0.116.0），但老師在**電腦**上批完成績、要印一張紙給家長時，
只能整頁列印 —— 紙上會連按鈕、批次補登的表格、出席率月報一起印出來，而且沒有「這一張是誰的」的抬頭。

這一版只在**網頁後台**加一顆按鈕，沒有新頁面、沒有新端點、沒有新表：

- 「成績與出勤」分頁、選好學生之後多一列：**列印學年**（下拉，預設最新那個學年）＋ **列印成績單**。
- 印出來的是一張 A4：抬頭寫**學號／姓名／班別**與**學年、列印時間**，
  下面是按學段分區的成績表（科目／測驗／日期／分數），每個學段右邊寫**平均**與筆數，
  最後一行是該學年的**出缺席摘要**（上課日／出席／遲到／請假／缺席／出席率）。
- 列印時**只印這一張**：其他分頁、登入畫面、按鈕、頁籤全部收起來（`body.printing` ＋ `@media print`），
  印完就自動收回，不會影響下一次操作。
- 按下去會**先重抓一次**該學生的成績與出缺席再排版，不是印畫面上可能已經被改過的舊表格；沒有成績時明講「先補登或同步再印」，不印一張空白紙。

## 為什麼數字要跟小程序一模一樣

同一份成績在手機（`pages/print/transcript`）和電腦（網頁後台）印出來必須是同一組數字，
否則家長手上兩張紙對不起來。所以分組、平均、出缺席口徑**逐條照抄** `utils/transcriptSheet.js`：

- 缺考／未評分印 `—`（不是 0），平均**只算有分數的科目**；
- 學段照「第一段 → 第二段 → 第三段」固定順序，**空學段不留在紙上**；不在三個固定值裡的舊學段排在最後而不是丟掉；
- 出缺席：**遲到算出席、請假不算缺席**，出席率 `(有紀錄 − 缺席) ÷ 有紀錄`，沒紀錄回 `null`（不假裝 100%）；
- 學號由 `sc:s3201301037` 取成 `3201301037`（家校通帳號前綴不是學號，直接印會讓老師以為打錯）。

## 順手抓到的兩個舊 bug

1. **`@media print` 用到的 `--print-ink`／`--print-muted`／`--print-line`／`--print-bg` 從來沒有宣告過**
   （v0.42.0 的列印樣式只寫了 `var(--print-*)`）。變數不存在時整條宣告無效 —— 列印的表格邊框一直是「沒有邊框」，
   而且不會有任何錯誤訊息。這一版把它們補進 `:root`。
2. **成績單若按「收掉 `main > section`」來隔離，紙上會是全白**：成績單在 `#adminView` 裡面，
   把 `#adminView` 一起 `display:none` 等於連它自己都藏起來。改成明確列出要收的分頁（`#adminView > section`、`.tabs`、`#loginView`），
   再用 ID 選擇器（2 個 ID 勝過 1 個 class）把成績單打開。這一條已寫成測試斷言，避免以後有人「簡化」選擇器又印出白紙。
