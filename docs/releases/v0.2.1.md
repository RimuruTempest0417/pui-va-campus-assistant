# v0.2.1 — 設計系統改為 Apple HIG 風格（2026-10-22）

## 為什麼改

初版用綠色系卡牌風，但**培華並不是綠色為主的學校**：校徽是紅（字與圓環）＋藍（水波）＋綠（葉），官網主色是 `#0C96B1` 青藍。
使用者同時指定要有 Apple 的設計語言，因此整套重做。

## 改變

- **色彩**：改為 iOS 語意色系 —— tint 培華藍 `#0C96B1`（互動）／brand 培華紅 `#C8102E`（識別與緊急）／systemRed `#D70015`（破壞性）
  ／`systemGroupedBackground` `#F2F2F7`／`label` 三階透明度
- **排版**：改用 Apple 字階（Large Title 34pt → Caption 12pt），字距隨字級變化（大標題 −1.2rpx、小字 +0.2rpx）
- **形狀**：卡片改為 inset grouped（白底、無陰影、1rpx 髮絲線）；圓角統一 12/20/28rpx
- **觸控**：按鈕尺寸對齊 44pt 最小可點區；按下**同一幀**回饋（`hover-start-time=0`，縮放 0.97）
- **分段控制**：改成 iOS UISegmentedControl（灰底膠囊 + 白色浮起塊 + 陰影）
- **彈層**：加抓手（grabber）、iOS sheet 曲線 `cubic-bezier(.32,.72,0,1)`、安全區 padding
- **減少動態**：加入 `prefers-reduced-motion` 支援
- 新增 `docs/04-設計規範.md`（色彩／字階／間距表＋與 HIG 的偏離說明）

- 無真毛玻璃（Skyline 的 `backdrop-filter` 不可靠）→ 半透明近似
