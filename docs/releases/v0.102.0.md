# v0.102.0 — 課表印得出來：紙上版週課表＋存成圖片（W-83）

- **日期**：2026-11-07
- **版本**：前端 `v0.102.0`／後端 `v0.55.0`（後端這版沒有改動）
- **分支**：前端 `develop`（未合 `main`、未上傳微信）
- **上一版**：前端 `v0.101.0`（課表接校曆放假）

## 這一版做了什麼

班會要貼在課室後面的是**一張紙**，不是手機畫面。原本課表只有「今天／整週」兩種滑動檢視，
截圖會連導航列與分頁一起截進去。這一版補一條真正給紙用的路徑：

1. 新頁 `pages/print/timetable`（第 42 頁）：A4 版面的週課表 ——
   標題寫「班級 ＋ 本週 11/02–11/06」、副標寫列印日期；表格是**節次 × 星期一到五**的固定格子，
   每格寫科目、課室、老師（課室與老師分行，一行放不下「實驗室 B · 吳老師」）。
   沒課的格子留白，不是把清單硬印成一列一列。整頁強制 `theme-light`：深色模式下也是白底黑字。
2. `pages/timetable`：標題下面靠右一顆「列印／存成圖片」→ 帶班名進列印頁（沒有班級時不顯示）。
3. 「存成圖片」用 **`wx.createOffscreenCanvas` 離屏畫布**輸出 1080×1304 的 PNG（白底黑字、
   格線 1rpx 灰、表頭粗線），再 `canvasToTempFilePath` ＋ `saveImageToPhotosAlbum` 存相簿；
   相簿權限被拒時給明確說明，不會靜默失敗。
4. 新的純函式模組 `utils/timetableGrid.js`（`buildGrid`／`weekRange`／`imagePlan`／`draw`／`decodeParam`）：
   格子怎麼攤、圖怎麼排版、字怎麼截，全部離線可測 —— Node 端用假 ctx 把每個繪圖呼叫記下來逐項斷言。
5. `utils/theme.js` 補三個列印色（`ink`／`inkSoft`／`rule`），並把 `check-project` 第 13 條從
   「只比對 4 個 hex」擴成「8 個（含 `surface`／`ink`／`inkSoft`／`rule`，hex 與 rgba 都比）」——
   canvas 只能吃字面色值，少比對一個就等於容許它跟 tokens 漂移。
6. 示範課表資料修正：課室與老師改成**按科目**給（以前是按節次），
   不然印出來會出現「音樂在操場上課」。`SEED_VERSION` 14 → 15，舊裝置的示範資料會自動重生。
7. `pages/help` 補一問「課表可以印出來或存成圖片嗎？」（學生分頁最後一條）。

## 看圖才抓到的三個 bug（都是靜態守門全綠、編譯也不報）

1. **中文班名沒解碼**：課表頁用 `encodeURIComponent` 帶班名過來，列印頁 `onLoad` 收到的仍是
   `%E9%AB%98%E4%BA%8C%E4%BB%81`，於是拿編碼後的字串去查課表 → **整張表空白**。
   修法：`grid.decodeParam()`（對沒有 `%` 的字串原樣回傳，兩種情況都能吃），守門補 4 項。
2. **`<canvas>` 節點在 Skyline 拿不到**：`NodesRef.fields({node:true})` 對不在屏的節點不回呼
   （console 只給一句 `[warn] 检测到 NodesRef.fields 不能立即回调`），症狀是按了「存成圖片」
   **loading 一直轉、圖永遠不出來**（`busy` 卡在 true，之後按鈕再也按不動）。把 canvas 挪到
   scroll-view 外面、改成 `opacity: 0` 都一樣。最後改用 `wx.createOffscreenCanvas` 才通。
3. **「課室 · 老師」合一行被截斷**：圖上出現「實驗室 B · …」。改成
   `buildGrid` 分別回 `room`／`teacher`，紙上與圖上都分兩行畫。

另外順手加了 `_watchdog`（8 秒）：任何一步沒回呼都會收掉 loading 並提示「產生失敗」，
不會讓按鈕永遠卡在轉圈。

## 設計取捨

- **不新增後端端點**：課表資料早就有（`GET /timetable`），列印頁只是換一種視圖；
  多開一支 `/timetable/print` 等於兩份真相，課表改了列印版不會跟著改。
- **列印頁強制淺色**：紙永遠是白的。跟隨深色模式的話，印出來／存下來的圖是黑底白字。
- **存圖用離屏畫布，不用 WXML `<canvas>`**：除了上面第 2 個 bug，離屏畫布還不受
  scroll-view、視窗大小、DPR 影響，圖尺寸固定 1080 寬，貼到班群不會糊。
- **圖片用 1080 寬而不是跟螢幕一樣寬**：420pt 寬的螢幕存出來的圖在別人的手機上看會很模糊。
- **不做「一頁 40 格全印」以外的版面選項**：先確定老師真的需要什麼再加，現在這張就是一張 A4。
- **示範資料改了就要升 `SEED_VERSION`**：不升的話舊裝置永遠看到「音樂在操場」的舊資料，
  而且不會有任何錯誤訊息。
