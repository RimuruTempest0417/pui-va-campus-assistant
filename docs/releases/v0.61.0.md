# v0.61.0 — 列表 grouped 樣式收成單一來源（W-48）（2026-10-25）

> 前端 v0.61.0｜後端維持 v0.28.0（本版不動 API）

## 1. W-48：`.ui-list--grouped` 從三份真相收成一份

v0.58.0 把 inset grouped 清單樣式上移到 `styles/ui.wxss`，但失物列表與活動列表的頁面 wxss 還各留一份同樣的規則
（`.ui-list { background… }`、`.ui-list .ui-card--row { … }`、`.ui-list .ui-card--last { … }`）。
結果是同一套樣式有三個地方可改，改一處另兩處不會跟 —— 而 Skyline 對沒生效的樣式是靜默的（不報錯、不 warn）。

- 兩頁 wrapper 改成 `class="ui-list ui-list--grouped"`，頁面 wxss 的那三行刪掉，只留一行註解指向共用來源
- 純樣式搬移、行為等價：`styles/ui.wxss` 的規則與原頁面規則逐條相同

## 2. 順手修掉兩個 grouped 的漏網處（同一輪、同一類）

- **失物列表的「已經到底了」原本在卡片裡面**：`.list-foot` 寫在 `.ui-list--grouped` 容器內，於是那一行灰字被包進白色卡片、
  容器底部多出 60px 空白（rect：容器 786.2 高、七列只佔 725.9）。已搬到容器外，現在列與容器完全貼合（725.9 = 725.9）。
- **載入骨架沒有 grouped 容器**：兩頁的 skeleton 是散的 `ui-card`，資料回來時會從「兩張分開的卡」跳成「一張卡」。
  已改成 `ui-list ui-list--grouped` ＋ `ui-card--row`（最後一列 `ui-card--last`），載入與載入後同一個形狀。

## 3. 新增守門：`check-project` 第 21 條

兩件事一起擋，因為它們都會靜默通過編譯：

1. 頁面 wxss 不得再自己寫 `.ui-list` 群組規則（只有 `styles/ui.wxss` 一份來源）
2. wxml 只要用了 `ui-card--row`，同一個檔案就必須出現 `ui-list ui-list--grouped` 容器（骨架最常漏）
