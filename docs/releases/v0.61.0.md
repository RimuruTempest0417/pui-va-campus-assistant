# v0.61.0 — 修補：設定頁間距、使用說明分頁、後台刪除進垃圾桶、網頁公告管理（2026-10-25）

## 1. 設定頁：資料來源與下面三項黏在一起
`.set-inner` 改成 flex column + `gap`，卡片間距不再靠各自的 margin 疊；群組標題上緣也收到 8rpx。

## 2. 使用說明：只看得到「學生」和半個「家長」
分頁 chips 原本放在 `scroll-view scroll-x` 裡，超出寬度就被裁掉。改成 **flex + wrap**：四個分頁（學生／家長／老師／資訊管理員）自動換行全部看得到，chip 高度 60rpx、左右 22rpx。

## 3. 後台：每個東西都能刪，刪完只進垃圾桶
- 後端新增 `DELETE /admin/items/:id`（軟刪除）、`DELETE /admin/events/:id`（軟刪除＋取消報名者通知）
- `Event` 加 `deletedAt`：前台活動清單、後台活動清單都排除；回收桶可還原（還原時狀態回到 `PUBLISHED`）
- 資源回收桶支援 **event** 類型（列表＋還原＋計數）
- 小程序後台活動列加「刪除」按鈕（兩段式確認，避免誤刪）
- 失物、公告、使用者原本就有下架／刪除 → 同樣走垃圾桶，不需另加

## 4. 網頁後台：「發公告」改成「公告」
- 分頁改名，下面新增**既有公告清單**（標題／類型／時間／刪除）
- 刪除是兩段式（按一次變「確定刪除？」，4 秒內再按才執行），刪完移到回收桶
