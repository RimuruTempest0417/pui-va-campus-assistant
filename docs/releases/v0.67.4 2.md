# v0.67.4 — 後台「刪除」與家校通「解除連結」按下去會炸（別名／方法名錯）

這一版修的是同一個家族的三個錯：**請求層的別名與方法名寫錯**，而且編譯、console、既有守門全部不會報，
只有按到那個按鈕、或線上錯誤記錄才看得到。

## 抓到的 bug

1. `services/admin.js` 的 `deleteEvent()`／`deleteItem()` 寫成 `request.delete(...)`，
   但那個檔案裡的請求物件叫 **`http`** → 執行期 `request is not defined`。
   也就是說後台「刪除活動」「刪除失物」兩顆鈕按下去直接失敗（軟刪除根本沒送出去）。
2. 即使改成 `http.delete(...)` 也不對：`utils/request.js` 只匯出 `get/post/patch/del`，
   **沒有 `delete`** → `http.delete is not a function`。正確是 `http.del(...)`。
3. `services/api.js` 的 `schoolUnlink()` 同樣寫成 `http.delete('/school/link')`
   → 家校通「解除連結」按下去 TypeError，帳密也就解除不掉。

## 怎麼修

- `services/admin.js`：`request.delete` → `http.del`（2 處）
- `services/api.js`：`http.delete` → `http.del`（1 處）
- `scripts/check-project.mjs` 新增第 22 條守門：`services/`、`utils/` 裡呼叫
  `<別名>.<get|post|put|patch|del|delete|head>(` 時，
  ①別名必須真的由 `require('…/request')` 宣告（擋 `request is not defined`）；
  ②方法必須在 `utils/request.js` 的 `module.exports` 裡（擋 `http.delete is not a function`）。
  允許清單直接從 `utils/request.js` 解析，不再另抄一份。
