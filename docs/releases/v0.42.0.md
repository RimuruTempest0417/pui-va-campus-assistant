# v0.42.0 — 活動回饋與分享卡（2026-10-24）

## W-31 活動回饋

只有「**報名正取**且**活動已結束**」的人可以評，一人一次（重填是覆蓋，不會洗分）。

- 後端：`POST /events/:id/feedback`（`rating` 1–5、`comment` ≤300）、`GET /events/:id/feedback`（平均分、筆數、我的評分、最近 20 條留言）
- 前端活動詳情：結束後出現回饋卡 —— 五顆星＋留言框；下方直接看到「★ 4.6 · 12 人評分」與別人的留言

## W-32 分享卡

活動詳情底部「產生分享卡」：用 canvas 2D 畫一張 600×800 的海報（品牌色底、活動名、時間、地點、名額），
`canvasToTempFilePath` → `saveImageToPhotosAlbum` 存到相簿；沒有相簿權限時給明確說明，不靜默失敗。
