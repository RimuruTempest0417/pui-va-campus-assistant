# 前端 v1.0.24（套餐可評分、首頁離線標示）

**日期**：2026-11-21｜**後端 v1.0.24｜教育版 1.0.24**

## ① 菜單：套餐可以評分了

- A／B／C 每一格的天花板文字後面加「· 可評分」，整格可點 → 進那道菜的詳情頁打分／按讚。
- 按下有底色回饋（`set-meal--pressed`），不會像壞掉。
- 湯／糖水不可點（它不是獨立菜色）。

## ② 首頁：吃到舊資料一定要寫出來

實測回報「明明只有兩份功課，首頁寫三份未交」。伺服器當時回的是 2 份、公告 0 則未讀 ——
所以畫面是**舊快取**，而首頁以前沒有離線標示，數字看起來像即時的。

- 首頁載入前 `offlineReset()`、載入後把「離線資料 · 上次更新」寫在最上面（與功課／公告頁同一套）。
- 這樣就不會再有「數字對不上又找不到原因」的情況。

## ③ 提醒

若更新後菜單仍看不到「湯／糖水」，請到「設定 → 版本」看是不是 1.0.24（舊版沒有那一行）。
