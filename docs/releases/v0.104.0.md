# v0.104.0 — 圖書館：熱門排行、借閱 CSV 匯出、預約到書通知（2026-11-07）

任務：W-85（P1，後端 v0.57.0）

## 做了什麼

- **熱門排行（學生看得到）**：圖書館列表上方多一個「熱門」分頁，列出**近 90 天借出次數前 5 名**，
  每一列左邊是名次圓徽章、標題下面寫「近 90 天借出 N 次 · 作者」。次數由後端 `groupBy` 算，
  前端不自己數一遍（換窗口天數時才不會跟詳情頁的「近 90 天借出」對不上）。
  沒有資料時顯示「最近還沒有人借書／有人借過之後，這裡就會出現排行」，不是一片空白。
  切到「熱門」時搜尋列會收起（搜尋結果是另一種視圖），切回「全部」就回來。
- **借閱紀錄 CSV（只在網頁後台）**：`/admin` →「圖書館」→「借閱紀錄」→ 右上「匯出借閱 CSV」，
  依目前選的範圍（借閱中／逾期／已歸還／全部）匯出。端點本來就帶 UTF-8 BOM，Excel 開中文不亂碼；
  網頁用 `fetch` 帶 token 抓（不能只用 `<a href>`，會被 401 擋掉）。
  小程序端刻意沒有這顆按鈕 —— 微信不能下載 CSV，做了也只會失敗。
- **熱門榜在網頁後台也看得到**：館藏分頁下方多一張「熱門排行（近 90 天）」表（前 10 名），
  館藏換頁／改書之後會一起重載。
- **預約到書通知補齊**：排候補時順便問一次訂閱同意（`subscribe.request('hold')`）；
  有人還書／有人取消已留書／留書逾期回收，三個時機都會發**站內通知＋（有同意時）微信訂閱消息**，
  文案統一在後端 `notifyHoldReady()`。模板 ID 沒填就不彈窗、不發送，功能照常。
- 使用說明補三條 Q&A（哪些書最多人借／書到了怎麼通知／借閱紀錄怎麼匯出 Excel），
  學生與職員分頁各對應自己的操作路徑。

## 設計取捨

- **窗口維持 90 天，不是規劃書原本寫的 30 天**：校內一學期借閱量小，30 天常湊不滿 5 本，
  榜單時有時無（老師演示看到空清單會以為壞了）。後端已支援 `?days=`，要做月度榜改一個參數就行。
- **熱門用分頁而不是在首屏塞 5 列卡片**：圖書館列表首屏已經有搜尋、掃碼與篩選 chips，
  再放一段排行會把真正的館藏擠到第二屏；分頁讓使用者自己選要不要看。
- **CSV 只有網頁版**：不是漏做，是小程序下載不了檔案（`wx.openDocument` 不支援 csv）。
