# v0.36.0 — W-21 深色模式（三選一：跟隨系統／淺色／深色）（2026-10-24）

## 做法與為什麼

Skyline 對 `prefers-color-scheme` 的支援不穩定（不同基礎庫版本行為不一致），所以**不用媒體查詢**，改用最可靠的方式：

1. `utils/appearance.js` 決定目前應該是 light 還是 dark（跟隨系統時讀 `wx.getAppBaseInfo().theme`）
2. 20 個頁面的根節點都掛 `{{themeClass}}` → 得到 `.theme-light` 或 `.theme-dark`
3. `styles/tokens.wxss` 的 `.theme-dark` 只覆寫**顏色變數**，頁面與組件完全不用改（顏色早就收斂成 `--pv-*`）
4. `app.js` 用 `wx.onThemeChange` 監聽系統切換，即時更新當前頁

設定頁的「外觀」三選一會立刻套用（不用重開）。

## 深色配色（實測對比度）

| 用途 | 值 | 對比度（深色底 #1c1c1e） |
|---|---|---|
| 主文字 | `#ffffff` | 17.0:1 |
| 次要文字 | `rgba(235,235,245,0.62)` | 6.3:1 |
| 三級文字 | `rgba(235,235,245,0.52)` | **4.8:1**（原本 0.34 → 2.8:1，已調高） |
| 連結／主要動作 | `#9d7ce0` | 5.2:1 |
| 危險 | `#ff6961` | 6.0:1 |
| 成功 | `#4cd964` | 9.3:1 |
| 警告 | `#ffb340` | 9.5:1 |

配色原則：背景純黑 `#000`、卡片 `#1c1c1e`（iOS grouped 深色）；**培華紅 `#c8102e` 不變**（校徽識別色不隨外觀漂移），但徽章底調整透明度以免刺眼。

## 守門

漏一個就會出現「深色底配白色卡片」這種半深半淺的災難，這條會直接判錯。
