# v0.60.0 — 線性圖標系統（W-47）＋ 全站按鈕間距修正（2026-10-25）

> 前端 v0.60.0｜後端維持 v0.28.0

## 1. W-47 線性圖標（`components/pv-icon`）

之前把 emoji 換成「單字」（失／活／餐／告）只是過渡。這版建了真正的圖標組件：

- **用 view＋border 畫，不用 SVG 檔**：Skyline 對 `<image src="*.svg">` 與 data-URI 支援不穩，而這個專案已經用同一招畫過鈴鐺與空狀態圓環（模擬器與實機都正常）
- 規格：24px 網格、描邊恆為 **2rpx**、單色、內部幾何用百分比定位 → 同一個圖標放大縮小線寬不變
- 5 種色調：`default`／`muted`／`tint`（品牌紫）／`on-tint`／`brand`（校徽紅），全部讀 CSS 變數，**深色模式自動跟著換**
- 首批 8 個：items（置物箱）、events（日曆）、menu（餐碗）、notices（文件三行）、bell（鈴鐺）、search（放大鏡）、inbox（空狀態）、chevron
- 已接入：首頁四宮格、首頁鈴鐺、失物搜尋、`pv-empty` 空狀態

## 2. 按鈕擠在一起：一次修 23 處

使用者回報「多個頁面按鈕沒有分開」。掃描全站後找到 **23 組**相鄰按鈕，其中 7 組的容器完全沒有 `gap`：

| 容器 | 頁面 | 修法 |
|---|---|---|
| `.ui-row` | 活動詳情（組隊、回饋等功能列） | 全域加 `gap: 12rpx` ＋ `flex-wrap` |
| `.row-actions` | 後台 11 個清單（每列的操作按鈕） | 加 `gap` ＋ `flex-wrap` |
| `.mine-actions` | 我的報名、我的發布 | 同上 |
| `.state-actions` | 家長頁 | 同上 |
| `.ci-actions` | 簽到頁 | 同上 |
| `.toolbar__btns` | 兩個列印頁 | **補上缺失的規則**（原本根本沒有這條 CSS） |
| `.api-actions` | 資料來源自檢頁 | 兩欄等寬 ＋ 間距 |

## 4. 自檢頁的「語言卡跑到容器外」（真正原因）

`pages/dev/api-check/index.wxml` 在根節點 `</view>` **之後**還掛著一段 `<view class="ui-card">`（介面語言），
它被寫在 `scroll-view` 外，於是渲染在頁面底部蓋住內容、把按鈕區壓在一起。已搬回容器內並改用 `pv-card`。

> 這種錯不會讓 `check-project` 紅（結構檢查看的是標籤與註冊關係，不是標籤位置），所以只能靠使用者回報。
