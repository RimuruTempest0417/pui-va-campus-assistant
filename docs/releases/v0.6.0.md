# v0.6.0 — 活動與社團（W-5，2026-10-22）

## 新增

| 頁面 | 內容 |
|---|---|
| `pages/events/list` | 分段控制（即將開始／已結束／全部）＋「我的報名」入口；卡片帶名額進度條（`37 / 40 人`、不限名額另計）與狀態（已報名／候補中／已滿／已結束） |
| `pages/events/detail` | 標題、社團、狀態標籤、時間地點名額、進度條、剩餘名額文案、活動說明、我的報名狀態；底部操作列依狀態變化（立即報名／排入候補／取消報名／取消候補／已結束） |

底層：
- `services/mock` 活動層重寫：`listEvents(scope)` / `getEvent` / `signupEvent` / `cancelSignup` / `mySignups` / `switchDemoUser`
- **滿額不是錯誤**：`signupEvent` 回傳 `status: WAITLIST` 與 `waitlistPos`，讓 UI 直接顯示「候補第 N 位」，不再把正常流程當成 exception 吞掉
- **取消自動補位**：有人取消 `CONFIRMED` 時，最早排隊的 `WAITLIST` 升為 `CONFIRMED` 並重排候補序號
- 示範資料 seed 升到 v3：6 個活動（含 20/20 已滿、只有 1 個名額、不限名額、已結束各一）

## 設計取捨

- 滿額回「候補成功」而非 409 錯誤：對使用者來說那不是失敗，是另一種成功；錯誤碼 `EVENT_FULL` 仍保留給後端契約（W-8 需要明確語意時可用）
- 進度條用純 CSS 寬度百分比，不用第三方圖表
- 報名狀態以「伺服器回傳的 mySignup」為準，前端不自己推算
