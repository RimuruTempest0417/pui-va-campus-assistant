# v0.121.0 — 校曆多一條時間軸：公告、假期、活動、測驗排在同一條線上（2026-11-07）

## 做了什麼（W-100）

校曆以前只有月視圖：想知道「接下來有什麼」，得在月曆格子上逐天點，或另外開公告、測驗兩頁對照。
這一版在**同一頁**加第二種看法，資料來源完全沒變：

- 校曆頁最上面多一組分段控制：**月視圖／時間軸**。
- 時間軸＝**由今天起 60 天**，只列有安排的那幾天，一天一組：
  日期標題（`11月8日 · 週六 · 今天`）＋ 一張 inset grouped 卡，列與列之間 1rpx 髮絲線。
- 同一天的四種來源排在一起，順序固定：
  **緊急公告 → 測驗 → 活動 → 學校校曆（ICS）→ 假期 → 一般公告**；
  同類型再按時間由早到晚，沒寫時間的排最後。
- 日期標題左邊一條 8rpx 色帶表示這天最重的事（紅＝緊急、橙＝測驗、紫＝活動、灰＝其他）。
- 點日期標題 → **切回月視圖並選中那一天**（兩種看法指向同一批事，不新增頁面）。

## 兩個容易做錯的規則（這也是這一版的主要工作量）

1. **同一筆資料既是活動又是測驗 → 只出一列**。老師把考試建成活動時，測驗倒數也會抓到它；
   若照兩邊結果各畫一列，同一天會出現兩張一樣的卡。現在會合併成一列並標上「測驗」。
2. **公告裡的考試日期不是發布日**。`utils/study.upcomingExams` 從公告文字抓出的是「考試那天」，
   所以那種測驗要落在考試日、徽章是「測驗」、點下去回到那則公告 —— 不是落在公告發布日。

## 順手修掉的兩個舊問題

- 月視圖下方的當天清單原本是**每一項一張卡**（一頁 2.7 張 `pv-card` 的來源之一），
  改成 iOS inset grouped：**一張卡＋1rpx 髮絲線分列**，標籤固定在右邊不壓縮、標題 `min-width: 0` 可換行。
- 當天清單的按壓回饋原本用 `hover-class`（Skyline 下不可靠，按下去常常沒反應），
  改成 `bindtouchstart`／`bindtouchend` 自己管 `pressedKey`：按下 60ms、放開 180ms。

## 設計取捨

- **不加新頁面**：時間軸是同一份 `data.calendar()` ＋ `data.externalCalendar()` 的第二種視圖，
  連 `services/` 都沒有動 —— 多開一頁等於多一份沒人看過的畫面，而 Gary 這幾天無法幫忙看畫面。
- **不重寫考試日期規則**：直接吃 `utils/study.upcomingExams` 的結果（含公告文字抓日期、120 天 horizon），
  兩頁對「什麼算測驗」的判斷永遠一致；重寫一份早晚會出現「測驗頁有、校曆沒有」。
- 純函式放 `utils/calendarTimeline.js`，不 require `wx`／`services`／`i18n`：
  顯示文字由頁面傳入，規則才能被 Node 直接測。
- 時間軸只列「有東西的那幾天」——它是議程，不是月曆；空白日不佔版面。
