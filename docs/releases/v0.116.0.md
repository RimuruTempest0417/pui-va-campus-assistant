# v0.116.0 — 成績單可以印了（W-95 收尾）

> 2026-11-07｜前端 v0.116.0（後端不變 v0.67.0）

## 這一版做了什麼

### ① 成績單列印／存成圖片（新頁 `pages/print/transcript`，第 49 頁）

老師交數字時最常被問的一句是「成績單可以印嗎」，家長也想知道「可不可以拿一張紙給家裡看」。
這一版把「一個學生、一個學年」的成績攤成一張 A4 版面：

- **三種身分共用同一頁**，差別只在資料來源與入口：
  - 學生／職員：`/school/grades`＋`/school/attendance`（自己那一列）
  - 家長：`/parents/me/children/:id/grades|attendance`（`?child=`，後端仍用 `parent_links` 反查）
  - 老師／資訊管理員：`/admin/school/grades|attendance?studentId=`（`?studentId=`，能力 `school:manage`）
- **按學段分區**（第一段／第二段／第三段），每列寫科目、測驗名稱、日期、分數；沒有分數（缺考／未批改）顯示破折號，不是 0。
- **每個學段自動算平均**：只算真的有分數的那幾筆，缺考不進分母；一個都沒有回 `—`。
- **出缺席摘要一段**：上課日、出席、遲到、請假、缺席、出席率。口徑與後端 `/admin/school/attendance/monthly` 完全一致 —— **遲到算出席、請假不算缺席**。
- **學年 chip**：讀到兩個學年以上才出現，切換只重算不重抓（三支端點一次就回整份，上限 500 筆，慢網路上少打一次差很多）。
- **「存成圖片」用離屏 canvas**（沿用課表列印的做法）：`wx.createOffscreenCanvas` + `canvasToTempFilePath`，1080 寬、白底黑字，深色模式下也一樣；8 秒 watchdog，任一步沒回呼就收掉 loading 並提示「產生失敗」，不會卡住。
- 紙永遠是白的（本頁強制 `theme-light`）；顏色全部由 `utils/theme.js` 取，`check-project` 第 13 條逐項比對 `styles/tokens.wxss`。

入口三處：
1. `pages/school`（成績與出缺席）→ 成績分頁右上「列印成績單」
2. `pages/admin/index`（小程序後台）→ 成績分頁選中學生後「列印成績單」
3. 家長從「我的子女」→ 成績分頁同一顆（帶 `child`）

### ② 小程序後台「成績」分頁加出席率月報

網頁後台 v0.114.0 已有 `GET /admin/school/attendance/monthly`，但手機上要開電腦才看得到。
這一版把它接進小程序後台（**沒有新端點、沒有新表**）：

- 月份 picker（`fields="month"`），一進分頁就載當月。
- 一句話摘要：全校 N 人 · 紀錄 M 筆 · 出席率 X% · 遲到 · 請假 · 缺席。
- 每個班一列（出席率＋人數＋缺席次數）。沒紀錄時 `rate` 是 `—`（不是 0%）。
- 這個月缺席或遲到最多的五天（最多 5 天，31 天全列在手機上沒有意義）。
- 月報讀不到**只影響那一區**（寫一行原因），上面的補登功能照常可用 —— 不要讓一支聚合端點把整頁打成「載入失敗」。

### ③ 示範資料補齊（成績單要有東西可印）

`services/mock.js` 的 `demoSchoolGrades` 從 3 筆（只有第一段）擴到 **8 筆／兩個學年／兩個學段**，`demoSchoolAttendance` 從 3 天擴到 **9 天（含遲到、請假、曠課各一）**，並補上 `yearTerm`：
- 沒有 `yearTerm` 時回全部（與真 API 同語意）；
- 給了 `yearTerm` 就真的過濾，`summary` 跟著重算；
- `parentChildGrades`／`parentChildAttendance` 也支援同一個參數，未綁定子女仍 `FORBIDDEN`（示範模式不可以比真 API 寬鬆）。

## 設計取捨

- **不開第二頁**：成績單與「成績與出缺席」共用同一份資料，只是呈現不同（一個是清單、一個是紙）。所以入口放在既有頁面，只新增列印頁本身。
- **學年切換在客戶端過濾**：三支端點本來就一次回整份，再打一次只會讓家長多等；也讓「切學年」在示範模式與真 API 行為一致。
- **月報不在前端重算**：三個地方（成績單、月報、網頁後台）都要用同一套口徑，所以在頁面再算一次一定會漂。前端只顯示後端回來的數字。
- **網頁後台不加成績單列印**（刻意）：網頁可以整頁 Ctrl+P，再做人一份 canvas 版等於兩套版面要同步；這一輪先把小程序端做完，列進規劃書的後續項。

## 已知缺口（這一版沒做／沒驗）

- **畫面沒有親眼驗**：本輪沒有開開發者工具（老師的機器／模擬器不在手邊），成績單的實際排版、學年 chip 的寬度、月報在小螢幕上的摺行都只有靜態與邏輯模擬，沒有真人看過。
- **網頁後台沒有「成績單列印」**：只有在網頁看得到成績清單（既有），要印紙本建議用瀏覽器列印整個分頁；獨立成一份 A4 版面列進規劃書。
- **小程序後台月報的示範模式**：後台頁面本來就只走真 API，示範模式下這一區會顯示「讀不到」——與其他後台分頁一致，不是這一版新增的問題。
- **`check-console` 走查沒跑**：需要開發者工具在線，留待下一次能開工具時補。
