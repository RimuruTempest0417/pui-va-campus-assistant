# 前端 v1.0.6（網頁端菜單表格；小程序未變）

**日期**：2026-11-18｜**後端 v1.0.6｜教育版仍為 1.0.5**

## 這一版

- 網頁後台「菜單」分頁最上面多了 **本週菜單（A／B／C 餐）** 表格：橫的是星期一到五、直的是 A／B／C 餐，
  每一格直接輸入文字（例：咖哩雞飯 · 例湯）；上一週／本週／下一週切換；「儲存這一週」一次送 15 格。
- 原本的「排菜單（一道一道菜）」、評分統計與 CSV 匯入都保留在下面，沒有動。

## 為什麼不是逐格儲存

一個星期只有 15 格，逐格送要 15 個請求，中途失敗會留下「半週新、半週舊」的菜單 —— 這種錯家長一眼看出來。
所以後端是整週覆蓋（`PUT /admin/menu/sets`），前端一次送完。

## 小程序

這一版**沒有改動小程序**，所以不用重新上傳體驗版；手機端菜單頁照舊顯示 `menu_entries` 的菜色。
若要把 A／B／C 餐也顯示在手機上，下一版再加（後端 API 已具備）。
