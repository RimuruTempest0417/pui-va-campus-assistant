# 前端 v1.0.1（家校通修正）

**日期**：2026-11-18｜**前一版**：v1.0.0｜**後端**：v1.0.1

## 修了什麼

| 問題（使用者回報） | 修法 |
|---|---|
| 同一個家長有 `pv` 與沒有 `pv` 變成兩個帳號 | 後端收斂 openid 並就地合併；前端不用改，登入哪一種寫法都會進同一個帳號 |
| 登入後看不到姓名與班別 | 後端從家校通側邊欄抓姓名／班別寫回帳號；登入回應多 `studentCard`，家長端顯示子女姓名 |
| 今日多次抓取家校通失敗、資料不全面 | 新增「順手刷新」：`services/data.js` 在任何讀到成績／出缺席／狀態的動作後踢一次 `/school/refresh`（10 分鐘節流、8 秒預算、失敗靜音），使用者不會多等 |
| 後台沒有手動刷新按鈕 | 小程序後台「成績與出勤」最上面多一張「家校通資料」卡：按一下刷新（選了學生只刷新他），結果寫「已刷新 N 位：成績 X 筆、出缺席 Y 筆」；網頁 `/admin` 同一個位置也有按鈕 |
| 管理頁多段文字沒有分行、超出畫面 | `styles/ui.wxss`：`.ui-row-between` 允許換行、`row-gap: 6rpx`，並對 `.ui-title/.ui-body/.ui-meta/.ui-section` 與列內子元素加 `min-width: 0; word-break: break-word; overflow-wrap: anywhere`（Skyline 下 flex 子元素預設 `min-width:auto` 會把整列推出畫面） |
| 登入後沒有自動刷新 | 登入成功設 `app.globalData.needRefresh`，首頁 `onShow` 看到旗標就重跑 `refresh()`；家校通登入成功另外順手抓一批最新資料 |
