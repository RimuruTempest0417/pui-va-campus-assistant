## 三、加了會擋的守門（`scripts/check-docs.mjs`）

1. `docs/進度.md` 最新一列的版本 **必須等於** 最新 release（做完沒登記＝紅燈）
2. 進度表**必須由新到舊**排序
3. 進度表**不得被空行打斷**
4. `docs/進度.md` **不得出現隊列表**（隊列只放規劃書）
5. 規劃書「待完成細節」**不得出現 ✅**
6. 規劃書「執行順序」與「待完成細節」的 W 編號**必須雙向對得上**

負向測試：故意插入一列假隊列 → `exit 1` 並指出「隊列只放規劃書」；還原後 `exit 0`。

已把今天所有文件的日期統一校正為 2026-10-24，避免之後對不上 git log 與錯誤記錄的時間戳。
