# v0.43.0 — 組隊報名（W-30，最後一項功能）

## 怎麼運作

| 角色 | 動作 |
|---|---|
| 老師 | 建立活動時勾「開放組隊報名」（`teamsEnabled`） |
| 隊長 | 活動詳情 → 建立隊伍 → 系統給 **6 碼邀請碼**（同活動隊名不可重複） |
| 隊員 | 「用邀請碼加入」→ 輸入 6 碼 → 按報名（名額仍算活動層級，先滿先候補） |

- 只有**隊長**看得到自己隊伍的邀請碼；其他人在列表只看到隊名與人數
- 報名時帶 `teamCode` 會驗證隊伍屬於該活動，碼錯了回 422
- 個人報名與組隊報名並存：不填碼就是個人報名
