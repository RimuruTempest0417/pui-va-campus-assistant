# v0.11.1 — 修正真 API 模式下發布失物的兩個問題（2026-10-23）

接上真後端（`DEMO_MODE='off'`）之後才暴露的兩個欄位問題：

1. **分類會掉**：發布頁送的是 `categoryKey`（例如 `other`），後端要的是 `categoryId`。
   Zod 會把不認得的欄位濾掉，所以分類一直是空的。
   → 改為同時送 `categoryKey`（示範資料用）與 `categoryId`（真 API 用，從已載入的分類清單查出）。
2. **圖片會存成無效路徑**：真 API 模式下 `wx.chooseMedia` 拿到的是本機臨時路徑，後端照樣存進 `item_images`，
   結果是打不開的網址。→ 真 API 模式下不送圖片，並在 Toast 提示「已發布（圖片暫不支援）」；
   發布頁的說明文字也依模式切換（示範：只存本機／真 API：尚未開通）。
