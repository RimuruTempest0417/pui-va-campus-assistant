# v0.37.1 — 修兩個「畫面空白」的 bug（2026-10-24）

## 1. 設定頁整頁空白（`this.options is not a function`）

上傳到線上錯誤記錄的實際堆疊：

```
TypeError: this.options is not a function
    at ComponentCaller.onShow (pages/settings/index.js:86:13)
```

原因：設定頁把「外觀／語言選項」寫成 `options()` 方法，但 **`options` 是 Page 的保留欄位**
（頁面參數，框架自己會用）。覆蓋之後 Page 註冊異常，`onShow` 裡的 `this.options()` 直接拋錯，
`setData` 從沒執行 → 整頁只剩卡片外框、所有文字空白。

修法：改名 `labelOptions()`；`check-project` 新增守門，`Page({})` 內用 `options()`／`properties()`／
`behaviors()` 當方法名一律判錯。

## 2. 深色模式下部分文字仍是黑色

實機量到：`失物招領`、`今日午餐`、`管理後台` 等**沒有自己寫 `color` 的節點**，
在深色底上繼承了平台預設黑色 → 看不見。

修法：在根節點 class 同時給文字色：

```css
.theme-light,
.theme-dark { color: var(--pv-label); }
```

這樣沒有明寫顏色的節點也會跟著主題走。順手把守門的 `.theme-dark` 解析改成「取最後一個區塊」，
免得群組選擇器 `.theme-light,\n.theme-dark` 被誤判成缺漏 29 個變數。
