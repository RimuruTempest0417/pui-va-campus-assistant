## 這版抓到的兩個真問題

1. **發布時間**：原本一律取「當日 09:00」，導致今天發布的新貼文排在既有資料（相對 `now`）後面 —— 違反「發布後立即出現在列表頂部」。修法：日期是今天就用 `Date.now()`。
2. **物件參照別名**：mock 直接回傳 storage 裡的同一個物件，兩次狀態更新後舊變數也跟著變（自檢因此誤判）。修法：一律回 `Object.assign({}, item)`。

## 已知限制

- 圖片在示範模式只存本機暫存路徑（換裝置消失）；真後端要等 W-8 的 COS 簽名直傳
- 認領目前是「申請即改狀態」，尚未有作者審批流程（後端 `/items/:id/claims` 審批在 W-8）
- 分頁用 mock 的 slice 模擬，真實後端由 API 分頁
