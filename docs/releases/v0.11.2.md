# v0.11.2 — 清掉 Skyline 警告與訪客的 401 噪音（2026-10-23）

開發者工具 console 之前有 3 條噪音，逐條處理：

| Console 訊息 | 判斷 | 處理 |
|---|---|---|
| `[skyline wxss warning] Unsupported Property: -webkit-font-smoothing`（`styles/tokens.wxss:77`） | Skyline 不支援（那是 iOS Safari 的屬性，Skyline 自己會抗鋸齒） | 移除 |
| `Unsupported Property: text-transform: none`（`tokens.wxss:87`） | 本來就是預設值，而且 Skyline 不認 | 移除 |
| `GET /api/v1/auth/me 401 (Unauthorized)` | **預期行為**（訪客沒有 token），但每次開首頁都在 console 留一條紅色很干擾 | `data.me()` 在沒有 token 時直接回 `null`，不再白打一次請求 |

另外：刪掉沒被任何頁面引用的 `components/navigation-bar/`（初始模板殘留，且用了 `-webkit-mask`，Skyline 也不認）。

## 仍需在後台做的一件事（我做不到）

Console 那條「Skyline 渲染模式在 2.29.2 及以上基礎庫支持，當前小程序未設置線上最低基礎庫版本」：
要到 mp.weixin.qq.com → 設置 → 基本設置 → **基礎庫最低版本設為 2.29.2 或以上**。
不設的話，低版本微信客戶端會用 WebView 渲染，Skyline 的佈局與動效會走另一條路徑（我們的頁面仍可顯示，但接近「兩套渲染都要顧」）。
