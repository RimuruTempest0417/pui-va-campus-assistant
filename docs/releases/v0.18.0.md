# v0.18.0 — 雲開發代理（免備案上線路線）v0.18.0

## 背景

正式版小程序只能請求**已 ICP 備案**的域名，`*.vercel.app` 無法備案。
老師提到教育版限制較少、可用雲開發 —— 實測確認：**測試號不能使用雲服務**（`-601059`），所以這條路要等教育版 appid。

## 這版做了什麼

| 檔案 | 內容 |
|---|---|
| `cloudfunctions/apiProxy/index.js` | 雲函數：白名單 `/api/v1/`、只允許四種方法、轉發 JWT、15s 逾時、統一錯誤 |
| `cloudfunctions/apiProxy/package.json` | 零依賴（純 `https`） |
| `config/config.js` | `TRANSPORT: 'https' \| 'cloud'`、`CLOUD_FUNCTION`、`CLOUD_ENV` |
| `utils/request.js` | 新增 `onceCloud()`，錯誤碼與 https 通道一致 |
| `scripts/use-appid.mjs` ＋ `config/appids.json` | 同一資料夾切換 appid（測試號 ↔ 教育版） |
| `docs/雲開發-代理方案.md` | 為什麼、怎麼切、限制 |

## 驗證

本機直接呼叫雲函數 `main`（打真實 Vercel API）：

```
GET  /api/v1/notices?limit=1      → 200「颱風期間停課安排」
POST /api/v1/admin/login          → 200 SUPER_ADMIN
GET  /admin/users（白名單外）       → 400 BAD_PATH
GET  /api/v1/admin/users（帶 JWT）  → 200 三個帳號
```

`node scripts/check-project.mjs`：16 頁 0 警告。
