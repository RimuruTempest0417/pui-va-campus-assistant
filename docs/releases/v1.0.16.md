# 前端 v1.0.16（登入頁像入口、舊版會被擋）

**日期**：2026-11-19｜**後端 v1.0.16｜教育版 1.0.16**

## ① 登入頁＝開場頁

- 上方多一行「**澳門培華中學**」，標題下兩行說明：「用家校通帳號登入即可使用」「查課表、功課、成績、午餐與校園公告都在裡面」。
- 預設停在「**家校通**」分頁（學生與家長手上只有家校通帳號；老師要進後台就切「校內帳號」）。

## ② 版本太舊擋下來

- `utils/version-check.js`：開機打 `GET /app/version`，`config.VERSION < minClient` 就跳 modal（只有「重新載入」，不給「稍後」）。
- 同時接 `wx.getUpdateManager()`：微信下載好新 bundle 時問一次「立即重啟」。
- 抓不到後端就靜默跳過 —— 版本檢查不會變成新的「連不上就進不去」。

## ③ 使用說明

加一則「為什麼有時會叫我重新載入？」，解釋新版與舊版畫面不一致的情況。
