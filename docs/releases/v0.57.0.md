# v0.57.0 — 去 AI 味（第三階段）：列表改成 inset grouped（2026-10-25）

## 問題

失物列表與活動列表原本是**每一個項目一張卡**（各自圓角、各自間距）。十筆資料就是十張卡，這是「卡片堆疊感」最直接的來源，也是 iOS 原生 App 幾乎不會做的事。

## 改法

整份列表變成**一張卡**，項目之間用 1rpx 髮絲線分隔，最後一列不收邊（`ui-card--last`），容器 `overflow: hidden` 讓首尾列自然貼齊圓角。

```wxss
.ui-list { background: var(--pv-surface); border-radius: var(--pv-r-lg); overflow: hidden; }
.ui-list .ui-card--row { margin: 0; border-radius: 0; background: transparent; box-shadow: none; border-bottom: 1rpx solid var(--pv-sep); }
.ui-list .ui-card--last { border-bottom: 0; }
```

按壓回饋、縮圖、標籤、名額進度條全部保留，只改「容器關係」。
