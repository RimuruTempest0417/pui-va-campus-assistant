# v0.82.0 — 用家校通帳號就能登入（不用微信授權、不用等管理員開帳號）

## 為什麼

在這之前，第一次打開小程序只有兩條路：微信一鍵登入，或等管理員替你開帳號並設密碼。
同學第一次打開，最常問的是「我沒有帳號要怎麼進去？」——但**每個人本來就有一組家校通帳號**，
那組帳密就是「我是培華學生」最直接的證明。這一版把它接成第三條路。

## 改了什麼

| 檔案 | 內容 |

後端對應版本 **v0.41.0**（`POST /auth/school`）：先向家校通驗證，通過才發 JWT；
使用者 `openid = sc:<帳號>`，已存在就直接登入且**不改角色**，不存在才建立 STUDENT；
密碼不落庫、不寫 `SchoolLink`；5 次失敗鎖 15 分鐘；家校通掛掉回 503 並提示「可改用校內帳號」。

## 三個設計取捨

1. **第一次登入一定落在 STUDENT**：系統只憑「家校通驗得過」，無從知道你是家長還是老師。
   要自動猜就會有人看到別人家孩子的資料，所以角色一律由後台指派。
2. **登入不等於連結**：這張 token 只證明「你是誰」。要同步成績才另外按「連結家校通」，
   那時才用 AES-256-GCM 加密保存帳密 —— 兩件事混在一起，等於每個登入過的人都被存了一份密碼。
3. **失敗文案分兩種**：密碼錯＝「家校通帳號或密碼不正確」（帳號不存在也回同一句，防探測）；
   學校站掛掉＝「學校系統暫時連不上，可改用校內帳號」。後者若講成「密碼錯」，使用者會一直重打密碼。

## 未驗到的

- 登入頁新 chip 的**按壓手感**只能用手機／模擬器親手點（自動化在 Skyline 下收不到 touchstart）。
- 家校通**真的**驗證一次沒有在自動化裡跑（e2e 一律用假 fetch），實際登入要等使用者用自己的帳號試。
