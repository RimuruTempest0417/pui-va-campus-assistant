# v0.10.0 — 預設連真後端 ＋ 交付包（W-12，2026-10-23）

## 1. 資料來源預設改成真 API

`config/config.js`：`DEMO_MODE` 由 `'auto'` 改為 **`'off'`**，`API_BASE_URL` 指向 `http://127.0.0.1:3100/api/v1`。

原本 `'auto'` + 空 `API_BASE_URL` 的結果是：**每次重新編譯／刷新都退回示範資料**，看到的不一定是真的。
現在連不上後端就是連不上，首頁會顯示失敗與重試，不會偷偷換資料。

## 2. 離線示範變成「開關」而不是「預設」

- `services/data.js` 新增 `setForceDemo(on)` / `forceDemoOn()`，開關存在 storage（`pv_force_demo`）
- 「開發自檢頁」加一個 switch：**離線示範模式**（關掉立刻回真 API，不用改程式碼、不用重新編譯）
- 首頁底部新增「資料來源」入口（可直接點進自檢頁）——老師拿到包也找得到

## 3. 未登入（訪客）也能看

首頁與詳情頁的 `data.me()` 改為容錯（`catch(() => null)`）：未登入時 401 不再讓整頁失敗，
四個模組的讀取類內容照常顯示，只有寫入操作提示「請先登入」。

## 4. 自檢頁修正（原本是壞的）

- `data.signup('e2')` 方法不存在 → 改用 `signupEvent`
- 「滿額轉候補」還在期待舊的 `EVENT_FULL` 錯誤 → 改成驗證 `WAITLIST` + 候補順位（W-5 改的語意）
- 未登入時只跑讀取檢查，寫入類標示「略過（需登入）」

## 5. 交付包（W-12）

- `scripts/package.mjs`：`node scripts/package.mjs` → `dist/pui-va-campus-assistant-vX.Y.Z.zip`
- 自動排除 `.git` / `node_modules` / `docs` / `.github` / `project.private.config.json`
- `docs/交付給老師.md` 會複製成包內 `使用說明.md`（五步 + 四模組操作路徑 + 常見問題）
- 打包後自我檢查：四個模組頁面＋說明檔必須存在，否則 exit 1
