# v0.27.0 — 校曆接上 iCloud 校曆表（自動更新）（2026-10-24）

## 需求

使用者把自己的 iCloud 校曆「發布」成 `webcal://…` 連結，希望小程序校曆**自動跟著更新**，不用每次手動加。

## 做法

| 層 | 內容 |
|---|---|
| 後端（v0.13.0） | `GET /api/v1/calendar/external?from&to`：抓 ICS、解析（行折疊／`TZID`／`VALUE=DATE`／UTC）、展開 `RRULE`（DAILY／WEEKLY＋BYDAY＋UNTIL／COUNT）、記憶體快取 10 分鐘、`webcal://` 自動改 `https://`、失敗回空陣列不影響站內資料 |
| 前端 | 校曆頁把外部場次併進同一份分組（`utils/calendar.js` 新增 `mergeExternal`）；外部場次標籤「**校曆表**」、圓點用琥珀色（與站內活動的紫、公告的灰區分） |
| 資料層 | `api.externalCalendar()`、`mock.externalCalendar()`（示範模式回空）、`data.externalCalendar()`；自檢新增 2 項：合併成功、圓點會畫出來 |
| 設定 | 後端 `SCHOOL_ICS_URL`（已設在本機 `.env` 與 Vercel production 環境變數） |


## 這份校曆的實況

- 來源共 **97 筆事件**（2024-03-08 → 2026-07-16，其中 28 筆有 RRULE），展開後 2024–2027 共 **111 場**
- 因為最後一筆是 2026-07-16，**「今天以後 120 天」目前是空的**；在校曆頁切到 2026 年 1–7 月就看得到
- 之後在 iCloud 新增／修改行程，最多 10 分鐘後（或 `refresh=1`）就會反映到小程序

## 注意

- 只讀：小程序不會回寫你的日曆。
- iCloud「發布」連結是**公開可讀**的（拿到連結的人都看得到），私人行程不要放同一個日曆。
