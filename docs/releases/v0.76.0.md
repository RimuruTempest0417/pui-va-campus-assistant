# v0.76.0 — 全校搜尋（W-59）

前端對應版本 **v0.76.0**；後端 **v0.37.0**。

## 為什麼

四個模組、25 個頁面，但**沒有任何地方能用關鍵字找東西**。
學生記得的是「上星期那則關於圖書館的公告」，不會記得它在哪一頁第幾則 —— 只能一頁一頁翻，還要記得先去哪個模組翻。
這一版補上這件事，而且刻意**不讓前端自己篩**：每個模組的「看得到」規則都不一樣（公告有預約發佈與過期、活動與失物有軟刪除、失物有不對外回傳的聯絡方式），
抄到前端就是第二份真相，漏掉的那一份就是資料外洩。

## 這一版做了什麼

| 位置 | 改動 |
|---|---|
| `pages/search/`（新，4 檔） | 搜尋頁：輸入框（打字去抖 280ms）→ 分組結果 → 點列跳詳情；未輸入時顯示提示與**最近 5 筆**（存在本機 `pv_recent_searches`，不上傳）；載入／空／失敗三態齊全 |
| `pages/index/index.{wxml,js,wxss}` | 右上角多一顆放大鏡（鈴鐺左邊），按下回饋用 `bindtouchstart/end` 自設 `pressed`（不用 `hover-class`，Skyline 下它不可靠） |
| `services/api.js` | `search(q)` → `GET /search` |
| `services/mock.js` | `search()` 示範層實作，規則刻意與後端一致（過期公告不算、標題命中排前、空白關鍵字不打請求） |
| `services/data.js` | `search` 走唯一入口（`data↔api↔mock` 三方對齊） |

| `scripts/check-data-layer.mjs` | +6 條：跨類別有結果／標題命中排最前／過期公告不出現／只命中過期時回空／空白關鍵字不打後端／真 API 走 `/search` |
| `docs/openapi.yaml` | `GET /search` ＋ `SearchHit` schema（119 路徑／138 操作，parity 雙向 0） |
| `utils/i18n-phrases.js` | 重建繁→簡對照表（999 組） |

## 三個設計取捨

| 決定 | 為什麼 |
|---|---|
| 徽章文字「用的時候才 `i18n.pick`」，不宣告成常數 | 模組層常數會停在 App 啟動時的語言：在設定頁切成簡體再回來，分組標題是簡體、徽章還是繁體 |
| 最近搜尋放 `wx.setStorageSync`，不做後端「熱門搜尋」 | 熱門搜尋要另一張表、要清理、還要知道「誰搜了什麼」；這一版不需要那個隱私成本 |
| 搜尋頁不進四宮格 | 首屏可點元素已經 6 個，放大鏡放在頂部列不佔宮格，也不會讓「四個模組」變成五個 |

## 已知缺口（下一版可做）

- **不搜菜單**：菜單是「這週」的資料，命中後還要判斷哪一週，容易誤導；菜單頁本身已有當週全文。
- **不做模糊／拼音比對**：這一版是精確包含，先確認學生真的會用再談權重（失物匹配的教訓：亂加權重會推出不相關的東西）。
- **搜尋結果沒有「載入更多」**：每類最多 5 筆，超過就只能縮小關鍵字。真有需要時再加分頁（後端 `limit` 已支援到 20）。
