## 已知限制（誠實寫）

- 名額是**活動層級**共用，不是每組各自有名額；要做「各組限額」得再加 `groupCapacity`，等真的有需求。
- 分組目前只能建立時設定，**修改活動的組別**還沒做（避免已有報名的組別被改名後對不上）。
- 這版做 UI 驗證時開發者工具的自動化接口沒有回應（重開專案與整個工具都試過），
  所以「組別 chips 的畫面」是用結構檢查＋資料層＋後端 e2e 三層守住，**視覺確認留待自動化恢復後補**。
