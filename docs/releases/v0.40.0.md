# v0.40.0 — 兩步驗證搬到網頁後台、新增使用說明頁（2026-10-24）

## 1. 兩步驗證移到網頁（使用者指定）

小程序裡的「安全」區塊只保留**狀態顯示**（已開啟／未開啟）＋「複製設定網址」，
真正的開啟／關閉流程搬到網頁：**`/admin/2fa-ui`**（獨立一頁，不塞進 admin.html）。

| 網頁流程 | 說明 |
|---|---|
| 產生密鑰 | 顯示密鑰與 `otpauth://` 連結，**同時先列出 8 組備用碼** |
| 輸入 6 位碼 | 確認後才真正開啟 |
| 備用碼 | 三欄卡片＋「複製全部／我已保存」 |
| 關閉 | 要再輸入一次登入密碼 |

**後端也一併修**：`POST /admin/2fa/enable` 現在會**回傳備用碼**（原本只回 `{enabled:true}`），
所以客戶端就算清了狀態也拿得到碼 —— 這是「備用碼看不到」的根治點，不是只在 UI 補一塊。

## 2. 使用說明頁（W-25）

`pages/help`：依身分分四個分頁（學生／家長／老師／資訊管理員），每個身分 3–6 條 Q&A，
入口在設定頁「使用說明」。內容涵蓋失物認領、候補規則、簽到、審批、帳號管理、錯誤記錄等實際操作。
