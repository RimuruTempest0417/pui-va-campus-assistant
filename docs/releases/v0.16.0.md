# v0.16.0 — 帳號管理完整化（2026-10-23）

## 使用者分頁現在能做

| 功能 | 說明 |
|---|---|
| 新增帳號 | 帳號／密碼／顯示名稱＋角色，建立後可立刻在後台登入 |
| 搜尋 | 依帳號或名稱 |
| 角色篩選 | 全部／學生／老師／資訊管理員 |
| 等級顯示 | 每列顯示 `Lv1–Lv4`，並標示「可管理／只讀」 |
| 角色調整 | 只顯示**低於自己等級**的角色按鈕（例如管理員看不到「設為資訊管理員」） |
| 重設密碼 | 彈窗輸入新密碼（≥8 位） |
| 停用／恢復 | 停用後該帳號登入後台回 403 |
| 刪除 | 二次確認；連帶清掉該使用者的認領／報名／評分／已讀／訂閱／檢舉，失物改為下架 |

規則與 competition-manager 一致：**只能管比自己低階的帳號、不能改自己、不能動最高權限**。
