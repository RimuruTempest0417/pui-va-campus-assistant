# v0.95.0 — 功課清單：今天有什麼要交，交了就打勾（2026-11-06）

> 前端 v0.95.0／後端 v0.52.0；兩張新表 `homework`、`homework_done`（1 支 migration，第 32 支）
> 任務：W-76（P1）

## 為什麼

課表回答「下一節在哪間課室」、測驗倒數回答「還有多久考」，但學生每天真正要做的事是**「今天有哪幾樣要交」**——
這件事目前仍在系統外：黑板角落、班群訊息、抄在手心。把它補上，學生的每日流程才閉環：
課表 → 功課 → 測驗 → 圖書館 → 請假。

## 設計取捨

- **按班級存，不按人名展開**：培華的作業是「這一班明天交」，名單會隨插班轉班變動；按班級存不必每次派作業就展開全班，也不必回頭改已派的功課。
- **`dueAt` 存時間不是日期**：同一科常常是「明早第一節前交」，只有日期會讓當天全部算逾期。前端只給日期時，後端視為當天 23:59（澳門時間）。
- **逾期由後端算**：手機時間設錯也不會標錯。
- **收回是軟刪除**：派錯了要能收回，但紀錄留著（審計與回收桶靠它），前台看不到、DB 仍在。
- **不做的事**：家長端看子女功課（要再接 `parent_links`，屬下一版）、功課附件、完成率統計。
