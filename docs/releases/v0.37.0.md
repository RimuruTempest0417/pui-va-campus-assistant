# v0.37.0 — 簡繁第二階段：JS 產生的字也真的會切換（W-20b）（2026-10-24）

## 問題

v0.35.0 把 19 頁 WXML 的 311 條字串抽成 `{{L.kNN}}` 之後，畫面標題會切換了，
但**由 JS 產生的字沒有**：toast（`已轉正 3 人`）、底部主按鈕文案（`立即報名`／`排入候補`）、
後台十二個分頁標籤、統計摘要句、錯誤訊息（`請先登入`）——
切到簡體後這些全部還是繁體，使用者看到的是「半繁半簡」。

而且它**不會有任何錯誤**：`pick()` 沒包到就是原樣回傳，編譯過、console 乾淨、畫面也照樣渲染。

## 做法

1. **`scripts/i18n-wrap-js.mjs`（新）**：掃 `pages/**/*.js`，把沒包 `i18n.pick()` 的中文字面值包起來；
   跳過註解、`console.*` 的開發訊息、已包過的字串；缺 `require('…/utils/i18n')` 的檔案自動補（深度按檔案位置算）。
   本輪改 **18 個檔案、316 條**（後台 `pages/admin/index` 一個檔就 148 條）。
2. **`scripts/build-i18n-phrases.py`（新）**：收集所有 `pick()` 字面值 ＋ `utils/errors.js` 的 `TEXT` 表，
   用 opencc 產生繁→簡對照，重建 `utils/i18n-phrases.js`（288 → **532 組**）。
   轉換器從 `t2s` 換成 **`tw2sp`**（含詞組轉換）：`請先登入 → 请先登录`、`批次匯入 → 批量导入`，
   `t2s` 只換單字，會留下「请先登入」這種半套結果。
3. **共用工具改成「取用時才翻」**：`utils/errors.js`、`utils/item.js`、`utils/reportSheet.js`
   的文案表保持繁體原文，在回傳給頁面那一刻才 `pick()`。
   理由：語言可以在 session 中途切換，模組載入時翻會把第一次的語言鎖死。
4. **兩支新守門**（都進 `verify-all` 與 CI）：
   - `check-project.mjs` **第 15／16 項**：頁面 JS 不得有沒包 `pick()` 的中文字面值；每一條 `pick()` 都必須在對照表裡（否則靜默回傳繁體）。
   - **`scripts/check-i18n.mjs`（新）**：簡體模式下 `pick()` 抽樣真的變（7 組硬斷言）＋對照表不得殘留繁體字＋WXML 用到的每一條 `L.*` 都必須由該頁 `labels()` 提供。
   兩支都用「故意改壞」驗過：注入 `'沒包裝的中文'` 與 `pick('這條對照表沒有')` → 各回 1 個錯誤，還原後 0 錯。

## 守門一上線就抓到的三個真 bug

1. **公告列表的三個字是空的**：`pages/notices/list` 在 `onLoad` 設了 `L.list／L.calendar／L.allRead`（來自 DICT），
   `onShow` 又整個覆蓋成 `labels()` → 三個鍵消失。分段控制與「全部標為已讀」實際渲染成空字串，
   而畫面上只是「一顆沒有字的膠囊」，看起來像樣式問題。
2. **切語言後使用者站的那一頁不換字**：設定頁的 `localeOptions` 寫在 `data` 初始值（模組載入時算一次），
   切換後自己那頁不重算；回首頁時模組名稱（`失物招領` 等）也停在舊語言（它們是 `refresh()` 才算的，
   `onShow` 只更新 `L`）。修法：設定頁抽出 `options()` 在 `onShow`／切換後重算；首頁 `onShow` 比對 `i18n.locale()` 變了就整頁重抓。
3. **`check-states` 漂移**：`pages/settings` 從 v0.34.0 就沒登記進 REQUIRE 表，三態守門一直在紅（19 頁 vs 20 頁）。

## 設計取捨

- **逐段包 `pick()`，不引入樣板函式**：`i18n.pick('已轉正 ') + n + i18n.pick(' 人')` 讀起來囉唆，
  但它和 WXML 那邊 `kNN: i18n.pick('…')` 的做法一致，而且字串是「原文即 key」——不需要為每一句發明 key，
  翻譯表由 opencc 自動產生，新增文案不用改兩份。
- **不加「頁面層自動翻譯」**：遞迴翻 `setData` 的所有字串會連**公告標題、使用者暱稱**一起翻掉，
  那是內容不是介面。介面字串必須顯式包 `pick()`。
- **`utils/errors.js` 的錯誤文案在 Node 自檢裡仍回繁體**（沒有 storage 時 locale 預設 zh-Hant），
  所以既有的 65 項資料層檢查數字不變。

## 沒驗到的

- 開發者工具這一輪 `loginExpired: true`（`open_project_window` 直接回「需要重新登录」／`APPID_ERROR`），
  所以**沒有**親眼在模擬器看簡體畫面，也**沒有**上傳體驗版。畫面確認要等登入恢復（掃碼）後補。
- WXML 裡仍有 **133 條**寫死中文（42 條文字節點 ＋ 91 條 `{{}}` 三元運算裡的字面值），
  例如 `{{item.status === 'CONFIRMED' ? '正取' : '候補'}}`。它們藏在 mustache 裡，掃描器原本會跳過，
  要逐頁改成 `L.*` —— 已列為 **W-20c**（下一項）。
