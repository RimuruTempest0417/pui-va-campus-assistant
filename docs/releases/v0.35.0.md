# v0.35.0 — W-20 簡繁覆蓋（介面文字全面雙語）（2026-10-24）

## 做了什麼

以前只有 5 頁接了 i18n，其餘頁面的文字寫死在 WXML 裡，切簡體只會看到一半繁體。

| 層 | 數量 | 做法 |
|---|---|---|
| WXML 文字與屬性 | **311 條、19 頁** | 全部抽成 `{{L.kNN}}`，每個 key 由 `i18n.pick('繁體原文')` 產生 |
| 共用工具（日期／週次／活動／校曆／公告／角色） | 6 個檔 | `週`、`剛剛`、`分鐘前`、`本週`、`已報名`、`不限名額`、`資訊管理員`… 全部走 `i18n.pick()` |
| 繁→簡對照 | **288 組** | `utils/i18n-phrases.js` 由 opencc `t2s` 自動產生，不再手寫翻譯 |

做法上刻意用「**繁體原文就是 key**」：翻錯或多翻都看得出來，而且新增文案只要包 `i18n.pick()`，
執行 `python3 /tmp/build_phrases.py`（或 migrate 腳本）就會補上對照，不需要人工維護字典。

## 配套工具

- `scripts/i18n-scan.mjs`：掃出還寫死中文的地方（WXML 文字／placeholder／title／desc／text）
- `scripts/i18n-migrate.py`：抽字串 → 改 WXML → 產生 `labels()` → 產對照表
- 守門 `check-project.mjs` 新增：**WXML 用到的 `{{L.x}}` 必須真的有人提供**（畫面會空白的那種錯）
