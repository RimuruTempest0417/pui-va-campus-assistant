# v0.33.3 — 登入頁不再「一邊登入一邊登出」（2026-10-24）

## 你回報的現象

登入成功後，頁面上還是看得到帳號／密碼／登入按鈕，下面又出現「目前身分＋登出」。
**是 bug**：登入頁同時渲染了兩種狀態（表單 + 已登入），而且沒有做狀態互斥。

## 修法

登入頁改成兩個互斥狀態：

| 狀態 | 畫面 |
|---|---|
| 未登入 | 帳號／密碼＋登入按鈕（原有行為） |
| 已登入 | 名稱＋角色（中文）、**回首頁**、切換帳號、登出 —— **不再顯示登入表單** |

- 判斷依據：storage 有 token **且** 有 role 才算已登入（只有其一時視為未登入，避免半登入狀態）
- 「切換帳號」把狀態切回表單並清空帳密
- 「回首頁」在只有這一頁時走 `reLaunch`，其餘走 `navigateBack`（避免點了沒反應）

## 順手：角色名稱中文化

原本直接顯示 `SUPER_ADMIN` 這種內部代碼。新增 `utils/role.js`：

| 代碼 | 顯示 |
|---|---|
| `SUPER_ADMIN` | 最高權限 |
| `ADMIN` | 資訊管理員 |
| `STAFF` | 校內職員 |
| `TEACHER` | 老師 |
| `PARENT` | 家長 |
| `STUDENT` | 學生 |
| `GUEST` | 訪客 |
