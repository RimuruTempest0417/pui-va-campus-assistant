# v0.67.0 — 使用說明只顯示「自己這級或更低」；學生／家長可用帳密登入

## 1. 使用說明不再顯示更高權限的內容

使用者要求：只顯示當前角色或以下權限的說明。

以角色等級過濾（訪客 0 ＜ 學生／家長 1 ＜ 老師／校內職員 2 ＜ 資訊管理員 3 ＜ 最高權限 4）：

| 你的身分 | 看到的分頁 |
|---|---|
| 未登入 | 訪客 |
| 學生 | 訪客、學生、家長 |
| 家長 | 訪客、學生、家長 |
| 老師／校內職員 | ＋老師、校內職員 |
| 資訊管理員 | ＋資訊管理員 |
| 最高權限 | 全部 |

順手修掉一個顯示 bug：Q&A 清單原本用 `sections[active]` 這種動態索引渲染，Skyline 下會落回第一組
（所以切到「訪客」看到的是別人的內容）。現在改由 JS 算好 `list` 陣列再渲染。

## 2. 學生／家長可以用帳號密碼登入

之前登入頁只認教職員帳號（後端 `/admin/login` 的閘門是「至少一項後台能力」）。
後端新增 `POST /auth/password`（v0.30.2），登入頁改走這支：
學生、家長、職員、管理員都能用帳號密碼登入，登入後照樣由首頁的入口決定進不進後台。
