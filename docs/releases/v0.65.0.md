## 設計取捨

- **只修失敗態，不改家校通的資料流程**：額度留給後面幾輪；這一版目標是「守門回到全綠」，不是重做頁面。
- **`loadAll()` 的 catch 也改成失敗卡**（原本只彈 toast）：toast 消失後畫面停在「還沒有成績資料」，那句話在讀取失敗時是錯的敘述 —— 空狀態與失敗態不能共用一句文案。
- **統計卡只改顏色，不動版面**：仍是 3×2 的六格。改中性後「本週概況」（白卡＋紫數字）才是視覺主角，「累計」退成參考值，兩者形成層級而不是兩片色塊。
- **`--pv-brand-soft`／`--pv-brand-strong` 沒有刪**：`pv-tag--danger`、緊急公告紅條、活動警示、菜單「我也喜歡」都還在用 soft；strong 留給緊急與破壞性文字。刪 token 會讓那些地方靜默退回繼承色。

## 未做／未驗

- **淺色／深色各截一張對照（W-49 的驗收條件）沒做**：本輪沒有開開發者工具（`check-console` 需要工具開著專案，本輪未跑），配色改動只經守門與程式碼審閱；觀感要等下一輪開模擬器補量測，或由使用者直接看。
- 家校通失敗態的實際畫面（網路斷線時是否真的出現失敗卡）未在模擬器上打斷網測試，只驗了模板與程式分支。
- 後台分頁列仍用 `--pv-brand`（紅）當選中態，與「紅色不參與一般互動」這條規範有出入 —— 屬於後台外殼的既定設計，本版沒有動，留給使用者決定。
