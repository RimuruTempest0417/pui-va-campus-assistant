# v0.72.0 — 活動回饋統計（W-55）

後端對應版本 **v0.33.0**。

## 做什麼

回饋表早就做完了（W-31），但那是**給學生用的**：評完星、寫完意見就沒有下文。
老師想知道「這次活動辦得怎樣」，只能一則一則點進活動詳情翻留言 —— 等於沒有統計。

這一版在後台的活動統計卡上多一段「活動回饋」：

- **一行看完**：`回饋 3 份 · 平均 4.0 星 · 回覆率 60%（回饋 3 ÷ 出席 5）`
- **星等分佈**：`5★ 1　4★ 1　3★ 1　2★ 0　1★ 0`
- **最近 3 條留言**（小程序）／**5 條**（網頁），帶暱稱與時間
- **網頁後台同一套**：`/admin` → 「報名名單」分頁的「活動回饋」區塊，
  切換上面的活動選單就自動重讀（Gary 的驗收方式就是在網頁點一輪）

沒有回饋時顯示「**還沒有人回饋**」，不是「0 星」—— 這是刻意的：0 星會被讀成
「大家都給 0 分」，意思剛好相反。

## 三條規則

1. **0 份回饋 → 平均與回覆率都是「—」**（後端回 `null`）。不是 0、
   也不是 0%，因為那兩個數字都會讓人以為「有資料但很差」。
2. **回覆率的分母是「有出席的人」**：沒來的人不該被算成「不願回饋」。
   一個人都沒簽到時顯示「回覆率 —（還沒有人簽到）」。
3. **紙卡不新增**：回饋統計放在**既有的報名統計卡裡面**，用一條髮絲線隔開。
   另開一張卡會讓後台活動分頁變成「每塊都包卡」。
