# v0.55.0 — 去 AI 味：拿掉全站 emoji 圖標（2026-10-25）

使用者回饋：「UI 有點 AI 味太重」。實測找到了最大來源：**34 種 emoji 當圖標、散在 20 個頁面**（⚠ 17 次、🍽 5、🔍 5、🎟 3、🕳 3…）。
彩色 emoji 每台手機長得都不一樣、粗細不統一，是最容易讓人看出「臨時拼的」的地方。

## 這次改了什麼

| 位置 | 之前 | 之後 |
|---|---|---|
| 空狀態（17 個檔案） | emoji（📭／🕳／🎟／📅／🎪／👪／✅／🔐…） | `pv-empty` 統一的**線性圓環＋刻點標記**；警示類自動轉淡紅（`tone` 屬性，由 icon 值自動判斷，舊頁面不用改） |
| 首頁通知鈴鐺 | 🔔 emoji | CSS 畫的**線性鈴形**（鐘身＋鐘舌），跟其他圖標同一粗細 |
| 失物搜尋框 | 🔍 emoji | CSS **放大鏡**（圓環＋斜柄） |
| 失物縮圖佔位 | 🔍／📦 emoji | **「失」／「拾」單字**徽章，資訊量比 emoji 高 |
| 菜式詳情標題 | 🍽 emoji | **菜名首字**徽章（例「叉」燒飯） |
| 圓角 | `--pv-r-lg: 28rpx`（14pt） | **20rpx**（10pt）—— 大圓角是「可愛模板」的味道 |

刻意**保留**的符號（功能性、非裝飾）：★ 評分、✓ 簽到完成、✕ 清除、☑／☐ 勾選。

**紫色 `#6D3FC4` 不動**：使用者確認「老師和學校很喜歡這個顏色」，它是品牌互動色，不是 AI 味的來源。
