# v0.4.0 — 首頁（2026-10-22）

## 新增

- **首頁**（`pages/index`，取代原本的模板殼）：
  - 自訂導航列（安全區 + 學校名稱 + 示範資料標籤 + 頭像）
  - 大字問候（依時段自動早安／午安／晚安）＋ 日期、星期、班級
  - **緊急公告橫幅**：只在真的有 `kind === 'URGENT'` 時出現，培華紅實底（全站唯一用紅色的地方）
  - **四宮格入口**：失物招領／活動與社團／午餐與小賣部／公告與提示，各自帶即時數量
  - **今日午餐卡**：用本地日期比對當天菜單（不用 `toISOString`，避免被時區推到前一天），顯示評分數與點讚數；下方小賣部與價格
  - 下拉刷新、骨架屏、失敗重試、資料更新時間
- `utils/date.js`：本地日期 key、星期、時段問候、相對時間、時鐘
- **自檢頁改為前後都重置示範資料**，避免測試資料殘留在交付狀態
