# v0.33.0 — 檢舉入口擴到公告與活動、錯誤記錄納入每輪流程（2026-10-25）

## 一、檢舉入口（W-24）

失物詳情在 v0.29.0 有了檢舉入口，但公告與活動同樣是使用者產生內容，之前只能靠失物檢舉。

| 頁面 | 入口位置 |
|---|---|
| 公告詳情 | 內容卡下方「檢舉這則公告」文字連結 |
| 活動詳情 | 底部操作列左側「檢舉」小字（不搶主按鈕） |

三者共用同一支 `utils/reportSheet.js`（失物詳情也改用它，少一份重複程式）：

```js
Page({
  ...reportSheet.methods('NOTICE', function () { return this.data.notice && this.data.notice.id; }),
  data: { ...reportSheet.data(), /* … */ },
})
```

`targetType` 分別是 `ITEM`／`NOTICE`／`EVENT`，後端 `POST /reports` 早已支援三種。
