# v0.39.3 — 備用碼啟用後看不到（2026-10-24）

## 問題

使用者回報：開啟兩步驗證成功後，**8 組備用碼完全沒有顯示**。

## 根因

備用碼是 `POST /admin/2fa/begin` 產生並回傳的，但前端在 `twoFactorEnable()` 成功後
把 `tfaSetup` 整包清成 `null`（畫面上那個區塊就消失了），於是碼從來沒被看到 ——
使用者等於開了一個「遺失就鎖死」的保護。

## 修法

1. 啟用成功時**先把 `tfaSetup.backupCodes` 留在 `tfaBackupCodes`**，再清 `tfaSetup`
2. 安全卡片新增備用碼區塊：8 組以三欄排列、附提示「只顯示這一次，請抄下來或複製收好；每組只能用一次」
3. 兩顆動作：**複製全部**（複製到剪貼簿，一行一組）、**我已保存**（收起區塊）
4. 之後只顯示「已開啟 · 備用碼 N 組」——備用碼本身不再顯示（用過就作廢，後端也只回剩餘數量）

## 驗證

```
後端（已有 e2e）：begin 回 8 組、用掉一組後 backupCodesLeft = 7、同一組再用回 401
實機（注入 8 組測試資料）：三欄排列正常、複製全部／我已保存 可點、深色與簡體下都可讀
check-project 20 頁 0 警告｜資料層 65/65｜check-docs 0 錯 0 警
```
