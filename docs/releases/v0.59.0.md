# v0.59.0 — 區段標題與數字排版統一（W-46）

> 2026-10-25｜前端 v0.59.0｜後端維持 v0.28.0（本版沒有後端改動）

## 做什麼

**全站的「小標題」與「會被拿來比大小的數字」收成各一份規格。**

1. **區段標題（13pt 次級灰 ＋ 0.5rpx 字距）**
   - 新增 token `--pv-ls-section: 0.5rpx`（13pt 下約 0.02em），`styles/tokens.wxss` 的 `.pv-group-title`（頁面級，10+ 頁在用）與 `styles/ui.wxss` 的 `.ui-section`（卡片內，無上下 padding）都吃這一個值。
   - 收掉四份同規格但不一致的重複定義：後台 `.ov-section`、菜單 `.sec-title`、後台 `.field__label`、登入頁 `.field__label` —— 前兩個改成 `ui-section` 只留 margin，後兩個直接用 `.ui-field__label`（16 處＋3 處 WXML 一併換掉）。
   - 顏色用 `--pv-label-2`（次級）而不是規劃書原本寫的 `--pv-label-3`：`label-3` 在淺色是 `rgba(60,60,67,0.3)`，13pt 小字對比只有 **2.6:1**，讀不清；iOS 的 section header 本來就是 secondaryLabel（`label-2` 約 **5.6:1**）。

2. **數字排版（等寬）**
   - 新增 `styles/ui.wxss` 的 `.ui-num { font-variant-numeric: tabular-nums; }`，套在：後台概況五張卡、累計六格、活動統計四格、簽到碼、活動列表名額、活動詳情名額、菜單評分、家長端兩個統計數。
   - **設計基準頁新增「數字排版」示範區**（`pages/style-guide`）：上排等寬、下排比例，同一段 `1111.50／8888.50`。

3. **新守門（`check-project.mjs` 第 20 條）**
   - `font-variant-numeric` 只准出現在 `styles/ui.wxss`（其他 wxss 出現就判錯）—— 這種屬性 Skyline 不認時是**完全靜默**的，只能靠守門防散落。
   - WXML 用到 `ui-section`／`ui-num` 的頁面，其 wxss 必須 `@import styles/ui.wxss`（漏了就變成「class 沒有樣式」，跟漏 `setData` 的 `L.*` 一樣靜默）。

## 順手修掉的三個真問題

| 問題 | 症狀 | 修法 |
|---|---|---|
| JWT 過期卻不清登入態 | 登入頁說「已登入 巡查／最高權限」，後台卻顯示「請先登入」——同一個人看到兩種身分 | `utils/request.js`：帶了 token 卻回 401 → 清 `pv_token`／`pv_user`，改回 `SESSION_EXPIRED`（`utils/errors.js` 新增文案「登入已過期，請重新登入」）。`auth: false` 的登入請求不會被誤清，所以打錯密碼不會把人踢掉 |
| `pv-navbar` 型別警告 | 每頁首次渲染 `title="{{L.k01}}"`（L 還沒 setData）→ 傳 null，DevTools 吐 `type-uncompatible`，會淹掉真警告 | 屬性改 `type: null`（任意型別），警告歸零 |
| 統計卡標籤語意重複 | 「待認領」（未認領失物）與「待審認領」（待審核的認領申請）並排，看起來像同一個數字出現兩次 | 前者改文案「未認領失物」 |

## 怎麼驗

- **`font-variant-numeric` 在 Skyline 上不生效（實測）**：`automation_element_action --action style --name font-variant-numeric` 回**空字串**（computed style 沒有這個屬性）；`#num-tab-1/2`（等寬，1111.50／8888.50）寬度 **75.9／91.7**，`#num-prop-1/2`（比例）也是 **75.9／91.7** —— 兩排完全一樣。
- **但視覺上小數點本來就對齊**：同一組字串在 Skyline 的預設字型下數字寬度一致（PingFang 的數字是等寬設計），所以「1111.50」與「8888.50」量出來都是 75.9／91.7。`.ui-num` 因此是**跨引擎的正確宣告**（教育版關鍵頁用 WebView 渲染、未來基礎庫版本會生效），不是本版畫面的視覺修正 —— 這句話要照實講，不能說「已修好對齊」。
- **登入態矛盾已用實機流程驗過**：模擬器原本有一枚過期 token（201 字元、role SUPER_ADMIN）＋ `pv_user`，`curl /auth/me` 回 401。改完重新編譯後開 `pages/admin/index` → token 長度變 **0**、`pv_user` 變 **null**、頁面自動退回 `pages/admin/login`，畫面是**登入表單**（不是「已登入」卡片）；`currentName` 空、`loggedIn: false`。
- 區段標題與表單標籤的外觀在模擬器上看過（設計基準頁、首頁、登入頁、後台概況）；四頁 console（`grep -n .`）都只有 WeChatLib 版本與 lazy code loading 兩條資訊級訊息。

## 設計取捨

- **不為了「等寬」換字型**：`font-family: monospace` 會讓整個小程序的質感變成終端機。Skyline 現況已是等寬數字，等真的有對不齊的場景再處理。
- **`.pv-group-title` 與 `.ui-section` 兩個 class 而不是合成一個**：差別只在「有沒有上下 padding」—— 頁面級標題要跟內容留呼吸距離，卡片內標題的位置由呼叫端用 `ui-mt-*` 決定。硬合成一個會讓其中一種用法到處覆寫 margin。
- **紅色的統計卡沒有動**：後台「累計」六格是 `--pv-brand-soft` 底 ＋ `--pv-brand-strong` 數字（tokens 註解寫明是「後台統計數字」用途），屬於既定設計，本版不擅自改配色。已列入規劃書 W-49 待你決定。
