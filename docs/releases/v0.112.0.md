# v0.112.0 — 首頁多一張「今日待辦」：三件事一次看完（2026-11-07）

任務：W-93（前端 v0.112.0／後端不變 v0.64.0；沒有新表、沒有 migration、沒有新端點）

## 為什麼做這一項

首頁到上一版為止已經有九條入口列：圖書館、場地、轉贈、測驗倒數、請假、課表、功課、提案、報修。
每一條的副標都寫著自己的數字（「數學 · 302（10:30）」「3 項未交」「N 張處理中」），
但學生真正想問的一句話是「**今天還有什麼沒做完**」——這個問題要沿著九條列逐條讀才拼得出來。

再加上「下一節」與「未讀通知」分散在課表頁與右上角鈴鐺，第一屏其實答不出這三件事。

## 做了什麼

### 前端（v0.112.0）

- **首頁新增一張「今日待辦」卡**（位置在緊急公告之後、四宮格之前），一張卡三行（inset grouped ＋ 1rpx 髮絲線，
  不是每項一張卡）：

  | 行 | 內容 | 點下去 |
  |---|---|---|
  | 未交功課 | `3 項未交`，有逾期時第二行寫「1 項已逾期」並轉警示色；交清了寫「都交了」 | 功課清單 |
  | 下一節 | 直接用課表頁的 `nextText`（例「數學 · 302（10:30）」）；放假日寫出**原因**（例「重陽節假期（校曆公告）」）；放學後寫「今天沒有下一節了」 | 課表 |
  | 未讀通知 | `5 則未讀`，超過 99 顯示 `99+ 則未讀`；沒有未讀寫「沒有未讀」 | 通知中心 |

- **不新增端點、不打額外的 API**：三個來源都是首頁 `refresh()` 本來就抓的回應
  （功課 `scope=todo` 的 `stats`、`timetable/today` 的 `nextText`／`dayOffReason`、`notifications` 的未讀數）。
  組裝邏輯抽成 `utils/todo.js` 的純函式 `rows()`，同一份規則可以被 Node 直接測。
- **單支失敗只降級那一行（不靜默降級）**：任何一支取不到時，那一行寫「暫時取不到」、tone 轉淡，
  其他行照常顯示；**不會**把失敗顯示成 0（那會讓人以為功課交清了），也不會讓整張卡消失。
- **訪客整張卡不顯示**（沒有功課也沒有通知）；**家長只有兩行**：子女未交功課（數字來自家長卡 summary，
  不是家長自己的班級）＋自己的未讀通知；家長帳號沒有班級，所以不出現「下一節」。
- **拿不到班級資料時寫「—」＋「還沒有班級資料」**，不是 0 項。
- 按壓回饋照 Skyline 的寫法（`bindtouchstart`／`bindtouchend` 自設 pressed，60ms 按下／180ms 放開），
  **沒有用 `hover-class`**；行高 88rpx（44pt）符合最小可點區域。
- **使用說明補 2 條 Q&A**：學生「首頁最上面那張『今日待辦』是什麼？」、家長「顯示的是誰的資料？」。

### 守門

  訪客不顯示／三行順序／單支失敗只降級那一行／沒班級給「—」而不是 0／有逾期轉警示／
  放假寫原因／放學後文案／未讀 0 與 99+／家長只有兩行且數字來自子女／

## 抓到的問題（邊做邊修）

- **`needsClass` 的判斷順序寫反了**：原本先判 `!homework.stats` 再判 `needsClass`，
  而沒有班級的帳號 `stats` 本來就是 `null` → 第一版把「還沒有班級」誤報成「暫時取不到」
  （使用者看到的是「載入失敗」而不是「請找校務處設班級」）。守門第一次跑就紅了兩項，改成先判 `needsClass`。
  這正是為什麼這類顯示邏輯要寫成純函式 ＋ 固定輸入斷言：畫面上一樣只是一行字，肉眼看不出差別。
- **`check-parent-view.cjs` 的 vm 沙盒有一份 require 白名單**：首頁多 require 一個 `utils/todo` 之後，
  那支守門直接拋 `unexpected require`（看起來像程式壞了，其實是沙盒沒跟上）。補上 stub 後順手加了兩項斷言。

## 設計取捨

- **不加第十條入口列**：首頁已經九條，再加一條只是更長；「今日待辦」的價值在**聚合**，
  所以做成卡片而不是第九＋一條列。三行共用一張卡也符合「不要每項一張卡」的方向。
- **不做一支 `/home/summary` 聚合端點**：三個數字本來就在同一輪 Promise.all 裡，
  多一支端點等於同一份資料兩個來源（改了一邊另一邊不會跟著改），而且會讓首頁從 1 個 round trip 變 2 個。
- **功課那行取不到就寫「暫時取不到」而不是「—」**：`—` 留給「這個帳號本來就沒有這項資料」（沒有班級），
  兩種狀態在畫面上必須分得出來，否則使用者無法判斷是「要去找校務處」還是「等一下再刷新」。
- **家長不顯示「下一節」**：家長帳號沒有班級，硬要顯示就得再多打一支子女課表端點；
  子女的課表在「我的子女」那頁已經有，首頁不重複。
