# v0.127.0 — W-108 校曆匯出 `.ics`（放進手機行事曆）

> 前端 v0.127.0｜後端 v0.76.0
> 日期：2026-11-08

## 這一版解決什麼

公告、活動、測驗倒數已經在校曆頁排成一條時間軸，但**只有打開小程序才看得到**。同學每天真正會瞄一眼的地方是手機內建日曆（iCloud／Google）—— 這裡缺的不是資料，是一支輸出。

匯出一份 `.ics` 之後，「下星期有甚麼」會自己出現在每天看的地方，不必再記得打開任何 App。

## 做了什麼

### 後端（v0.76.0）

- 新端點 `GET /api/v1/calendar/export.ics`（能力 `notice:read`，**訪客也拿得到**；每 IP 每分鐘 60 次）：
  - 把「今天起 N 天」的公告與活動輸出成 iCalendar 2.0：每筆一個 `VEVENT`，`UID` 用 `notice-<id>@puiva`／`event-<id>@puiva`（**同一筆重複匯入不會變成兩份**，只會更新）。
  - `days` 預設 90，可調 7–365；亂填（`3`／`500`／`abc`／`1.5`）一律 422，不靜默退回預設值。
  - 輸出上限 500 筆（一個學年遠小於這個數字，超過就是有人在掃資料）。
  - `content-type: text/calendar; charset=utf-8`、`x-event-count`、檔名 `pui-va-campus-YYYY-MM-DD.ics`（澳門日界）。
- 新 lib `src/lib/ics-export.ts`，集中處理三件「錯了不會拋錯、只會讓日曆匯不進去」的事：
  - **TEXT 跳脫**（RFC 5545 §3.3.11）：反斜線先跳脫，再處理 `;` `,`；換行寫成字面 `\n`，不留真換行。
  - **行折行**：每行 ≤ **75 octets**，續行以一個空白開頭；逐「字元」累加位元組長度，**不切斷 UTF-8 多位元組字元**（按 bytes 硬切會留下 `�`）。
  - **全天事件語意**：`DTSTART;VALUE=DATE` 用澳門日界、`DTEND` 是**隔天（exclusive）**，多日活動取最後一天 + 1。用 `toISOString()` 切片會在早上 8 點前少一天。
- 口徑與 `/calendar` 時間軸一致，不另外解釋一套：
  - 公告：`visibleNoticeWhere`（軟刪除／未到發佈時間／已過期都不出）＋ 只取**今天起**的 `publishedAt`。
  - 活動：`status = PUBLISHED`（草稿與已取消都不出）、未軟刪除、與視窗有重疊（跨日活動還沒結束就留）。
  - 分類：活動 → `活動`；公告標題命中 `測驗|考試|測考|小測|大測|test|exam` → `測驗`；`kind: CALENDAR` → `校曆`；緊急 → `緊急公告`；其餘 → `公告`。
  - `DESCRIPTION` 寫類型、發布時間、時間地點、報名截止與 160 字摘要（去 HTML／markdown 標記、保留分段）。
- 沒有 schema 變更、沒有 migration。

### 前端（v0.127.0）

- 網頁後台「公告」分頁最上面多一顆「下載校曆 .ics」（帶 token `fetch` + Blob，沿用假單／月報／已讀名單的下載做法），下方一行說明「用日曆 App 打開即可匯入、公開內容」。
- 使用說明補 3 條 Q&A：學生（怎麼把校曆放進手機行事曆）、老師（同上，操作位置在網頁後台）、含「重複匯入不會變兩份」與「小程序不能下載檔案」兩個常見疑問。
- `docs/openapi.yaml` 補路徑（198 → 200 路徑／240 → 242 操作）。

### 刻意沒做

- **小程序不加任何按鈕**：微信不能下載檔案，`wx.openDocument` 也不支援 `.ics`；在小程序放一顆下載鈕只會做成「按了沒反應」。這一輪的紀律也是「不新增頁面」——49 頁裡還有一批沒被真人看過，加新頁只會擴大未驗面積。
- **不輸出 `VTIMEZONE`**：站內公告本來只有日期，活動時間寫進 `DESCRIPTION` 就夠；多一個時區區塊只是多一個會錯的地方。

## 設計取捨

- **全部輸出成全天事件**：站內公告只有日期、活動時間放摘要就夠。這條決定讓「澳門日界」只在一處（`macauDay()`）出錯，也省掉 `VTIMEZONE`。
- **`days` 亂填回 422 而不是夾到範圍內**：夾住的話呼叫端永遠不知道自己送錯了（下次改成 `days=0` 也照樣回 90 天）。與 W-64 的「截止時間」、W-104 的 `groupBy` 同一條規則。
- **公告只取今天起**：日曆是往後看的工具；把上個月的公告塞進來只會讓匯入後滿版。要回顧歷史用站內公告列表。
- **重複用 `visibleNoticeWhere`**：公告的「對外看得到」只有一份條件。這支端點若自己再寫一次 `deletedAt: null`，下一步一定漏掉「未到發佈時間」——那種漏法編譯、型別、其他測試都不會報。

## 已知缺口

- **`.ics` 沒有真的丟進 iPhone／Google 日曆匯入過**：驗到的是格式（跳脫／折行／日界／排除規則），「Apple 日曆實際吃不吃」要等使用者有裝置時點一次。RFC 5545 的三個硬要求都做了，但這是唯一無法在本機證明的一步。
- 網頁後台那顆「下載校曆 .ics」**沒有親眼點過**（只驗了端點、語法與 admin-ui 守門）。
- 小程序端這一版沒有任何畫面變動，所以「使用說明新增的 3 條 Q&A」排版未親眼驗（`check-pages-boot`／`check-states` 綠）。
- 這一版沒有改 schema、沒有 migration；示範模式（`services/mock.js`）不需要跟著改，因為小程序沒有呼叫這支端點。
