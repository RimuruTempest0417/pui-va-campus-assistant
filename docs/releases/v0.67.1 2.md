# v0.67.1 — 使用說明「學生頁什麼都沒有」修正

上一版把清單改成由 JS 算好，但抓錯來源：`sections` 是**方法**（`this.sections()`），不是 `data.sections`，
所以 `this.data.sections[active]` 永遠是空物件 → 每個分頁都空白。

- `applyTab()` 改用 `this.sections()[active]`
- 進入頁面時預設停在自己那個身分（之前不管什麼角色都停在「學生」）
- 新增守門 `scripts/check-help-roles.mjs`：用 vm 模擬七種身分各跑一次，任何身分 Q&A 為 0 就紅

實測（守門輸出）：

```
GUEST        分頁: GUEST                                     Q&A: 3
STUDENT      分頁: GUEST,STUDENT,PARENT                      Q&A: 11
PARENT       分頁: ...                                       Q&A: 3
TEACHER      分頁: ...TEACHER,STAFF                          Q&A: 8
STAFF        ...                                             Q&A: 3
ADMIN        ...ADMIN                                        Q&A: 7
SUPER_ADMIN  ...SUPER_ADMIN                                  Q&A: 3
```
