# v0.79.0 — 修活動刪除崩潰＋W-61／W-62／W-63 收尾

## 修的 bug（使用者回報）

**活動分頁按刪除 → `Can't find variable: adminApi`**：我上一版把刪除改成原生確認框時，
新寫的函式呼叫了 `adminApi.deleteEvent`，但那個檔案的模組別名是 **`admin`**。
同類錯誤連續發生三次（`request is not defined`、`sections`、`adminApi`），所以這次連同守門一起補。

## W-61 逐頁實點驗收（P0）

- 新增 `scripts/check-pages-boot.cjs`：把 26 頁的 JS 放進 vm，用「什麼都有的代理」取代 require／wx，
  實際呼叫 **onLoad → onShow**，任何例外或未定義變數就是紅燈 → **26 頁全過**
- 負面測試（證明它真的抓得到）：在 `pages/menu/dish/index.js` 的 onLoad 塞一行 `adminApi.boom();`
  → `✗ ReferenceError: adminApi is not defined`；還原後再跑回綠燈
- 新增 `scripts/check-aliases.cjs`：`adminApi`／`dataApi`／`requestApi` 這類別名用了卻沒宣告就紅燈（59 個 JS 檔）
- **真正的真機點擊仍未做**：開發者工具目前登入的帳號不是教育版 appid 的開發者（`登录用户不是该小程序的开发者`），
  `check-console.mjs` 26 頁全部卡在工具層。等登入後跑 `node scripts/verify-all.mjs --only console`。
