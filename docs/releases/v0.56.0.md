# v0.56.0 — 去 AI 味（第二階段）：四宮格與卡片節奏（2026-10-25）

第一階段（v0.55.0）拿掉了 emoji；這一階段處理「太像模板」的三個結構原因。

## 1. 首頁四宮格：四個彩色底＋emoji → 單一品牌淡底＋單字

| 之前 | 之後 |
|---|---|
| 🔍（紫底）🎪（紅底）🍚（黃底）📢（綠底）| **失／活／餐／告**（同一種淡紫底、紫字） |

四種粉彩底是最典型的「模板感」來源；改成單色後，一眼看得出是同一套系統。

## 2. 今日午餐＋小賣部：兩張卡 → 一張卡

同一天、同一個場景（吃什麼）拆成兩張卡，等於多一次視覺跳躍。現在合成一張，內部用**分段小標題＋髮絲線**分開（iOS inset grouped 的做法）。

## 3. 設定頁：三張單列卡 → 一張卡三列

「通知／使用說明／回報問題」都是「點一下去看」的同類入口，之前各佔一張卡；現在一張卡三列、用 1rpx 髮絲線分隔。設定頁卡片數 **9 → 7**。

## 4. 活動詳情：分享卡從大色塊變成資訊卡的一列

原本底部一塊紫色大色塊（又是「按鈕像橫幅」的模板味），改成資訊卡最後一列「產生分享卡 → 存到相簿」，紫色只用在右側文字。
