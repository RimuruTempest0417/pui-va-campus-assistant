## 各身分新增的說明

| 身分 | 新增內容 |
|---|---|
| 訪客 | 搜尋（訪客也搜得到） |
| 學生 | 右上角放大鏡一次搜公告／活動／失物／菜單 |
| 家長 | 成績旁「手動補登」是什麼、為什麼不會被同步蓋掉 |
| 老師 | **成績批次補登**（貼「科目,類型,日期,分數」→ 先檢查 → 確認匯入）＋**活動回饋統計與催填** |
| 校內職員 | 幫學生補成績／出缺席（成績與出勤分頁）＋公告已讀與催讀 |
| 資訊管理員 | 補登入口與權限（`school:manage` 由老師／職員／管理員共有） |

條數：訪客 4、學生 14、家長 4、老師 12、校內職員 5、資訊管理員 8、最高權限 3 → **合計 50 條**（原本 42）。
