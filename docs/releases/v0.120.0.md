# v0.120.0 — 自己的紀錄自己帶走：成績／出缺席／借閱／請假匯出（2026-11-07）

任務：W-102（後端 v0.70.0；**沒有新頁、沒有新表、沒有 migration**）

## 為什麼做這一項

成績、借閱、假單以前只有管理員匯得出來（`/admin/leaves/export`、`/admin/library/loans.csv`），
學生想把自己三年的紀錄留一份，只能請校務處幫忙。這一版把「個資自主」補起來：
四類資料各一支 CSV，只看得到自己的（家長看得到綁定的那一位子女）。

照 2026-11-07 的方針：**不新增頁面**（49 頁已有一批還沒被真人看過），把入口放進既有的設定頁。

## 改了什麼

### 後端：`GET /api/v1/me/export?type=grades|attendance|library|leaves`（新檔 `src/routes/me.ts`）

四條規則寫在檔案開頭，路由只做權限與組回應：

1. **一律以 JWT 的 `sub` 為準**。帶 `studentId` 進來且不是自己時，只有「家長 ＋ 真的綁定了這位學生」
   才放行（走既有的 `lib/parent-scope.ts`，全專案唯一閘門）；學生帶別人的 id 一樣回 403，
   而且訊息與「查無此人」**完全相同**（`沒有綁定這位學生`）—— 否則這支端點會變成學號探測器。
   老師帶學生 id 也是 403（老師要看走後台匯出）。
2. **家長不帶 `studentId` 時自動用唯一那位子女**：家校通一個家長帳號只對應一位學生，
   前端少帶一個參數不該匯出一份空檔；檔名用的是子女的學號，不是家長自己的 `pv…` 帳號。
3. **CSV 在伺服器組**：新增 `src/lib/csv.ts`（`csvEsc`／`oneLine`／`csvDocument`／`exportFilename`／`macauDateTime`）。
   檔頭帶 UTF-8 BOM（Excel 開中文不亂碼）、CRLF 換行、每個欄位都包雙引號；
   請假原因、報修備註這類多行文字壓成空白，否則一列會被 Excel 拆成兩列。
   **缺考的分數是空字串不是 0** —— 寫 0 會被算進平均。
4. 每次匯出寫一筆 `me.export` 審計（類型、筆數、是否為家長代取），回應帶 `x-row-count`
   讓 curl 與測試不必解析檔案就知道幾列；`cache-control: no-store`。

欄位（與後台匯出同一套口徑）：

| 類型 | 欄位 |
|---|---|
| `grades` | 學年／學段／科目／測驗／日期／分數／備註／來源（家校通・手動補登） |
| `attendance` | 日期／學年／學段／上午／下午／上午到校／下午到校／備註／來源 |
| `library` | 書名／索書號／ISBN／借出／應還／歸還／逾期天數／續借次數（未歸還算到今天） |
| `leaves` | 假別／開始／結束／天數／狀態／原因／審批人／審批時間／駁回原因 |

上限 5000 列（超過就不是「帶走自己的紀錄」而是整校拉檔）。新增 `tests/e2e/me-export.test.ts` **10 項**。

### 前端：設定頁新增「我的資料」（`pages/settings`）

登入後在「關於」之前多一組卡（inset grouped ＋ 1rpx 髮絲線，沒有新色值、沒有新頁）：
成績／出缺席／借閱／請假四列，右邊一顆「複製」，按下去抓 CSV 純文字 → `wx.setClipboardData`，
toast 回「已複製成績 8 列」。沒有資料時回「還沒有資料」，不會給一份空檔。
四個按鈕共用一個 busy 鎖（連點不會疊出四份）。

**為什麼是複製不是下載**：微信小程序不能下載 CSV（`wx.openDocument` 不支援），
所以「複製內容 → 貼到 Excel／Numbers／記事本」是手機上真的走得到的那條路。

資料層三支都補齊（`services/{api,mock,data}.js` 的 `myExport`）：

- `api.js` 用 `http.get('/me/export', { type, studentId }, { text: true })`；
  `utils/request.js` 新增 `text` 選項 → `wx.request` 帶 `dataType: 'text'`，
  否則預設的 `json` 會先嘗試 `JSON.parse`，有些基礎庫直接回空字串。
- `mock.js` 用同一組欄位順序由示範資料產生（斷網演示時按下去也要有內容）；
  示範層的家長也套「不帶 id 就用唯一子女」同一條規則。
- `data.js` **刻意不加進 `CACHEABLE`**：匯出是「當下要帶走的檔案」，快取只會讓人拿到舊資料。

### 契約與說明

  `--parity` 兩邊 0 落差（196 路徑／238 操作）。

## 已知缺口

- **設定頁那一組的畫面沒有在開發者工具或真機上親眼看過**（2026-11-07 老師還沒改完功課，
  使用者無法協助驗畫面）。已驗的是：結構守門（49 頁 0 警告）、頁面啟動零例外、
  資料層 297 項、後端 e2e 10 項。
- **`wx.setClipboardData` 在真機上的行為未實測**：長文字（例如 5000 列上限的成績）在個別
  基礎庫版本可能有長度限制，剪貼簿被截斷時畫面仍會顯示「已複製」。實際資料量在示範與一般
  學校規模下都在數十列，風險低；要等有人真的按一次才知道。
- **網頁後台沒有對應按鈕**：`/me/export` 是給登入者自己的，網頁後台已有各模組的管理端匯出，
  這一版刻意不重複做；若之後要在網頁也給學生用，直接開這一支端點即可。
