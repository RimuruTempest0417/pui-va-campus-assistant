## 這一版

- **刷新中指示條**：任何請求超過 250ms，畫面最上面出現一條會跑的細線＋一顆小藥丸寫「正在更新」；全部請求結束後再留 320ms 收起。250ms 內就結束的請求不顯示（切頁時一直閃比沒有更差）。
- 覆蓋頁面：首頁、課表、功課、成績、通知中心、後台首頁。
- 後台課表分頁：CSV 說明改成小標題「批次匯入（後備）」＋一行格式提示。
