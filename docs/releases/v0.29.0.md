# v0.29.0 — 修 WXML 編譯錯誤、檢舉入口、文件一致性守門（2026-10-25）

## 一、修掉一個會讓整個小程序打不開的錯（最優先）

`pages/events/detail/index.wxml` 用了 WXML 不支援的寫法：

```diff
- <pv-card wx:if="{{(ev.groups || []).length}}">
+ <pv-card wx:if="{{groups.length}}">
```

WXML 的表達式**不支援陣列／物件字面值**，編譯器直接報 `Bad attr 'wx:if' with message: unexpected token '.'`，
整頁編譯失敗 → 模擬器黑屏、自動化接口一直 timeout（我前一輪把它誤判成「自動化接口壞了」，實際上是自己的模板錯）。
已修，並在 `check-project.mjs` 加守門：`wx:if`／`wx:elif` 內出現 `[]`／`{}` 直接判錯。

## 二、分組按鈕的第二個 bug

選了組別之後底部按鈕仍顯示「選擇組別」且不可按（`barFor()` 只在載入時算一次）。
已改成 `chooseGroup()` 選完立刻重算，實測：選「乙組」→ 按鈕變「立即報名」→ 報名成功 → 「取消報名」。

## 三、檢舉功能沒有入口（使用者回報）

後端 `/reports` 早就做好，後台也有「檢舉」分頁，但**前端沒有任何地方可以檢舉**，所以那一頁永遠是空的。
這版補上：

| 層 | 內容 |
|---|---|
| 服務層 | `api.createReport()`／`mock.createReport()`／`data.createReport()`（示範模式會寫進本機資料，可驗證） |
| 失物詳情 | 底部操作列左側加「檢舉」文字入口 → 底部彈層選原因（內容不實／廣告或推銷／不當或冒犯內容／與校園無關）→ 送出後 toast |
| 權限 | 訪客點檢舉 → 提示先登入（真 API 模式）；示範模式可直接驗 |

## 四、文件一致性守門（針對「文件經常沒同步」）

新增 `scripts/check-docs.mjs`，把「文件對不上」變成 CI 會擋的錯：

1. 最新 `docs/releases/vX.Y.Z.md` ＝ README 版本徽章 ＝ `docs/發佈與上傳.md` 的版本號
2. `docs/規劃書-待完成.md` 的「現況」版本 ＝ 最新 release
3. 每份 `docs/*.md` 至少被 README 或規劃書引用（抓孤兒文件）
4. README／規劃書 反引號裡的專案路徑必須真的存在（抓幽靈引用）
5. 規劃書的 W 編號不得重複
6. README 寫的「N 頁」要等於 `app.json` 的頁面數

**第一次跑就抓到 4 個真實漂移**：README 徽章停在 0.27.2、規劃書現況停在 0.27.2、README 寫「11 頁」（實際 19）、README 提到後端才有的 `scripts/restore.mjs`。
全部已修，現在 0 錯誤 0 警告。已納入 `scripts/verify-all.mjs` 與 CI。
