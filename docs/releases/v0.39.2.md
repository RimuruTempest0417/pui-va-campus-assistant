# v0.39.2 — 深色模式真的跟隨系統了（2026-10-24）

使用者回報三件事，全部是實機才看得到的：

| 回報 | 根因 | 修法 |
|---|---|---|
| 「跟隨系統」只認淺色，系統深色沒反應 | **`app.json` 沒有開 `darkmode`** → 微信根本不會把系統主題告訴小程序，`getAppBaseInfo().theme` 永遠回 `light` | `app.json` 加 `"darkmode": true` ＋ `theme.json`（視窗底色／導航列深淺兩套） |
| 資料來源（資料層自我檢查）頁沒有深色 | 該頁根節點用 `.pv-page`，這個 class **只有 padding、沒有背景色** → 深色下是「淺色頁底＋白字」 | `.pv-page` 補 `background: var(--pv-bg)` |
| 該頁下方按鈕太擠 | `.api-actions pv-button { margin-right }` 對自訂組件不生效 | 改 `gap: var(--pv-sp-2)` ＋ `flex-wrap: wrap` |

## 順手修掉一個更嚴重的

設定頁「安全」區塊的文字全部對錯：顯示成「帳號／管理後台」。原因是**字串遷移腳本第二次跑時，key 從 k01 重新編號**，撞到既有 key。
已改用手工指定 key（k30–k43）並在 `labels()` 補齊，現在正確顯示「安全／兩步驗證／未開啟（建議資訊管理員開啟）／開啟（產生密鑰）」。
