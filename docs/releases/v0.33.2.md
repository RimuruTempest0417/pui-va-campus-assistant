# v0.33.2 — 校曆右上角那顆紫色方塊修好了（2026-10-24）

## 你看到的現象

校曆月份列 `‹ 2026 年 10 月 ›` 的右邊有「一個紫色方塊，不完整、像被遮住」。實際按下去會回到今天，但看不出是顆按鈕。

## 兩個 bug 疊在一起

| # | 問題 | 量到的證據 |
|---|---|---|
| 1 | **「今天」兩個字根本沒渲染** | `L.today` 在執行期是空字串（`{"title":"","today":"","empty":""…}`）。頁面有寫 `labels()`，但 `onLoad` **沒有呼叫它**，所以標籤全部是初始空值 —— 剩下的只有 `--pv-tint-soft` 的紫色背景，看起來就是「不完整的紫色方塊」 |
| 2 | 膠囊被月份標題擠扁 | 「今天」膠囊沒有 `flex-shrink: 0`，標題 `flex: 1` 搶走空間 → 量到膠囊寬度只有 **18.4px**（連字都放不下） |

## 修法

```diff
  onLoad() {
    const now = new Date();
    this.setData({
+     L: this.labels(),            // 漏了這行 → 按鈕文字全空
      year: now.getFullYear(),
```

```diff
+ .cal-head__title { flex: 1; min-width: 0; }      /* 讓標題先讓位，而不是擠壓按鈕 */
+ .cal-head__nav   { flex-shrink: 0; }
+ .cal-head__today { flex-shrink: 0; width: 104rpx; box-sizing: border-box; }
```

`onShow` 也重新套一次標籤，使用者在自檢頁切繁／簡回來就會跟著變。

## 順手加的守門

`check-project.mjs` 新增一條：**頁面若定義了 `labels()`，就必須有 `L: this.labels()`**，否則判錯。
這類「字典有、頁面沒套」的空白文字以前只能靠肉眼發現，現在編不過。
