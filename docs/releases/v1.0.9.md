# 前端 v1.0.9（網頁後台移除示範資料；小程序未變）

**日期**：2026-11-18｜**後端 v1.0.9｜教育版仍為 1.0.7（不需重新上傳）**

- 網頁後台側欄不再有「示範資料」分頁；匯入／清除示範資料的整塊 UI 與程式都移除。
- 原因：資料已經是真實資料，那顆按鈕會真的寫進資料庫。
- 後端 `/admin/demo-data` 仍保留（測試與示範環境用），只是網頁沒有入口。
- **小程序菜單頁也顯示 A／B／C 餐**：每天的卡片最上面是「今日套餐」（A／B／C 各一行，左邊字母圓牌）；
  這天沒有套餐就照舊顯示單點菜色，兩者都沒有才顯示「這天沒有排菜單」。
- 新公開端點 `GET /menu/sets?weekStart=`（訪客讀得到，與網頁後台同一份資料）。
