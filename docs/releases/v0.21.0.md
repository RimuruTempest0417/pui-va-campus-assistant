# v0.21.0 — 校曆視圖（公告模組補完）（2026-10-23）

## 為什麼

公告模組原本只有「列表＋詳情」，但學校真正需要的是「什麼時候有事」——停課、考試週、活動日散在公告與活動兩個模組裡。
公告本身已有 `kind: CALENDAR`（校曆類），活動也有 `startAt`，資料一直都在，只缺一個把它們攤開來看的地方。

## 做了什麼

| 檔案 | 內容 |
|---|---|
| `utils/calendar.js` | `monthGrid`（固定 6×7＝42 格、週一為首欄）、`groupByDate`（公告＋活動按日收在一起，緊急→活動→校曆→一般排序）、`monthSummary`（每天筆數與圓點類型）、`dateKey`／`monthLabel` |
| `pages/calendar/index` | 月視圖：上月／下月／今天、日期格（今天＝淡底、選中＝實心）、圓點（紅＝緊急、紫＝活動、灰＝公告）、當日項目列表（點擊進公告詳情／活動詳情） |
| 公告列表頁 | 頂部加「列表／校曆」分段入口 |
| `services/{api,mock,data}.js` | 新增 `calendar()`：**由既有 `/notices` 與 `/events` 組合，不新增後端端點** |
| `scripts/check-data-layer.mjs` | 新增 5 項校曆檢查（42 格、本月 1 號在格內、今天有標記、同日合併、緊急優先）→ **44/44** |

## 驗證

```
node scripts/check-project.mjs   → 17 個頁面 0 警告（新增 1 頁）
node scripts/check-data-layer.mjs → ALL PASS 44/44
模擬器實測（真 API）             → 2026 年 10 月、42 格、6 天有項目、今天 2026-10-24
```

## 設計取捨

- **不新增後端端點**：校曆只是既有資料的另一種視圖，加一支 API 會產生兩份真相（公告改了校曆沒改）。
- **固定 42 格**：避免月份高度跳動（5 列／6 列切換時版面會抖）。
- **圓點最多一個**：多個圓點擠在 96rpx 格子裡會變糊，用優先序（緊急 > 活動 > 公告）只顯示最重要的那個。
