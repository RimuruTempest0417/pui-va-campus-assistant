# v0.118.0 — 家長代子女請假（W-99）

> 前端 v0.118.0｜後端 v0.68.0｜2026-11-07
> 這一版**沒有新頁面、沒有新表、沒有 migration**：做法全部落在既有的家長頁、假單表單與後端 `shapeLeave`。

## 為什麼

請假（W-72）從第一版就讓 `PARENT` 能替綁定的子女送單，後端 `POST /leaves` 的閘門、e2e、審批流程都齊了，但**家長在畫面上找不到入口**：`pages/parent` 只有「代報名／取消報名」，假單要從首頁的「請假申請」進去，而那條路預設被當成學生自己在用。結果是「功能有、家長用不到」。

Gary 的定案是「家校通家長帳號登入後，直接就是那一位子女的視角」，所以入口要放在他最常開的那一頁（我的子女），而不是叫他自己去找。

## 做了什麼

### 前端

- **`pages/parent` 最上面那張卡加第二列「代請假」**（`set-row set-row--sep`，1rpx 髮絲線分隔，不另外長一張卡）。點下去帶 `?studentId=<目前選中的子女>` 進既有的假單表單。
- **同頁新增「孩子的假單」區**（inset grouped：一張卡、列與列之間髮絲線）：
  - 每列：假別 ＋ 日期、天數、右邊狀態標籤（待審批／已批准／已駁回／已取消）；
  - 第二行寫**「家長代送」或「學生本人」**（`sourceText`），老師與家長都不必猜這張單是誰送的；
  - 被駁回的直接把原因寫在列上；
  - 待審批的列有「取消」（原生 `wx.showModal` 確認，不用自製兩段式）；
  - 只列最近 5 張，右邊「全部 ›」跳 `pages/leaves/mine`。
- **`pages/leaves/create` 認 `?studentId=`**：從哪一位子女的代請假進來，就送給那一位（切換子女後再按代請假不會送錯人）。
- **`styles/ui.wxss` 收進 `.set-row*`**：這一組 class 原本只寫在 `pages/settings/index.wxss`，家長頁用了同一組卻沒有樣式（箭頭掉到標題下面、整列看不出可點）。樣式只有一份來源，兩個頁面共用。

### 後端

- `shapeLeave()` 多回 **`source`（`STUDENT`／`PARENT`）與 `sourceText`（學生本人／家長代送）**。
  **不新增欄位**：送出者永遠等於 `createdById`，多存一欄就一定有一天出現「欄位寫 PARENT、createdById 是學生」的兩份真相。用 `createdById === studentId` 算出來，送出回應／`GET /leaves/mine`／`GET /leaves/:id`／`GET /admin/leaves`／CSV 五條路徑自動一致。
- 權限與審批流程**完全沒有動**：家長仍必須通過 `parent_links` 反查（未綁定與「不存在的人」回同一句 403），學生帶別人的 `studentId` 仍 403，重疊日期仍 409。

### 示範層（斷網演示時也要走得完）

- `services/mock.js` 的 `createLeave` 補上家長分支（`parent.children` 反查、403／422 與後端同碼同訊息）；`myLeaves` 讓家長看得到子女的假單；`shapeLeave` 回同一組 `source`／`sourceText`。
- 示範資料多兩張**家長代送**的假單（`lv4` 待審批、`lv5` 已批准）：登入示範家長帳號就看得到「家長代送」兩種狀態，學生帳號看不到。

### 文件與說明

- `pages/help` 家長分頁的「可以替孩子請假嗎？」改寫成實際路徑（我的子女 → 代請假 → 孩子的假單 → 全部），並寫出狀態、來源標記與取消。
- `docs/openapi.yaml` 的 `LeaveRequest` 補 `source`／`sourceText`。
- 規劃書刪掉 W-99 一節、執行順序表重編號。

## 取捨

- **不加 `Leave.source` 欄位**：`createdById` 已經是事實來源，加欄位等於讓同一個事實有兩份，且要為舊資料回填。代價是查詢不能直接 `where source = 'PARENT'`（要 `where: { NOT: { createdById: studentId } }`），但目前沒有這種查詢需求；真的需要時再加欄位並在 shape 層對齊。
- **入口放「我的子女」而不是首頁**：家長登入後的第一落點就是那一頁，首頁再加一顆「代請假」會變成兩條路徑、其中一條遲早沒人維護。
- **只列 5 張**：這一區是「最近怎麼了」，不是完整清單；完整清單在「我的假單」（後端上限 100 筆）。
