# v0.38.0 — W-20c 簡繁最後一段：WXML 運算式裡的 91 條（2026-10-24）

## 背景

v0.35.0 搬完 WXML 的**純文字**（311 條），v0.37.0 搬完**頁面 JS**（316 條），
剩下 133 條卡在 `{{}}` 運算式裡 —— 例如：

```html
<text>{{item.full ? '已滿' : '可報名'}}</text>
```

這種字串不在文字節點、也不在 JS，所以前兩階段都掃不到。

## 做法

新增 `scripts/i18n-migrate-expr.py`：

1. 只挑 `{{ }}` 裡的**字串字面值**，且必須含中文
2. **跳過比較用的字串**（`=== '已認領'`、`!== 'OPEN'` 這種是邏輯判斷，搬了會壞）
3. 換成 `L.kNN` 並在該頁 `labels()` 自動補 `i18n.pick('原文')`
4. 對照表交給 `scripts/build-i18n-phrases.py` 重算（opencc t2s）

結果：**91 條**、11 個頁面（後台相關頁面為 0，因為那邊是 JS 產生字串，已在 0.37.0 處理）。
