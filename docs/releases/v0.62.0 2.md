# v0.62.0 — 失物管理加「刪除」按鈕（2026-10-25）

使用者要求：「刪除也包含失物管理，下架旁邊再加一個刪除的按鈕」。

## 差別（兩顆按鈕做不同的事）

| 按鈕 | 行為 | 去哪裡 |
|---|---|---|
| 下架（原有） | 狀態改為 `CLOSED`，仍留在失物管理清單裡，可以再上架 | 留在原清單 |
| **刪除（新增）** | 軟刪除 `deletedAt`，從清單消失 | **只出現在「回收桶」**，可還原 |

兩段式確認（按一次變提示，4 秒內再按才真的刪），避免誤刪；刪除後同時重載失物清單與回收桶計數。
只有「未刪除」的列才顯示刪除按鈕；已在垃圾桶的列顯示「還原」。
