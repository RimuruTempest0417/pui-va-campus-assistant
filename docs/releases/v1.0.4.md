# 前端 v1.0.4（緊急修補：家校通登入「連不到後端」）

**日期**：2026-11-18｜**後端 v1.0.4｜教育版 1.0.4**

## 症狀

用家校通帳號登入時，畫面顯示「連不到後端，無法登入」。

## 原因

- 小家端請求逾時是 8 秒，家校通登入本身就要 8.4 秒；
- v1.0.2 的「登入即同步」再吃掉最多 7 秒，總時間 15 秒以上 → 8 秒逾時先觸發；
- 前端把逾時一律顯示成「連不到後端」，看起來像網路斷了。

## 修法

- 家校通登入請求：逾時 8s → **25s**、**不重試**（`utils/request.js` 支援單次覆寫 timeout 與 retry）。
- 登入頁 watchdog：15s → **30s**。
- `api.schoolRefresh`：30 秒逾時（後端要重新登入家校通再抓一批）。
- 逾時與連不上分開顯示：「後端回應太慢（學校系統可能正在忙），請再試一次」。
- 後端同步預算同時由 7s 收緊到 2.5s（見後端 v1.0.4）。
