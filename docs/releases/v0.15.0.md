# v0.15.0 — 後台十個分頁（2026-10-23）

## 新增分頁

| 分頁 | 內容 |
|---|---|
| **活動** | 直接在小程序新增活動（標題／地點／日期／名額），列表可「取消／恢復」 |
| **使用者** | 清單顯示角色與停用狀態，一鍵設為學生／老師／資訊管理員，可停用／恢復 |
| **檢舉** | 待處理清單，「成立並下架」或「駁回」 |
| **審計** | 最近 50 筆操作（動作、目標） |
| **公告（增強）** | 發布表單下方多了「既有公告」清單，可置頂／取消置頂、刪除（有二次確認） |
| **菜單（增強）** | 排入後可看**本週已排**清單，逐筆移除 |

分頁權限（前端只做顯示）：
- 老師：公告、活動
- 資訊管理員：全部（除了審計）
- 最高權限：全部（含審計）

## 其他修正

- 登入頁移除標題下方說明小字
- 登入成功後**回上一頁**，不再自動跳後台；首頁多了「管理後台」入口按鈕（有權限才顯示）
- 首頁載入失敗時會顯示「連不到後端：<目前位址>」並提供「設定後端位址」按鈕
