# v0.64.0 — 使用說明涵蓋全部身分（三→七個分頁）

使用者回報：「使用說明畫面只有四種用戶涵蓋不全面」。

實際上系統有 **六級角色 ＋ 訪客**，原本只寫了四種。現在分頁是：

| 分頁 | 對象 | 內容重點 |
|---|---|---|
| 訪客 | 未登入 | 看得到什麼／怎麼登入／為什麼看不到別人的東西 |
| 學生 | STUDENT | 失物、活動、菜單、通知、分享卡、回饋、組隊 |
| 家長 | PARENT | 綁定子女、代報名、**成績與出缺席（家校通）** |
| 老師 | TEACHER | 發公告、開活動、簽到、統計、取消延期、組隊 |
| **校內職員** | STAFF | 發公告、審批認領、排菜單、匯出（不能開活動／管帳號） |
| 資訊管理員 | ADMIN | 認領審批、帳號管理、檢舉、錯誤、回收桶、列印 |
| **最高權限** | SUPER_ADMIN | 差別：指派管理員、審計匯出、備份還原、2FA 救援 |

- 預設停在自己那個身分（未登入 → 訪客）
- Q&A 從 24 條增加到 **38 條**
- 順手刪掉 6 個「` 2`」重複副本（之前工具產生的殘留，會讓結構檢查報幽靈頁）
