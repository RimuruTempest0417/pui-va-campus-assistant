# v0.34.0 — 新的「設定」頁：帳號、語言、外觀（2026-10-24）

使用者 2026-10-24 的四個決定：

| 決定 | 內容 |
|---|---|
| 深色模式 | 三選一（跟隨系統／淺色／深色），預設跟隨系統 |
| 繁簡 | **預設跟隨手機系統語言**，設定頁可覆寫 |
| 設定入口 | 首頁右上角頭像 |
| 登入／登出 | 集中到設定頁；登入頁只給未登入的人用 |

## 一、新頁面 `pages/settings`

| 區塊 | 內容 |
|---|---|
| 帳號 | 未登入 → 一列「登入」（點進去登入頁）；已登入 → 名稱、角色（中文）、管理後台（教職員才顯示）、切換帳號、登出 |
| 介面語言 | 跟隨系統／繁體／簡體 —— **預設跟隨系統**（`wx.getAppBaseInfo().language`：`zh_CN`、`zh_SG` → 簡體，其餘中文 → 繁體） |
| 外觀 | 跟隨系統／淺色／深色（偏好已儲存，實際配色下一版接上，見下方說明） |
| 資料來源 | 只有教職員以上看得到：顯示目前是真後端還是離線示範，點進去是原本的自檢頁 |
| 關於 | 版本、學校 |

首頁右上角頭像 `goAccount()` 從「導向登入頁」改成「導向設定頁」。

## 二、語言：預設跟隨系統

`utils/appearance.js` 統一管兩個偏好（`pv_theme`、`pv_locale`），`utils/i18n.js` 的 `locale()` 遇到 `system` 就走系統語言。

實測：在設定頁選「簡體」→ 校曆頁標題從「校曆／校曆表」變成「校历／校历表」；切回「繁體」即恢復。

## 三、登入頁只做登入

已登入時只顯示「名稱／角色＋回首頁＋到設定管理帳號」，**不再有登出按鈕**（登出在設定頁），也不會同時出現登入表單。

## 四、深色模式：這版只存偏好，配色下一版接

Skyline 是否支援 `prefers-color-scheme` 尚未實測；若不支援，需要逐頁在根節點掛 `themeClass` 才能手動切換。
為了不交付一個「選了不會變」的假開關，這版只做偏好儲存與 UI，**實際配色切換排入 W-21**，屆時會先實測再選做法並標明。
