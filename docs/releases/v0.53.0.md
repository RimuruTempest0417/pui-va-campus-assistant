# v0.53.0 — 活動附件（W-38）：章程、場地圖不再塞在說明欄

日期：2026-10-25

## 為什麼

老師辦比賽、工作坊，章程與場地圖只能整段貼進「活動說明」——文字被拉得很長，
而且 PDF 根本放不進去。同學到現場前要翻半天，家長代報名時也看不到要準備什麼。

這一版把附件做成活動的一部分：詳情頁多一個「附件」區塊，點一下直接開檔或複製連結；
老師可以自己加、自己刪，不用找管理員。

## 抓到的坑

- **`services/api.js` 有 8 個方法在真 API 模式必定拋 `ReferenceError`**（`request` 未定義）。`check-data-layer` 走的是示範層、頁面又全都 `.catch()`，所以守門全綠、畫面只是「沒有資料」。
  這一版順手修掉並在檢查裡加上「真 API 走哪支端點」的靜態斷言；沒有這條斷言，同類錯誤還會再發生一次。
- **COS 未設定時舊版回的是「VALIDATION_FAILED ＋ 一句話」**：前端分不出「你填錯」與「後台還沒開通」。
  改成專用錯誤碼後，使用者看到的是「尚未開通檔案上傳」＋一顆「改用貼連結」的按鈕。
- **`wx.openDocument` 對 HTML 一定失敗**：示範與多數外部連結都是網頁，所以「下載→開啟」那條路要準備退路（複製連結），
  不能只彈一顆「檔案開啟失敗」讓人以為附件壞了。

## 設計取捨

- **附件只存位址，不搬檔案**：COS 直傳後的 URL 與老師貼的學校連結走同一條路，後端不必碰檔案本體。
  COS 沒開通時「貼連結」照樣可用 —— 這是目前唯一的真實路徑，也讓功能不被一個未開通的服務卡住。
- **`canManageAttachments` 由後端算**：`event:create` ＋（老師：`createdBy === 我`／ADMIN 以上：全部）。
  前端只照旗標顯示，不在頁面裡重算等級 —— 兩套判斷早晚會不一致。
- **上限 10 份、`url` 只收 http(s)**：附件區是給「章程／地圖」這種少量檔案用的，不是雲端硬碟；
  10 份足夠，而且能讓詳情頁一屏內看完。
- **不動 `Event.version`**：附件是獨立資源，加一份附件不該讓正在編輯說明的老師存檔時撞 409。
- **沒有在小程序做「附件管理頁」**：老師就在詳情頁加／刪，少開一頁也少一個「後台與詳情不同步」的地方。
