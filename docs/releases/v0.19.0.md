# v0.19.0 — W-13 驗收自動化＋登入頁帳號格式（2026-10-23）

## 一、驗收自動化（W-13）

`scripts/check-project.mjs` 從「結構檢查」擴充成「出錯就擋發版」的守門，新增四類檢查：

| 檢查 | 為什麼要加 | 這次抓到什麼 |
|---|---|---|
| 頁面 `.js` 必須有 `Page(` / `Component(` | 少這行頁面不會被註冊，但編譯不會報錯 | 0（全部正常） |
| `page.json` 必須有 `navigationBarTitleText` | 少了導航列會空白 | **10 頁缺** → 已補 |
| `wxml` 用到的 `<pv-*>` 必須在 `usingComponents` 註冊（雙向） | 漏註冊會渲染成空白標籤；註冊沒用是死代碼 | 5 個未使用註冊 → 已移除 |
| `pages/` 底下有檔案但沒登記到 `app.json`、tabBar／entryPagePath 指到不存在的頁面 | 頁面做好卻進不去 | 0 |

新增 `docs/驗收清單.md`：6 項自動檢查（含通過標準與本次數字）＋ 18 項手動驗收（每項標明證據方式：截圖／API 回應／頁面數）。

## 二、登入頁帳號格式

- 登入頁帳號輸入框的提示文字從「例如 Rimuru」改成「例如 3201201001」（學號／教職員編號格式）
- 原因：`Rimuru` 是開發者自己的帳號，會誤導使用者以為要填英文名
