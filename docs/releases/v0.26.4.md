# v0.26.4 — 家長頁的「進不來」分成三種

> 2026-10-24（第十五輪 · 夜間）

## 做什麼

`pages/parent`（我的子女）原本把所有失敗都畫成同一張卡：「無法讀取子女資料」＋`重試`。
但學生／老師／校內職員打開這一頁時，後端 `GET /parents/me/children` 回的是 **403 FORBIDDEN**
（`assertParent()` 在碰資料庫之前就擋掉），重試一萬次還是 403 —— 這不是「載入失敗」，
是「這一頁不屬於你」。使用者看到的是「系統壞了」，實際上系統運作完全正常。

改成三種互斥狀態，各自給對得上的操作：

| 後端回應 | 狀態 | 畫面 | 該給的操作 |
|---|---|---|---|
| `403 FORBIDDEN` | `denied` | 「這一頁只給已綁定子女的家長」＋說明學生／老師／職員都沒有子女資料 | 回首頁、切換帳號（**不給重試**） |
| `401 UNAUTHORIZED` | `guest` | 「請先在家長帳號登入」 | 去登入、回首頁 |
| 其他（NETWORK／INTERNAL） | `failed` | 「無法讀取子女資料」＋錯誤文案 | 重試（這才是重試有意義的一態） |

改的檔案：`pages/parent/index.js`（`data` 加 `denied`／`guest`、`retry()`／`goHome()`／`goLogin()`、
`load()` 依 `codeOf(e)` 分流）、`pages/parent/index.wxml`（三個 `pv-empty` 分支，按鈕放 slot）、
`pages/parent/index.wxss`（`.state-actions` 橫排）。

## 怎麼驗

- `node scripts/check-project.mjs` → 19 個頁面 **0 警告**
- `node scripts/check-data-layer.mjs` → **ALL PASS 60/60**
- `node scripts/check-states.mjs` → 19 頁全部符合 REQUIRE 表
- `node scripts/check-console.mjs` → 19 頁 **0 error／0 warn**
- 模擬器實測（真後端，`pv_api_base` 指到 `127.0.0.1:3100`）：
  學生 JWT → `denied:true / guest:false / failed:false`；無 token → `guest:true`；
  接到打不通的 `39999` → `failed:true`、`errorText='網路不穩，請檢查連線後重試'`
- 尺寸探針（Skyline 要量，不能只看 data）：`pv-empty` **375×227.8**、內嵌按鈕 **78.9×39**（真的畫出來）
- 文字探針：`pv-empty` 的 text 回「👪這一頁只給已綁定子女的家長…回首頁切換帳號」——**沒有「重試」**

## 設計取捨

1. **不在前端判斷角色**。前端只知道「後端回了什麼碼」，不自己比對 `me.role === 'PARENT'`。
   兩份判斷早晚不一致，而且真正的門本來就在後端；前端多做一份只會多一個過期真相。
2. **403 不給重試**。不可恢復的錯誤配一個無效按鈕，是把「沒有權限」講成「系統壞了」的元兇。
3. **401 與 403 分開**。401 使用者自己可以解決（登入），403 要學校改設定（綁定／換帳號），
   混成一句「請先登入」會讓家長以為登入就能解決。
4. 順手把 `failed` 這一態補上 `重試`（原本連重試都沒有），三態才完整。
