# v0.96.0 — 後台「功課」分頁：全校哪一班沒交，一眼看完（2026-11-06）

> 前端 v0.96.0／後端 v0.52.4；沒有新表、沒有 migration
> 任務：W-77（P0：後台分頁缺口）

## 為什麼

W-76 把功課帶進系統，但**只有老師在自己的班看得到**：老師打開功課頁看到「8/24 人交了」，
校務處／資訊管理員卻答不出「今天全校派了幾樣、哪一班沒人交、哪一項派錯了要收回」。
後台二十個分頁裡每一個模組都有一頁，只有功課沒有 —— 這一版把它補上，
順便把「老師只能管自己班」與「管理員看全校」的分界寫進權限，不是只把畫面做出來。

## 改了什麼

## 設計取捨

- **新開一支 `/admin/homework`，不改 `/homework` 的語意**：那一支的班級是「我的班」，學生傳 `className` 也會被忽略（防窺別班）。把「全校」塞進去等於讓一支端點同時有兩種權限語意，測試與文件都會開始互相矛盾。
- **只回數字不回姓名**：一頁最多 120 項，每項都帶全班姓名會變成幾千筆；要點名時才打 `/homework/:id/pending`（既有端點），一次一項。
- **完成率不從前端算**：分母要查使用者表，前端拿不到；而且「多少人算一班」只能有一個答案（現在是 `User.className` 的集合，W-86 會把名單可設定化）。
- **收回沿用軟刪除**：派錯作業要能立刻從學生畫面消失，但「老師派過什麼」是校方要查的紀錄，不能真的刪。
- **老師看不到這一頁**：`homework:manage` 只有資訊管理員以上；老師在自己的功課頁已經有完成率與未交名單（W-76），不需要跨班視角。權限是後端 `requireCapability()` 擋的，不是 UI 隱藏。
- **不做的事**：完成率歷史趨勢與每日折線（W-84）、功課附件（W-84）、把後台分頁做成可拖拉排序。
