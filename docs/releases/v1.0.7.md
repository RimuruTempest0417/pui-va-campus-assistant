# 前端 v1.0.7（校曆改成直接給學校那條網址）

**日期**：2026-11-18｜**後端不變（1.0.6）**

## 這一版

使用者定案：**小程序的日曆連結直接給學校已發布的那條 `webcal://` 網址，貼上就好，不用額外生成。**

- 設定 →「訂閱校曆」：第一列就是學校日曆網址（`webcal://p46-caldav.icloud.com/published/2/…`），
  按「複製」→ 貼進手機日曆的「加入訂閱行事曆」。網址很長，加了斷行規則，不會撐破卡片。
- 原本「產生網址」那一組（權杖、重新產生、停止訂閱、訂閱範圍）**整個從畫面拿掉**（使用者定案「把進階拿掉」）。
  後端端點與資料層仍保留（舊權杖仍然有效），只是設定頁不再出現。
- 使用說明兩條問答同步改成新流程。

## 個人行程去哪裡了

學校公開日曆不含個人資料，所以孩子的假單、功課截止日回到小程序裡看（「我的子女」→ 功課／假單分頁）。
一條公開網址外流不會帶出任何人的請假紀錄 —— 這比「每個人都要記得保管自己的權杖」更適合中學生。

## 驗證

- 前端守門 16 步全過（結構／i18n／資料層 340 項／文件一致性）
- `PUBLIC_CALENDAR_URL` 為單一來源（`config/config.js`），要換學校日曆只改一行
