# 前端 v1.0.15（一開即登入、功課顯示老師）

**日期**：2026-11-19｜**後端 v1.0.15｜教育版 1.0.15**

## ① 小程式一開就是登入頁

Gary 定案：「小程序進入的頁面改成直接登入帳號，沒有登入不能使用」。

- `app.json` 第一頁改成 `pages/admin/login/index`；
- 已登入的人開到登入頁會自動進首頁（從「切換帳號」進來的除外）；
- 11 個主入口頁（首頁／設定／通知／課表／功課／菜單／家校通／成績／家長／後台／搜尋）`onShow` 第一行就是 `authGuard.guard()`，沒 token 一律回登入頁；
- 登出、以及 JWT 逾時（401）都會 reLaunch 回登入頁，不會停在一個什麼都抓不到的畫面；
- 新增守門腳本 `check-login-first.mjs`（16 項）釘住以上規則。

## ② 功課：顯示任教老師、不代學生打勾

- 家校通匯入的功課在標題右邊顯示「已提交／遲交」文字標籤（綠底）與「家校通」來源標籤；
- 下一行顯示「任教老師 梁莉娜」；
- 學校端標「已提交」**不再自動幫學生打勾**，打勾仍由學生本人按。

## ③ 使用說明同步

三條原本寫「沒登入也可以看…」的問答改成「一定要登入才能用／要登入才看得到」，避免說明與行為不一致。
