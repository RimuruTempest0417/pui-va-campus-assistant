# v0.1.0 — 小程序骨架與專案藍圖（2026-10-22）

第一個進版控的版本：可編譯的 Skyline 小程序外殼，加上完整的設計與競賽材料。

## 新增

- **小程序骨架**：原生小程序 + Skyline 渲染引擎 + glass-easel 組件框架，`project.config.json` 設定 `appid`，可直接由開發者工具導入
- **導航列組件**：`components/navigation-bar`（自訂 `navigationStyle: custom`）
- **設計文件**（`docs/`，已用 `packOptions.ignore` 排除打包）：
  - `01-藍圖與競賽對標.md`：定位、痛點→指標、P0/P1/P2、四維度評分對標、亮點工期、里程碑、風險登記
  - `architecture.html`：系統架構圖（含兩階段部署路徑）
  - `02-資料模型與API.md`：13 張表、兩個狀態機、樂觀鎖 SQL、錯誤碼、32 個操作
  - `openapi.yaml`：27 條路徑 / 32 個操作的 API 契約
- **工程基線**：`LICENSE`（MIT）、`SECURITY.md`、`CONTRIBUTING.md`、Issue/PR 模板、CI（結構檢查 + JSON 解析）

## 修正

- 移除 `app.json` 的 `rendererOptions.skyline.tagNameStyleIsolation`——WeChatLib 3.17.5 起已失效，會持續吐 `[warn]`
