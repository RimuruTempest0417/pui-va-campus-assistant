# v0.2.2 — 主題色改為培華紫（2026-10-22）

## 為什麼改

使用者指出：**培華的主題色是紫色**，不是初版猜的藍、也不是更早的綠。
校徽本身是紅字圓環＋藍水波＋綠葉，但學校識別色以紫為主（官網也出現 `#9966FF`）。

## 改變

- `--pv-tint`：`#6D3FC4`（培華紫）—— 主要動作、連結、選中態；白字對比 **6.65:1**，通過 WCAG AA
- `--pv-tint-pressed`：`#5A31A6`、`--pv-tint-soft`：`#F0EAFB`
- `--pv-brand` 保持 `#C8102E`（校徽紅），只用在身份標記與緊急，不參與一般互動
- 為什麼不用官網那個亮紫 `#9966FF`：白字對比只有 3.68:1，不合格；同色系壓深到 `#6D3FC4` 才兼顧識別與可讀性
- 展示頁色票、`docs/04-設計規範.md` 同步
