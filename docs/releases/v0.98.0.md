# v0.98.0 — 首頁家長卡直接寫「子女功課未交數」（2026-11-06）

任務：W-79（前端 v0.98.0；後端不變 v0.53.0）

## 這一版在回答什麼問題

家長打開小程序，第一眼最想知道的不是「小孩報了幾個活動」，而是**「今天有沒有功課沒交」**。
上一版家長端已經有「功課」分頁（W-76），但要點進成績頁、再切到第三個分頁才看得到；
首頁那張「我的子女」卡只有報名數／認領數／未讀公告 —— 那三個數字家長反而不太在意。

這一版把那行加上去，並且刻意處理兩件「看起來小事、實際上會被當成 bug」的情況：
**取不到資料時顯示「—」而不是 0**（0 會被讀成「功課都交了」），
以及**切換子女時那行要跟著換人**（否則會停在第一個小孩的數字，家長完全不會發現）。

## 改了什麼

- 前端 `pages/index/index.js`：
  - `loadKidSummary()` 多讀一支 `data.parentChildHomework(studentId)`，把 `stats.todo`／`stats.overdue` 放進家長卡摘要。
  - 新增純函式 `homeworkLine(hw)` 產生那行文字，四種結果：`功課 2 項未交`／`功課 2 項未交（含逾期）`／`功課都交了`／`功課 —`。
  - 這一支**包在自己的 try/catch 裡**：功課取不到（孩子帳號沒班級、後端一時失敗）只讓那一行變「—」，報名／認領／未讀照常顯示；同時 `reporter.reportError()` 上報，線上錯誤記錄接得住（不是靜靜吞掉）。
  - 用既有 `i18n.pick()` 文案：` 項未交`／` 項未交（含逾期）`／`功課都交了` 都是原本就有的字串，沒有新增翻譯條目。
- 前端 `pages/index/index.wxml`：家長摘要多一行 `.kids__sum-hw`，有逾期時加 `is-warn`。
- 前端 `pages/index/index.wxss`：那一行用 `--pv-fs-caption-1` ＋ `--pv-label-2`，逾期轉 `--pv-warning`（橘），沒有新增任何色值。
- 前端 `pages/help/index.js`：家長分頁補一條 Q「首頁那張子女卡上的『功課 2 項未交』是什麼意思？」，把「— 不是 0 項」寫清楚。
- `utils/i18n-phrases.js`：以 `scripts/build-i18n-phrases.py` 重建，1535 組（原 1533）。
- 守門：
  - `scripts/check-data-layer.mjs` 加 2 條（示範層 `parentChildHomework` 的 `todo > 0` 且 `todo + done === total`；`pages/index` 真的接了這支端點、WXML 真的有那一行）→ **181/181**。
  - `scripts/check-parent-view.cjs` 加 7 條首頁家長卡斷言（22 項）：有未交／含逾期文案、全部交齊、`needsClass` 顯示「—」、**取不到時顯示「—」而不是 0**、取不到時其他資料仍在。

## 設計取捨（答辯會被問的）

- **不新增後端端點**：`GET /parents/me/children/:id/homework` 上一版就有了，這一版只是把同一份資料多接一個畫面。多開一支「摘要」端點等於兩份真相，功課改了摘要不會跟著改。
- **「—」而不是 0**：家長看到 0 會直接理解成「功課都交了」，而實際上是「這支查詢失敗」或「孩子還沒設班級」。同理未綁定子女時也是「—」。
- **不加「未交」通知給家長**：站內通知只發學生（見 v0.97.0 的取捨）；家長要看細節點進成績頁，首頁只給一個數字，避免同一件事通知兩次。
- **不在 `onLoad` 的 `Promise.all` 裡一起等**：功課那支失敗會讓整個 `Promise.all` reject，整張卡（連報名數）都消失 —— 這是這一版最主要的風險，所以它自己一個 try/catch。
