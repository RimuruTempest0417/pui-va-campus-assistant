# v0.113.0 — 教師端「班級總覽」：朝會前 30 秒看完本班（2026-11-07）

任務：W-94（前端 v0.113.0／後端 v0.65.0；沒有新表、沒有 migration、新增 1 支端點）

## 為什麼做這一項

老師現在要知道「本班這週誰沒交功課、有沒有待審假單、報修處理到哪」，得在後台三個分頁之間來回
（功課分頁看完成率、假單分頁看待審、報修分頁看處理中），而且手機上每次都要重新篩班級。
這一頁要回答的是導師在朝會前那個問題：**「我們班今天有沒有事？」**

## 做了什麼

### 後端（v0.65.0）

- **`GET /teacher/class`（一支聚合端點）**，`src/routes/class-overview.ts`：

  | 區塊 | 內容 |
  |---|---|
  | 基本 | `className`／`grade`／`role`／`classSize`（本班**學生**人數，不含帶班老師） |
  | `homework` | `items`（未收回的功課項數）／`overdueItems`／`pendingTotal`（全部功課的未打勾人次合計）／`subjects`（依科目分組：items／pending／overdue）／`upcoming`（未到期最近三項，帶已交/全班） |
  | `leaves` | `pending`（待審件數）／`approvedToday`（今天請假中的人數）／`latest`（最近三張待審：誰、假別、起訖） |
  | `repairs` | `pending`／`inProgress`／`latest`（本班同學送出的最近三張） |

- **班級由後端從 `User.className` 決定，不信前端傳來的班級**：老師帶 `?className=` 指定別班回 **403**；
  只有 `ADMIN`／`SUPER_ADMIN` 可以指定別班（校務處／資訊管理員要跨班看）。
- **學生與家長一律 403** —— 這一頁會出現同學姓名，只在 UI 隱藏是最常見的資料外洩點。
- **沒班級回 422** 並寫「請找校務處在後台設定班級」，不是 500 也不是空頁面。
- **口徑與各模組清單一致**：功課只用 `deletedAt: null`、假單只算 `status='PENDING'`、報修只算本班同學送出且
  狀態為 `PENDING`／`IN_PROGRESS`；每一格都是同一份查詢條件算出來的，不會「這一頁說 3、點進清單有 5」。
- **順手修掉一個分母不一致**：`/homework/stats` 的「全班人數」原本把**帶班老師**也算進去（老師自己打勾就永遠
  到不了 100%），v0.105.0 已把 `/admin/homework` 的班級完成率改成只算 `STUDENT`，這一版把 `/homework/stats`
  一起對齊。三支端點（`/homework/stats`、`/admin/homework`、`/teacher/class`）現在同一個分母。
- 沒有新表、沒有 migration、沒有改任何既有權限或角色。

### 前端（v0.113.0）

- **不開新頁**：在既有「功課」頁最上面多一張「班級總覽」卡（只有老師與校方看得到）——
  一張卡 2×2 四個數字（功課未交人次／逾期功課／待審假單／報修待處理），下面是「依科目（未交）」與
  「待審假單」兩段，段與段之間是 1rpx 髮絲線（不是每項一張卡）。
- 標題右邊寫「高二仁 · 24 人」，一眼知道看的是哪一班。
- **取不到就整區不出現**：`data.classOverview()` 失敗（例如帳號還沒設班級 → 422、示範模式關掉時後端沒這支）
  只有這張卡消失，功課清單照常 —— 附加資訊不該讓整頁變成「載入失敗」。
- `services/{api,mock,data}.js` 三層都補 `classOverview()`：示範層由同一組示範資料算出同一個形狀
  （同一筆功課打勾後，總覽的未交人次也會跟著變），權限規則照抄後端（非教職員 403、老師帶別班 403）。
- 使用說明（老師分頁）補一條 Q&A：「想在上課前一次看完本班有沒有事，要去哪裡看？」
- `docs/openapi.yaml` 補 `/teacher/class`（191 路徑／233 操作，parity 雙向 0）。

## 設計取捨

- **為什麼是一支聚合端點，而不是前端打三支**：三支請求在手機上會一閃一閃跳數字，而且「本班人數」這個分母
  會在三處各算一次（遲早不一致）。聚合在後端做，口徑只有一份。
- **為什麼只回數字、不回全班姓名**：一頁幾十項功課都帶姓名會變成上千筆。要點名請走既有的
  `/homework/:id/pending`（點一項才查一次）。
- **為什麼不放在後台「概況」分頁**：導師最常開的是功課頁（每天要看要交什麼），班級總覽放在同一頁才不用多跳一層；
  後台概況是校方視角（全校），語意不同。
- **沒做的事**：各科老師視角（只認導師班）、匯出這張總覽、報修只看「本班教室」而不是「本班同學送出」
  —— 報修的地點是自由文字（`304 室`／`化學實驗室`），用字串比對班級會漏也會誤中，改用報修人的班級比較準。
