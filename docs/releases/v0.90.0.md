# v0.90.0 — 搜尋多一類：二手轉贈也搜得到（2026-11-06）

> 前端 v0.90.0／後端 v0.48.0；沒有新表、沒有新 migration（只有 `/search` 多一組來源）
> 任務：W-71（P2）

## 為什麼

轉贈已經有 4 頁、清單上數十件東西，但首頁那顆放大鏡只搜公告、活動與失物。同學要找「化學課本」時，
不會先想到「去轉贈分頁慢慢翻」——他會直接打關鍵字，然後看到「沒有找到相符的內容」，以為學校沒有人送。
這一版把轉贈接進同一支搜尋，**一支輸入框、四種東西**。

## 設計取捨

- **接進既有 `/search`，不另開 `/search/giveaway`**：兩支端點等於兩份「誰看得到」的規則，轉贈的可見性一改就只會改一邊。這一支只加一個 `if`，可見性條件仍然只寫一次。
- **`type` 用小寫 `giveaway`**（規劃書原本寫 `GIVEAWAY`）：既有三類都是小寫，混用大小寫會讓前端的 `ROUTE`／`typeLabel` 對照表出現兩個 key 指向同一件事。
- **只搜 AVAILABLE，不做「已贈出但也顯示」**：可以理解成「歷史紀錄」很有用，但搜尋的用途是「我現在找得到什麼」；要翻歷史有「我的轉贈」。
- **徽章共用 `utils/giveaway`**：種類對照（BOOK→書籍）只有一份，後台、清單、詳情、搜尋都吃同一支。
- **不加「轉贈」專屬篩選 chip**：搜尋頁目前沒有類型篩選（四類全部一起回），加一個只給轉贈用的 chip 會讓其他三類看起來像被排除。
