# v0.63.0 — 家長端「成績與出缺席」（家校通整合）

## 做什麼

家長／學生用自己的**家校通帳號**（`app.puiva.edu.mo`）登入，App 讀自己的成績與出缺席。

| 模組 | 行為 |
|---|---|
| 連結 | 在「成績與出缺席」頁輸入家校通帳號密碼；後端**先真的登入一次**，成功才把帳密以 **AES-256-GCM** 加密存起來（任何 API 都不回傳帳密） |
| 同步 | 抓「當前學年＋上一個學年」× 三個學段：成績與出缺席（實測 2026/2027 第一段：成績 6 筆、考勤 35 筆） |
| 成績 | 依科目列表，顯示學段、測驗類型、日期、分數（等寬數字） |
| 出缺席 | 日期、到校／離校時間、狀態（出席／遲到／請假／缺席），上方統計上課日／遲到／缺席 |
| 手動後備 | 同步失敗（密碼失效、學校站掛）→ 明確顯示原因，並提示可手動補登或請老師代登；後端另有 `POST /school/manual/grades`、`/school/manual/attendance` |
| 解除 | 一鍵刪掉已存的帳密（已同步的資料保留） |

入口：家長頁最上方「成績與出缺席」。

## 注意

- 帳密只在使用者自己的連結上，老師看不到；`SCHOOL_CRED_KEY` 改了會讓已存帳密失效（需重新連結）。
- 學校系統是 PHP 7.3 舊站，若改版或加驗證，同步會失敗但**不會覆蓋既有資料**，會顯示原因。
