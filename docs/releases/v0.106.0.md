# v0.106.0 — 示範資料可以只補一類：場地／館藏／課表各自匯入、各自清除（2026-11-07）

任務：W-87（P2，後端 v0.59.0）

## 做了什麼

- **分項匯入／清除**：後端 `/admin/demo-data` 本來就收 `kind: venues | library | timetable | all`，
  但兩個後台只有「三種一起」的兩顆按鈕 —— 想單獨補館藏就得用 curl。現在兩邊都有分項操作：
  - **小程序後台「示範資料」分頁**：三列數字（場地與器材／館藏圖書／班級課表）右邊各一組
    「匯入」「清除」小按鈕（`data-kind` 傳給同一支 `runDemo(kind, action)`），共用同一個
    `demoBusy` 鎖；清除走 `wx.showModal`，標題會寫出是哪一類（例「清除館藏圖書示範資料」），
    內容明寫「只清掉這一類的示範資料，真實資料不會動」。
  - **網頁後台「示範資料」分頁**：多一個「分項匯入／清除」區塊，三列各一組按鈕；
    `runDemo(action, kind = 'all')` 一個函式吃兩種呼叫，`confirm()` 一樣寫出類名。
- **結果文字只唸這次動到的類別**：分項匯入不再印「場地 0 · 館藏 6 · 課表 0 格」，
  只寫「匯入完成：館藏圖書 6」。`skipped` 的統計也按同一組條件過濾，
  所以「因同名真實資料而跳過」的數字不會把別類的 0 也算進來。
- **原本的「全部匯入／全部清除」保留**，按鈕文案改成「匯入全部示範資料／清除全部示範資料」，
  避免和分項那幾顆混淆。
- **示範課表班級改顯示在輸入框下方**（「已匯入課表的班級：高二仁」），
  原本擠在「班級課表」那一列的數字後面，加了按鈕之後就沒位置了。
- 順手清掉 `.row-actions pv-button { margin-right }`：Skyline 下 margin 不會穿透自訂組件宿主，
  相鄰按鈕的間距一律用容器 `gap`（`styles/ui.wxss` 的 `.ui-row` 本來就是這樣寫）。

## 設計取捨

- **不新增端點**：`kind` 參數 v0.100.0 就支援了，這一版只補「讓使用者按得到」。
  多開一支 `/admin/demo-data/venues` 等於同一件事兩份真相。
- **共用一個 busy 鎖而不是每列一個**：示範資料是同一批表，兩個操作同時送出會互相打架
  （一個在 `SEED` 一個在 `CLEAR`），所以任何一顆按下去，六顆小按鈕＋兩顆全部按鈕一起鎖。
- **確認框一定要帶類名**：只寫「清除示範資料」時，使用者分不清是按了哪一類；
  寫成「清除館藏圖書示範資料」＋「只清掉這一類的示範資料，真實資料不會動」才敢按。
- **不做「只匯入某一位老師的課表」**：課表的粒度是班級（`className`），
  拆到老師層級要在 `timetableSlot` 上再加維度，超出這一項的範圍。
