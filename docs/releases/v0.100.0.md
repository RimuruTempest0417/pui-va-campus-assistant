# v0.100.0 — 示範資料一鍵匯入／清除（W-81，後端 v0.54.0）

> 日期：2026-11-06　｜　前端 `0.100.0`／後端 `0.54.0`　｜　分支 `develop`（後端 `main`）

## 這一版解決什麼

老師演示時最尷尬的畫面是「空的」：場地借用沒有任何場地、圖書館沒有半本書、班級課表一片空白。
以前只能現場手打，打完還要記得清掉，而且手打的資料跟真資料混在一起，事後分不出來。

這一版把「準備演示資料」與「清掉演示資料」各變成一顆按鈕，寫進去的**是真的資料列**（前台三個頁面真的讀得到），
只是多了一個 `demo = true` 的標記，所以清除時可以只刪這一批。

**刻意不做的事**：不把假資料寫死在讀取路徑裡。Gary 明確制止過「靜默降級」——畫面上分不清真假資料比沒有資料更糟。

## 後端（v0.54.0）

- **Schema（第 33 支 migration `20261106153534_demo_data_flag`）**：`books`／`resources`／`timetable_slots` 各加一個 `demo Boolean @default(false)`。
  用欄位而不是名稱前綴（`示範-`）：示範資料在畫面上要跟真資料長得一樣，前綴會讓人一眼看出是假資料，也清不掉手打的那些。
- **新檔 `src/routes/admin-demo.ts`**：
  - `GET /admin/demo-data`：回 `counts { venues, books, timetableSlots }` 與課表用了哪些班級（後台按鈕旁的三個數字）。
  - `POST /admin/demo-data`：`{ kind: venues|library|timetable|all, action: SEED|CLEAR, className? }`。
  - 能力一律 `system:config`（只有最高權限）——這支會批次寫入／刪除，比一般後台操作重。
- **匯入內容**：5 個場地／器材（三樓物理實驗室、圖書館研習室、禮堂、流動投影機、無線麥克風；最後一個刻意設「免審批」示範送出即生效）、
  6 本館藏（ISBN 是檢查碼正確的示範書號，條碼掃描真的能用；其中兩本借期不同，看得出規則）、
  一整週 5 天 × 7 節 = **35 格**課表（科目／老師／課室都填滿，含班會與自習）。
- **兩條安全規則**：
  - **匯入不覆蓋真實資料**：同名的真實場地／同書號的真實館藏／同班同節的真實課表都會跳過，並在 `skipped` 回報筆數。
  - **清除只刪 `demo = true`**：真實資料一筆不動。示範場地上如果已經有人試按過借用，那些申請會一起清掉，`cleared.bookings` / `cleared.loans` 會回報刪了幾筆。
- 匯入與清除都寫一筆審計（`DEMO_DATA_SEED` / `DEMO_DATA_CLEAR`）。

## 抓到的坑（給下一個人）

1. **`GET /admin/demo-data` 的班級清單不能在 WXML 用 `demoClasses.join('、')`**：WXML 不支援方法呼叫，寫了不會報錯、只會顯示空白。改成在 `loadDemo()` 算好 `demoClassText` 再 `setData`（本專案第二次踩這個形狀）。
2. **`app.register(timetableRoutes)` 那行差點被換掉**：加新路由時用 patch 直接把 `timetableRoutes` 那行換成新的註冊，課表整組會消失而 `tsc` 不會講話（型別沒少）。用 `git diff` 看 app.ts 才發現，已改回「保留原行＋新增一行」。
3. **新詞條要跑 `python3 scripts/build-i18n-phrases.py`**：`check-project` 第 15 條會逐條比對 `i18n.pick()` 有沒有簡體對照，漏了就是 17 條紅燈（不是警告）。
4. **Prisma 加欄位後的順序**：`migrate dev` → `generate` → `prepare-test-db.mjs` 之後才跑測試，否則 LSP／測試會說 `demo` 不存在（client 還停在舊 schema）。

## 未做／已知缺口

- **畫面沒有親眼驗**（本輪在排程環境跑，沒有開模擬器）：示範資料分頁的版面、按鈕間距、`wx.showModal` 的實際彈窗都只驗到資料與邏輯層（`check-pages-boot` + `check-states` + 後端 e2e）。
- **清除不按班級過濾**：`CLEAR` 一律刪掉所有 `demo = true` 的課表格（含之前用別的班級匯入的）。刻意如此——示範資料本來就是「一整批」的概念，要分開清就得記住自己匯入過哪幾班，反而容易留殘。
- **`venues` / `library` / `timetable` 三種的入口目前只有「全部一起」**：後端支援單獨 kind，前端只放了 all 的兩顆按鈕。要單獨匯入（例如只想加館藏）得用 curl。
- 依賴 W-86（班級名單可設定）之前，課表班級要靠管理員自己在輸入框打。
