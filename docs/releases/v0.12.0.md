# v0.12.0 — 前端登入與教職員入口（W-11 第一段，2026-10-23）

## 1. 修正：列表請求帶 `undefined` 造成 422

Console 的錯誤：

```
GET /api/v1/items?type=undefined&status=undefined&q=undefined&page=1&pageSize=10 → 422
```

原因：`wx.request` 會把 `undefined` 序列化成字串 `"undefined"` 放進 query，後端 Zod 看到 `type="undefined"` 不是 `LOST|FOUND` → `VALIDATION_FAILED`。

修法：`utils/request.js` 對 GET 參數做清洗（丟掉 `undefined`／`null`／空字串／字面 `"undefined"`、`"null"`），呼叫端不用逐個改。
驗證：失物列表回到 **6 筆**、Console 沒有 422。

## 2. 新增：進站自動登入（`wx.login` → JWT）

- `services/data.ensureLogin()`：沒有 token 時用 `wx.login` 換 code → `POST /auth/login` → 存 token
- 首頁載入前先呼叫；**失敗就當訪客**（沒後端、AppSecret 有問題都不會擋住畫面）
- 實測：清掉 token 後重進首頁 → token 196 字、`/auth/me` 回 `role=STUDENT`、四模組資料正常

## 3. 新增：首頁依角色顯示「教職員後台」入口

- 只有 `TEACHER`／`ADMIN`／`SUPER_ADMIN` 才看得到（前端只做顯示，真正的權限在後端）
- 後台是網頁，點一下**複製網址**（`http://127.0.0.1:3100/admin`）並提示用電腦瀏覽器打開
- 實測：把測試帳號改成 `ADMIN` → 首頁出現入口、`adminUrl` 正確；改回 `STUDENT` 即消失

## 4. 後端配套

`POST /auth/login` 新建使用者時預設 `nickname = '同學'`（原本是 null，首頁顯示空白訪客）。
