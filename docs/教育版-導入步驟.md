# 教育版（教育開發版）導入步驟

> 教育版與測試號是**兩套帳號**：程式碼完全共用，差別只有 `project.config.json` 的 `appid`。
> 這條線用來做「正式／上架」（可用雲開發、免備案），比賽與校內交付仍走原本的測試號專案。

## 實際採用：同一份程式碼，第二個資料夾

`project.config.json` 的 appid 是「一個資料夾一個」，而測試號要留著給比賽／校內交付、教育版要拿來發佈，兩者 appid 不同。

實測結果：把主資料夾 appid 切成教育版後，測試號那個開發者工具的**自動化直接回 `APPID_ERROR`** —— 所以兩個 appid 不能共用同一個資料夾。

解法（一行指令同步，兩個開發者工具可以**同時開**）：

```bash
node scripts/sync-edu.mjs
```

- 主資料夾 `wechat/exam` → appid `wx9f104c034c07e15f`（測試號，比賽用）
- `wechat/exam-edu` → appid `wx8b19ff2ad59bf581`（教育版，發佈用；由腳本產生）
- 同步時**不會覆蓋** `project.config.json`／`project.private.config.json`

改完程式碼跑一次 `sync-edu.mjs`，教育版那邊重新編譯就同步了。

## 為什麼選「本機項目」而不是「在線項目」

| 比較 | 本機項目（同一資料夾）✅ 建議 | 在線項目（微信代碼託管／Git） |
|---|---|---|
| 改一次兩邊生效 | ✅ 同一份檔案，重新編譯即可 | ❌ 要先 commit + push，另一邊再 pull |
| 我能不能自動化 | ✅ CLI／MCP 直接開頁面、跑自動化、量尺寸 | ❌ 工具鏈只能操作本地磁碟上的專案 |
| appid 切換 | `node scripts/use-appid.mjs edu` 一行 | ⚠️ `project.config.json` 進版控 → 每次切換都留一個 commit |
| 適合情境 | 單人開發、已有 GitHub repo（本專案） | 多人同時改、或要在別台電腦臨時改 |

**結論：本機項目。** 你的檔案已經在 GitHub，多一層「在線項目」只是多一次同步。

## 步驟

### 1. 先填教育版 appid（由帳號擁有者提供）

編輯 `config/appids.json`：

```json
"edu": { "appid": "wx你的教育版appid", "label": "教育版／正式主體" }
```

### 2. 切換 appid

```bash
node scripts/use-appid.mjs edu      # 切到教育版
node scripts/use-appid.mjs test     # 之後要回測試號
node scripts/use-appid.mjs          # 看目前是哪一個
```

### 3. 在教育版開發者工具導入

1. 教育開發版 → 左側「項目」→ 導入（＋）
2. 目錄選 `/Users/garycheong/Documents/Agents/wechat/exam`
3. AppID 會自動帶入 `project.config.json` 的值（教育版那個）
4. 後端服務選「不使用雲服務」（**除非**要測雲開發代理，見 `docs/雲開發-代理方案.md`）

### 4. 教育版用的是 `exam-edu` 資料夾

導入時選 `/Users/garycheong/Documents/Agents/wechat/exam-edu`（appid 已寫好）。
每次改完程式碼：`node scripts/sync-edu.mjs`，然後在教育版按「重新編譯」。

### 5. 兩個實例的 CLI/MCP 只能連一個

微信開發者工具會鎖定專案目錄。要切換時：

```bash
wechatide -c hermes close_project_window --project /Users/garycheong/Documents/Agents/wechat/exam
# 在教育版開，反之亦然
```

## 如果我需要直接操作教育版（可選）

教育版是**另一個開發者工具實例**（服務端口 `62517`），它自己的 MCP 沒有開在我這邊的連線上，所以目前我只能操作測試號那個實例。

要讓我也能自動化教育版，做法跟當初一樣：

1. 教育版 → 設置 → 安全 → 找到 MCP 設定（就在「多端插件服務端口」附近）
2. 複製那段 JSON（含 url 與 token）
3. 貼給我 → 我加一個 client 設定，之後 `-c edu` 就能開頁面、跑自動化、部署雲函數

## 導入後要改的地方（只有一處）

`config/config.js`：

```js
API_BASE_URL: 'https://pui-va-campus-server.vercel.app/api/v1',
TRANSPORT: 'https',   // 有雲開發並已部署 apiProxy 後改 'cloud'
```

教育版若能用學校已備案域名，`TRANSPORT` 保持 `'https'` 就好。
