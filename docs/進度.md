## 每輪流程

1. 先查餘額（< ¥12 停止）；再 `npm run check:errors`，修好的標記 `--resolve`。
2. 從 `docs/規劃書-待完成.md` 挑**一項**，只做那一項。
3. 綠燈才算完成：前端 `check-project`＋`check-data-layer`＋`check-docs`；後端 `tsc --noEmit`＋`npm test`。
4. 動前端 → `node scripts/sync-edu.mjs`；用開發者工具驗 UI 後**立刻 `close_project_window`**。
5. 收尾四件套：`docs/releases/vX.Y.Z.md`、本檔加一列、規劃書刪掉那項、README＋`docs/發佈與上傳.md`（版本號＋項目備注）。
