# 換成正式小程序：回鄉證路線（個人主體）

> 你手上的證件是**港澳居民來往內地通行證（回鄉證）**。
> 微信官方《小程序備案操作指引》的「個人備案」證件清單明確列出：居民身份證、護照、台灣居民來往大陸通行證、**港澳居民來往內地通行證**、外國人永久居留身份證、港澳居民居住證、台灣居民居住證。
> 所以回鄉證**可以**，不需要先辦居住證、也不需要學校主體。

---

## 階段 A｜註冊正式小程序（今天就能做，約 10 分鐘）

### 先準備（缺一項就會卡住）
- [ ] 一個**從未註冊過微信公眾平台**的郵箱（QQ／Gmail 都可以，建議新開一個專用郵箱）
- [ ] 手機號（先試澳門號 `+853`；若表單不接受，用大陸號碼）
- [ ] 你自己的微信（**必須已完成實名認證**，且實名用的就是回鄉證）—— 你要用它當「小程序管理員」掃碼
- [ ] 回鄉證正反面照片（手機拍，四角完整、字跡清楚、不要反光）
- [ ] 想好小程序名稱（見下面的「名稱風險」）

### 填表順序
1. 打開 https://mp.weixin.qq.com → 右上「立即註冊」→ 選 **小程序**
2. 填郵箱 → 收激活信 → 點擊激活連結
3. 選擇**主體類型：個人**，註冊國家/地區先選 **中国大陆**
   - 若下一步證件類型裡能選「**港澳居民來往內地通行證**」→ 直接填，最順
   - 若只能選「居民身份證」且必須 18 位號 → 返回上一步把地區改成 **中国香港／中国澳门**（港澳台個人），再填回鄉證
4. 填管理員資訊：姓名（與回鄉證完全一致）、證件號、手機號
5. 用微信掃碼做**人臉核驗**（管理員本人）
6. 提交 → 等審核（個人主體通常 **1–3 個工作日**，可能要求補交證件照）
7. 審核通過 → 郵箱／後台看到 **新的 AppID**（會與測試號 `wx9f104c034c07e15f` 不同）

> 同一張回鄉證最多可註冊 **5 個**個人小程序。
> 註冊**免費**；「微信認證」（30 元／次）是可選的，本項目不需要。

### 實測卡點（2026-10-23，第一次提交時遇到）

選了「中国大陆 / 个人」之後，表單只收**18 位大陸居民身份證**，所以：

| 欄位 | 填了什麼 | 錯誤訊息 | 原因 |
|---|---|---|---|
| 身份證號碼 | 澳門身份證（M 開頭 8 位） | 身份證格式不正確，或者年齡未滿 18 周歲 | 大陸個人主體只認 18 位居民身份證，**澳門身份證號不適用** |
| 管理員手機號碼 | `853` + 8 位 | 請輸入正確的手機號碼 | 大陸主體只收 11 位大陸手機（`1` 開頭） |

**解法：地區不能選「中国大陆」**。把「注册国家/地区」改成 **中国澳门**（若下拉沒有澳門，選 中国香港），主體類型仍是 **個人**，
證件類型會變成 **港澳居民來往內地通行證（回鄉證）**，填 H 開頭的證件號即可；手機號先試 `+853` 的寫法。

> 另外要注意「个人类型暂不支持微信认证、微信支付及高级接口能力」這行提示 ——
> 本項目不需要支付與高級接口，所以沒有影響；但**手機號快速驗證、部分插件**這類能力以後也不能用。

### 名稱風險（提前想好）
小程序名稱全平台唯一，**個人主體名稱含學校名（如「培華中學」）很可能被要求學校授權證明**。
建議先用中性名稱，例如：
- `培華校園助手（學生版）`
- `PV 校園助手`
- `培華生活助手`

等學校願意出授權，再改名也來得及。

## 階段 B｜小程序備案（拿到 AppID 後，不上架可以晚點做）

**什麼時候必須做**：要「發佈上線／被用戶搜到」才需要。只是參賽提交、開發版演示，可以不做。

- 入口：小程序後台 → 設置 → 基本設置 → **小程序備案**
- 材料：回鄉證、負責人現場拍攝照片（平台內完成）、互聯網信息服務承諾書（線上閱讀確認）、真實性核驗單（平台生成）
- 流程 5 環節：**填寫備案信息 → 平台初審（1–2 天）→ 工信部短信核驗（大陸手機號收碼，24 小時內回覆）→ 通管局審核（1–20 工作日，通常 3–7 天）→ 備案成功**
- 費用：**免費**

⚠️ 工信部短信核驗必須用**能收大陸短信的手機號**，這一步沒有替代方案。

## 階段 C｜域名備案（要真機打後端才需要）

小程序備案 ≠ 域名備案。真機上 `request` 打 `https://你的域名` 時，**域名本身必須已 ICP 備案**。

- 需要：域名（¥60–80／年）＋ 境內伺服器（騰訊雲輕量 ¥60–100／月，且多數省要求接入商購買滿 3 個月才給備案）
- 時間：1–3 週
- 之後把域名填進小程序後台「伺服器域名 → request 合法域名」

## 分工（誰做什麼）

| 事項 | 誰 | 備註 |
|---|---|---|
| 註冊填表、人臉核驗、付費 | **你** | 只能本人做，我無法代掃碼 |
| 備案材料文字（服務內容描述、說明書） | **我** | 你貼給平台前我先幫你寫好 |
| 換 AppID／AppSecret（repo + `.env`） | **我** | 你只提供新 AppID 與 Secret（Secret 別貼聊天，直接寫進 `.env`） |
| 後台「基礎庫最低版本 2.29.2+」 | **你** | 我不能登入你的後台 |
| 伺服器域名配置、上線檢查 | **我**（你操作後台） | 我會給你逐步指令 |

## 拿到新 AppID 之後我要改的三處

1. `project.config.json` → `"appid": "wx新號碼"`
2. 後端 `.env` → `WX_APPID`、`WX_SECRET`，重啟服務
3. 用 `curl` 驗證 `stable_token` 通過；再用假 code 打 `/auth/login` 應該回 `40029 invalid code`（代表通路正確）

> 不同 AppID 的 openid 不通用，換號後真機使用者會是新用戶；我們開發庫用的是假 openid，沒有影響。
