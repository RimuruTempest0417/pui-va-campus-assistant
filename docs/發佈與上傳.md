## 教育版的 CLI 為什麼接不上（已知問題）

- 這台機器只有一個 `/Applications/wechatwebdevtools.app`，教育版是**同一顆 app 的第二個實例**，資料目錄不同：
  - `…/微信开发者工具/d1e876…/Default/.ide` → `13305`（一般版）
  - `…/微信开发者工具/500597…/Default/.ide` → `62517`（教育版）
- 官方 CLI 只讀預設資料目錄的 `.ide`；把它改成 `62517` 後，教育版回「工具的服务端口已关闭」（該實例沒開 CLI/HTTP 憑證）
- 所以**教育版的上傳要在 UI 手動做**；一般版仍可用 `wechatide` 自動化
