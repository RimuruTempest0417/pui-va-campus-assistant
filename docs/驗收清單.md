## 每次改動後（後端 repo）

```bash
cd ../pui-va-campus-server
npm run check:errors               # 看未解決的錯誤記錄
npm run check:errors -- --full     # 需要時看完整訊息
npm run check:errors -- --resolve all   # 確認已修好的標記解決
```

或直接開後台 `https://pui-va-campus-server.vercel.app/admin` → 「錯誤」分頁。
**修好的一定要標記已解決**，否則下一輪會重複追同一筆。
