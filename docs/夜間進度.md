# 夜間自動改進：進度與隊列

> 用途：使用者睡覺期間，由排程任務每一輪取一項來做。**每輪只做一項、做完就要綠燈、綠燈才 commit。**
> 每輪開始先看餘額（DeepSeek 用量頁）；**餘額 < ¥12 立即停止一切工作**，不 commit、不 push，只回報現況。

## 鐵律（每輪都適用）

1. 只做**一項**，做完跑完測試才 commit；測試不綠就 `git stash` 或修正後重跑，**不留半成品在 main**。
2. 禁止 `git push --force`、禁止改 `.env`、禁止刪除資料庫使用者資料、禁止 `rm -rf`。
3. 每個改動都要有可重跑的驗證：`node scripts/check-project.mjs`＋`node scripts/check-data-layer.mjs`（動前端）、`npm test`＋`npx tsc --noEmit`（動後端）。
4. 動到前端 → 跑 `node scripts/sync-edu.mjs`；版本號＋1（0.x.y），並寫 `docs/releases/vX.Y.Z.md`。
5. 收尾三件事：README（功能表／進度）＋`docs/規劃書-待完成.md`（刪掉做完那項）＋`docs/發佈與上傳.md`（版本號與項目備注）。
6. 每輪最後把結果寫回本檔的「已完成」表，並把隊列第一項標記為進行中／完成。
